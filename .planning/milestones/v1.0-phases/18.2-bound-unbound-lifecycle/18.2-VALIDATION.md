stripped and excludes tests, specs, migrations, and the test kit. The cadence
scan matches the bare token `\binterval_days\b` (so it never matches the
unrelated `backup_interval_days`); the predicate scan matches the literal SQL
form `tracking_enabled = 0|1`.
