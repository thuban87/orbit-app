## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS picker grant → native module | Temporary per-field grant to picked contacts; must be copied out before it expires |
| native module → JS | Only app-owned values/paths cross; never the content:// URI |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-19-03 | Info disclosure | session URI leak into JS | high | mitigate | Native copies bytes/fields out of the grant; returns only app-owned file:// photo temp URIs and plain field values (V12/V8) |
| T-19-04 | Elevation of privilege | broad contacts permission | high | mitigate | No READ_CONTACTS declared; ACTION_PICK_CONTACTS per-field temporary grant only (the Android 17 privacy model) |
| T-19-06 | Tampering/DoS | malicious/oversized photo blob | medium | mitigate | copyToCache streams to an app-private temp file; downstream plan 10 resizes via expo-image-manipulator; a copy failure yields photoTempUri=null, never a crash |
| T-19-SC | Tampering | npm installs | high | accept | No package installs (in-repo native module + existing deps only) |
</threat_model>
