## This plan (slice 3 of 4)

Deliver the **`source='ai'` unconfirmed state** (FUEL-06). After this plan, an AI-proposed fuel item (which Phase 14 will write) renders visibly distinct on the profile — a "Suggested by AI" pill with **Confirm** and **Dismiss** — and confirming it makes it an ordinary item. No AI producer exists yet (Phase 14), so this is verified now by seeding a `source='ai'` row directly; the render + confirm-flip + prompt-exclusion are all testable today.

**Locked owner decision (resolved 2026-08-15), implemented exactly, not reopened:** confirming an AI-suggested item is a single `UPDATE fuel SET source='manual', modified_at=? WHERE id=? AND contact_id=?` — flip `source` 'ai'→'manual', **NO migration, NO new column** (no `ai_confirmed_at`, no migration 2), provenance intentionally not preserved. Because confirm flips 'ai'→'manual', "unconfirmed AI" is exactly `source='ai'`, which Plan 02's getRankedFuel already excludes from the glanceable/prompt-facing read — so confirming is what makes an item start ranking.

Purpose: closes the last privacy/provenance seam — a hallucinated fact never renders as user-authored and never feeds back into a prompt until the user vouches for it.

Output: `confirmFuel/confirmFuelCore` in `fuel-dao.ts` (+tests), and the AI-unconfirmed row treatment + Confirm/Dismiss wiring in `FuelEditor.tsx` / `ContactProfileScreen.tsx`.

Depends on 07-01 (fuel-dao) and 07-02 (FuelEditor/ContactProfileScreen serialization; getRankedFuel's source='ai' exclusion). **No new migration.**
</objective>
