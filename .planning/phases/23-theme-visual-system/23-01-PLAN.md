<assumption_delta_decision>
This phase FIRES the singular-theme assumption. Primary noun: the **theme identity** — theme package × appearance mode, with **per-package preference memory** (each package remembers its own mode, accent, background). Prior state assumed ONE dark-only preset (`space-dark`) and ONE AsyncStorage `orbit-theme` key holding only {mode, presetId}. This plan generalizes to TWO independent axes (package × mode = four palette slots) with per-package remembered accent/background/mode.

Decision: **PROMOTE.** The singular `orbit-theme` AsyncStorage key is retired to durable `app_settings` columns (theme_package + per-package galaxy_*/standard_* mode/accent/background) that are backup-portable; the old value is imported once at boot then the AsyncStorage key is cleared. Rationale: D-08 (theme prefs are durable settings that must live in app_settings and survive backup) and D-10 (independent axes, per-package memory, restore-before-paint). Companion invariant test: every package round-trips its own remembered accent/background/mode through the DAO write -> read path.
</assumption_delta_decision>

| Boundary | Description |

| backup file -> restore -> app_settings | Restored settings row may be tampered/partial |
