## Deviations from Plan

### Auto-fixed / adjusted

**1. [Rule 1 - Wording] Section labels come from the Profile section names, not the current-state registry**
- **Found during:** Task 1
- **Issue:** the plan says labels come "from the registry display names" and also that each kind reads with "its D-44 section name". The current-state registry's `displayName` is sentence case ("Last talked about", "Current location"), which is not the D-44 section name the Profile shows ("Last Talked About", "Current Location").
- **Fix:** current-state and Off Limits labels read `PROFILE_MODULE_REGISTRY` (the Profile's section titles); Gift Ideas / Thought of Them read `MEMORY_TYPE_REGISTRY`. No new wording. `CURRENT_STATE_FIELD_REGISTRY` is not imported by the search read; `isCurrentStateFieldKey` guards the key.
- **Commit:** `6ad9c169`

**2. [Rule 3 - Layering] UI label map does not import the DB search read**
- **Found during:** Task 1
- **Issue:** importing the label constants from `knowledge-search-read.ts` into `list-row-content.ts` would pull `field-defs-dao` (transaction, uid, data-revision) into a UI module and its node test.
- **Fix:** `list-row-content.ts` reads the same two registries directly.
- **Commit:** `6ad9c169`

**3. [Rule 2 - Test coverage] Name-only fallback test**
- **Found during:** Task 1
- **Issue:** the plan asks for "a name-LIKE fallback" case. The token scorer also matches substrings, so an ordinary name is always a corpus hit too.
- **Fix:** the case uses a punctuation-only term (`-` against "Mary-Kate"), which tokenizes to nothing, so only the name LIKE can match it; the row comes back with `match: null`. The relevance-order case became its own test.
- **Commit:** `6ad9c169`

**4. [Rule 2 - Test coverage] Replacement for the deleted fallback-snippet case**
- **Found during:** Task 2
- **Fix:** with the "name/fuel fallback announces the snippet" case deleted (as planned), a new case asserts a name-only hit announces "1 match." with no snippet, so the changed behaviour is still pinned.
- **Commit:** `f45745a7`
