## Phase Boundary

**Objective:** Remove `fuel` from the app root and stem, give each kept kind of remembered
information its own home and Profile section, make sharing land in a chosen Things to Remember
section, and fix the Things to Remember, memory and sharing UX the audit found — including the
three class-A fixes Phase 39 needs (G-11, I-01, I-04). Today fuel is an invisible store that only
shares and Add Contact's Off Limits box write to, that feeds AI without per-item consent, and whose
Off Limits half rides on a generic editor. After this phase: no fuel table, code or wording; Off
Limits in its own AI-free table; Gift Ideas and Thought of Them as memory sections; Last Talked
About with real dates, linked to interactions; one delete pattern; and per-section editors.

**In scope**
- Fuel retirement: table (copied, verified, dropped), DAO/read/ranking, AI feed, widget line,
  dashboard fuel search, FuelEditor and its three hosts, merge/purge/backup/restore/tombstones,
  "fuel" and "Avoid" wording (D-01, D-08, D-54, D-56, D-59, D-87).
- Homes: Off Limits table; Gift Ideas and Thought of Them as app-defined memory types; Recent,
  Topic and Fact dropped (D-33, D-34, D-36, D-43, D-44).
- Last Talked About and Current Location: dates, newest-date order, delete, See all and a reworked
  history page; interaction notes linked into any section via "Also save to" (D-37–D-42, D-45–D-53).
- Things to Remember surfaces: Profile sections, heading actions, empty-section Add, Pin, per-section
  editors replacing the Things to Remember editor screen, Memory screen retired (D-63, D-68,
  D-70, D-72, D-75).
- Add/Edit Contact inline sections with multi-line fields and Add buttons (D-05, D-65–D-67).
- Sharing: save-first to Thought of Them, section chips, Undo, AI switch, list picker, resume-prompt
  fix, new-contact confirmation copy (D-02–D-04, D-23, D-77–D-80, D-83).
- Moving entries between sections (D-06, D-84, D-85).
- AI permissions: shares start off, two new default settings, one switch for a linked note,
  Off Limits never sent (D-09, D-49, D-57, D-61).
- Search corpus: Gift Ideas, Thought of Them, Last Talked About, Current Location, Off Limits
  (D-58, D-62).
- Backup format v8 with v7 conversion (D-55).

**Out of scope**
- Share reminders ("Remind me about this") and the warm-share "stay in Orbit" native work → new
  phase (D-73, D-74, D-76).
- Hide from Profile beyond removing its one dead button (D-70, D-71).
- Widget replacement line → widget-overhaul phase (D-59; todo
  `2026-10-12-widget-knowledge-line-after-fuel.md`).
- Legacy-data repair steps (D-60).
- Contacts search's Bound-only default scope → 38.13. Merge summary completeness (NEW-12), merge
  success navigation, custom-field management and custom-field history (NEW-10) → 38.12.
  Relationship Overview "Not available yet" and the "AH" caption → 38.11. Accessibility labels
  G-24/I-15 → Phase 40.
- Removing the share screen's "New contact" option (rejected, D-82).
- Rolling the D-66 text field out to the rest of the app (≈25–35 free-text sites, ≈2 plans) and auditing the other ~55–65 inputs → Phase 40 (todo `2026-10-12-phase-40-text-field-sweep.md`).

**Preserved behavior** (CARRIED; see decisions)
- Off Limits is never sent to AI in any form and never on widget, notifications or contact cards
  (D-09, D-10). Scoped Off Limits write safety (D-11).
- Capture contracts: write before any prompt, never a touchpoint, canonical URL kept separate,
  every share owned by a contact, never-contacted included, archived excluded, name-only inline
  create, multi-attach = independent rows (D-12).
- Per-item AI permission rules; imported notes AI-off; app-owned types only (D-13–D-15).
- Last Talked About stays a distinct, history-aware concept (D-16).
- Migrations forward-only, copy-then-verify (D-18). 38.9 standards apply (D-19).
- Direct Last Talked About entries never count as contact (D-39).
- Sharing keeps today's `finish()` return to the source app (D-74).
