### Auto-fixed Issues

**1. [Rule 1 - Bug] Prototype-key lookup on stored kinds**
- **Found during:** Task 1
- **Issue:** `LEGACY_FUEL_KIND_HOMES[row.kind]` resolves `toString` / `constructor` through `Object.prototype`, so a stored kind of that name would map to an undefined table.
- **Fix:** own-property lookup (`Object.hasOwn`) in both the module and the migration's frozen copy; tested with `toString` and `constructor` kinds.
- **Commit:** `930aeccf`

**2. [Rule 1 - Bug] TypePicker label for a non-pickable stored type**
- **Found during:** Task 2
- **Issue:** with G-01 keeping the stored type and the picker filtered to `userPickable`, an imported memory's picker would show the fallback "Memory".
- **Fix:** the picker's selected label reads `MEMORY_TYPE_REGISTRY[value].displayName`.
- **Files:** `src/components/MemoryEditor.tsx`
- **Commit:** `2edae631`

**3. [Rule 3 - Blocking] Tests orphaned by this plan's own changes**
