## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] `undo-restore.ts` cannot import `localDateTime`**
- **Found during:** Task 1
- **Issue:** the plan says to build stamps with `localDateTime` (`database.ts`). `database.ts` imports `expo-sqlite`, so importing it would break the module's leaf / Node-pure rule and force every DAO test that reaches it to mock expo-sqlite.
- **Fix:** a private formatter using `formatLocalDate` plus local `hh:mm:ss`, the same rule as `localDateTime`; parsing still goes through `parseLocalMs`. Never `toISOString`.
- **Commit:** `72d14382`

**2. [Rule 2 - Correctness] The new hard-delete cores target live rows only**
- **Found during:** Task 3
- **Issue:** the snapshot excludes the live `deleted_at`, and Undo writes `deleted_at = NULL`. Hard-deleting a soft-deleted (trash) row through the new path would let Undo bring back as live a row the user had already binned.
- **Fix:** `deleteMemoryNowCore` / `deleteRelationshipNowCore` select and delete `WHERE id = ? AND contact_id = ? AND deleted_at IS NULL`; a trash row is refused like an unknown id. The trash path (`purgeMemoryPermanently` etc.) is untouched until plan 18. Tested.
- **Commit:** `37c9d781`

**3. [Rule 1 - Test fixture] Colour-word fixture**
- **Found during:** Task 3 gate
- **Issue:** a test note `"Red"` tripped `check:colors`.
- **Fix:** changed the fixture text.
- **Commit:** `37c9d781`
