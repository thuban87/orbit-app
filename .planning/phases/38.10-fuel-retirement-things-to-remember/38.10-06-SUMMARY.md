# Phase 38.10 Plan 06: AI context gate, prompt clean-up, Compose Research Summary

**The AI read now gates memories and interaction notes on both sides in SQL (Group Note copies, locked notes, AI-off links and cross-contact links never leave the device, and a linked note is sent once). The prompt and its item counts no longer carry a ranked list. Compose Research reads Off Limits from its own table under an "Off Limits" heading, takes memory Add-to-AI from the same SQL predicate, groups by a stable id and formats dates at render.**

## Accomplishments

- `MEMORY_AI_ELIGIBILITY` is two-sided (D-31, D-49, D-102, D-103, F-D1): live, `allow_ai = 1`, `group_note_copy = 0`, and a linked memory only through a `note` link to an interaction of the same contact that allows AI and is not locked.

- The ranked list is gone from the AI path: the reader import, the age helpers, `PromptContext`'s field and entry type, the resolver block, cap constant and contact-block lines, and the count helper. The default style note now says "the shared details".
- Compose Research:
  - Off Limits comes from `listOffLimitsForContact` under "Off Limits". An unlabeled item has `label: ""` and its text once (D-87, D-111). It is never AI-eligible (D-10).
  - Memory `aiEligible` comes from `listAiEligibleMemories` (D-49 for Message Focus).
  - `groupId` drives first-seen grouping and React keys (J-X01). Gift Ideas and Thought of Them group under their registry names (D-91).
  - Dates are formatted at render. `value` stays raw, and the read module still formats nothing.
- The `readProfileOffLimits` re-export is removed. The Profile read calls `listOffLimitsForContact` directly.
