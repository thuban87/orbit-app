## Sampling Rate

- **After every task commit:** quick run (touched tests + `tsc --noEmit`)
- **After every plan wave:** full post-merge gate (memory note `tsc-in-post-merge-gate`: vitest does not type-check)
- **Exception for waves 1–4 (the schema block):** during W1–W4 each plan keeps only `npx tsc --noEmit` and its own touched tests green. Other suites that migrate to `TARGET_VERSION` stay red until every SQL consumer is retargeted, because tsc cannot see SQL (RESEARCH Pitfall 1; PLAN-MAP §1; "this plan only" rule for this phase). The full post-merge gate is first required green at the end of W4, and after every later wave. Each W1–W3 SUMMARY lists its expected-red suites.
- **Before `/gsd-verify-work`:** full suite, tsc and check:colors green
- **Max feedback latency:** ~300 seconds
