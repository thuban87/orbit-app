# Phase 38.10 Plan 16: Profile Things to Remember Summary

## Accomplishments

**Read and layout (Task 1)**
- `readProfileKnowledge` splits non-imported memories into `memories`, `thoughtOfThem` and `giftIdeas` by type (any other type stays in Memories), each with its own hidden count; the imported count is unchanged. Pinned is built with no limit (`remainingCount` 0) and pinned rows stay out of their sections.
- `thought-of-them` and `gift-ideas` join the persisted ids, the parent map, the registry (labels "Thought of Them", "Gift Ideas") and the factory layout, in the D-44 order.
- `completeThingsToRememberChildren` inserts any missing Things to Remember child just after the nearest earlier factory child the saved layout has, with factory flags; the user's order and flags are kept and nothing is written back. `resolveProfilePresentation` applies it to every layout source.

**Presentation (Task 1)**
- `CHILD_ORDER` follows D-44; titles come from the registry. One count format ("N items"). "Not available yet" is now "Not set".
- `headingActionFor(id)` (exhaustive switch) and `childHasEntries(id, knowledge)` are exported; each child carries `headingAction` and `emptyAction` ("Add …", null for Imported and Pinned, null once the section has entries).
- Most Recent and Previous show `formatDisplayDateOrFallback(entry_date ?? created_at)`, date only. Last Talked About and Current Location carry `See all (N)` (N = the read's `total`, else 1 + Previous) whenever they have an entry.
- Pinned dedupes by `${owner}:${id}` and has no View all.
- `detail.url` for memories, current-state entries and Off Limits items; `detail.link` for linked memories and current-state entries.
- Entry actions are Edit and Pin/Unpin only; `KnowledgeAction` lost `hide` and the dead `restore`. Owner `fuel` → `offLimits`, item ids `off-limits:<id>`. The Off Limits helper "Avoid bringing these up" stays (D-105); Off Limits has no sparkle (D-10).

**Host (Task 1, Task 2)**
- `knowledgeHeaderAction` reads `headingActionFor`: `add` icon + "Add <section>", pencil + "Edit <section>", nothing for Pinned. It is drawn only when the knowledge read is ready and `childHasEntries` is true. The emitted intent is unchanged (`action: "edit"`, child id, section target).
- `onOpenLinked` is threaded to `ThingsToRemember` (optional).

**Sheet, cards, empty Add (Task 2)**
- Sheet buttons read "Edit", "Pin", "Unpin"; close reads "Close"; no Hide. A stored URL shows as a caption with an "Open" button through `openMemoryLink` (D-24).
- Card screen-reader actions are labelled the same and run the action that fired. Tap on a linked card calls `onOpenLinked(detail.link)`; long-press opens the sheet. Without `onOpenLinked` (or for an unlinked card) tap opens the sheet.
- An empty child with an `emptyAction` renders a tertiary button that emits `{ action: "edit", childId, target, affordance: "empty" }`.

**Screen routing (Task 2)**
