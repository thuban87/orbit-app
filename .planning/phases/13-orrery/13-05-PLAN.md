## Phase Goal (MVP user story)

**As a** person maintaining many relationships, **I want to** glance at my contacts as an at-a-glance solar system where drift and colour show who is slipping, **so that** I can spot who needs attention without reading a list.

This plan delivers the first user-visible slice of that story: the orrery becomes reachable from the dashboard and renders the status view (rings, planets, sun, rogue, empty state) with tap-to-profile. Morph, ambient motion, and the radial drag land in 13-07; the Settings star/sun controls in 13-06.

<objective>
Build the reachable static status-view orrery: a `<Canvas>` cloning `CropPhotoScreen`'s Skia idioms, rendering the orbiting set from `orrery-read` via the pure geometry/ring/occupant logic, with tap→profile, the rogue visual, the empty-state prompt, the two-segment view toggle (inert until 13-07), the bundled initials font, and the dashboard entry button + nav route.

Purpose: Turn the tested foundation into the first thing a user can see and touch.
Output: `SegmentedControl.tsx`, `OrreryScreen.tsx`, `assets/Inter-SemiBold.ttf`, the `Orrery` route, and the dashboard ◎ button.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stored photo path → Skia useImage | A stored relative photo path is resolved to a local file:// URI and decoded |
| Tap coordinate → navigation | A screen tap coordinate selects a contact id to open |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-13-05-01 | Tampering | photo path → `useImage` | low | mitigate | Paths resolve only via `resolvePhotoUri` (which runs `assertSafeRelative`); a decode failure falls back silently to swatch+initials (no error surface). |
| T-13-05-02 | Info disclosure | canvas render path | low | accept | Fully offline — `resolvePhotoUri` yields `file://` only; no network on the read/render path (local-first). |
| T-13-05-03 | Tampering | bundled font licence | low | mitigate | Vendor Inter (OFL-1.1) or Roboto (Apache-2.0) — both permit bundling; verify the licence before committing the `.ttf`. |

No high-severity threats. The orrery adds no network, no secrets, no new persistent write on this plan.
</threat_model>
