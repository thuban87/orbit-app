<objective>
Deliver the conservative multi-source consolidation Phase 19 explicitly owns — detecting that several SELECTED system-contact records represent one person and offering an explicit Combine-into-one (with multiple external links) vs Keep-separate choice — wired at the correct point in the flow: BEFORE the per-row batch runs, so the mechanism can actually see both siblings.

Purpose: The phase boundary lists "conservative multi-source consolidation" as owned by Phase 19; research sequenced it last. The cross-AI review found the original wiring (into DuplicateReviewScreen, after runImportBatch) was structurally dead — by the time it ran, one of any two same-person rows had already been imported and the other re-scored as a match against it. This plan moves detection PRE-batch (BulkImportSetup) over the raw snapshot and makes Combine an atomic one-contact/N-links/N-row-resolution write, then lets the driver's pending-only load naturally exclude the resolved rows.
Output: source-consolidation detector + atomic combine writer + ConsolidationPrompt + the BulkImportSetup wiring.
</objective>
