# BLOCKER RESOLVED (2026-08-29) — pointer injection was never broken

> The prior "pointer injection is dead" blocker was a MISDIAGNOSIS. Root cause was a full-screen
> touch-blocking scrim in `AddSpeedDialFab` (opacity-0 `absoluteFill` Pressable with hardcoded
> `pointerEvents="auto"`, always mounted) that swallowed EVERY dashboard touch — adb AND physical —
> leaving only the FAB (drawn above it) reachable. Fixed + committed as gap plan **19-18**
> (`33eefd7` fix, `1d660ad` summary) and **device-verified**: chips, Settings, contact nav, and
> FAB expand/collapse all respond to `adb input tap`.

- [x] adb `input tap` DOES drive React Native on this Pixel (proven: chip selection moved, Settings opened, FAB expanded).
- [x] Gotcha for high header targets: tap LOWER within a11y bounds (status-bar inset steals y≈105; y≈160 works).
- [x] `sendevent` is permission-denied (unrooted work phone) and is NOT needed. Do not root (breaks Uber Driver / Strong Play Integrity).
