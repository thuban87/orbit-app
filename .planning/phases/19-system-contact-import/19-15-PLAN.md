<objective>
Close GAP C.3 (IMP-04, part of failed verifier truth 4): `combineCluster` in
`source-consolidation.ts` (≈194–267) resolves every source row in the cluster to `imported` but
never calls `finalizeSessionIfTerminal`. For a cluster-only batch (all picked rows fall into one
cluster), after the combine there are zero pending rows, so `BulkImportSetupScreen` shows a
disabled `Import 0 contacts` control, the session stays `pending` forever, and the user can never
reach the completion summary.

Fix:
1. In `combineCluster`, after the successful combine + post-commit photo, call
   `finalizeSessionIfTerminal` for the cluster's session and report whether the session is now
   complete.
2. In `BulkImportSetupScreen.onCombine`, when the combine completed the session, route to
   `ImportComplete`; otherwise reload as today so remaining clusters / ungrouped pending rows still
   flow through the normal path.

Purpose: A conservative, consolidation-only batch must still terminalize and bridge to the
completion report — the same durable-completion contract every other review path already honors.
Output: A finalize-aware `combineCluster` (node-tested, incl. the two-row-only cluster) and a
BulkImportSetup route to ImportComplete on cluster-only completion.
</objective>
