## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| App JS → OS intent (dialer/messages/mail) | Native handoff hands data OFF to the OS; Orbit sends nothing to a server. |
| App JS → on-device SQLite | Assist writes; all `?`-bound. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-21-05 | Info disclosure | native handoff (tel:/sms:/mailto:) | low | accept | User-initiated OS intents need no permission and carry only the endpoint the user chose; no server egress (local-first). |
| T-21-06 | Spoofing (UX) | Text/Email "Yes" attestation | medium | mitigate | Copy is attestation-only; the UI never claims delivered/sent/read (grep-enforced) — no false trust conveyed. |
| T-21-07 | Tampering | Back-button vs banner | low | mitigate | Banner is a plain overlay (not a Modal); Back passes through, so a durable prompt can't be trivially cleared without an explicit resolve/dismiss. |
| T-21-08 | Elevation | new Android permission | high | mitigate | tel:/sms:/mailto: are permissionless; do NOT add CALL_PHONE/READ_SMS/call-log — verified absent from the diff. |
</threat_model>
