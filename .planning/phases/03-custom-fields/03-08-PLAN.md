| user field-definition input → DDL | Label/type/options entered here become a col_name + ALTER TABLE via the data layer; the screen never builds SQL itself. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | col_name from a user label | high | mitigate | The screen calls makeColName (Plan 01) and the tested DAOs; it never interpolates a label into SQL itself. |
| T-03-02 | Denial (data loss) | delete of a populated field | high | mitigate | The dynamic action forces Quarantine (reversible 30d) for a populated field; immediate Delete is offered only when isFieldEmpty is true. |
| T-03-07 | Information disclosure | hardcoded colour | low | mitigate | check:colors runs on every new UI file; error emphasis composed from tokens. |

No package installs (phase adds zero dependencies — reachability uses a local screen-state toggle, not a navigation library) — no supply-chain checkpoint applies. No automated behavioural test (no RN-component harness); behaviour is reviewed at the --to 3 gate.
</threat_model>
