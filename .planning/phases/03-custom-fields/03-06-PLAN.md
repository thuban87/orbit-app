<objective>
Rewrite the plugin's schema-driven form renderer (7 field types) against React Native primitives
(FLD-04 widgets, FLD-07 value rendering). This delivers the reusable custom-field VALUE input + display
components that Phase 4's contact forms and profile embed. No new dependency — RN primitives only.

Purpose: HANDOFF §14.8/§14.10 call the field editor the largest net-new item. The value widgets are its
foundation: one input per field type, plus the tap-to-fix error-state display for values that fail the
current type's parser. The dispatch and validation shape port from the plugin `FormRenderer`; the DOM
primitives (`<input>/<select>/<textarea>`, className, FormEvent) are dropped entirely.

Output: `src/components/field-widgets/*` (7 widgets), `src/components/FieldValueInput.tsx` (the
type→widget dispatcher), `src/components/CustomFieldValue.tsx` (read-time display + error state).

Scope fence: NO contact CRUD/forms shell (Phase 4 embeds these), NO photos pipeline (Phase 5 — the
photo widget is a minimal disabled placeholder), NO share_with_ai toggle (deferred to Phase 14).

Verification note: there is no RN-component test harness in this repo (RESEARCH). These components are
verified by tsc + biome + the no-hardcoded-colour gate here, and visually at the owner's --to 3 gate.
</objective>
