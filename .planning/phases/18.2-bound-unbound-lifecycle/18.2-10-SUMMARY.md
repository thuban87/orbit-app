### Task 2 deviations (reverse nothing; environmental)

- **Debug vs release build:** the plan assumed a `run-as`-capable v10 build on the
  device, but the installed build was **release** (not run-as-debuggable). Built a
  **debug** APK on the desktop (`assembleDebug`), `install -r` over the release build
  (data preserved), which satisfies both the real v10→v11 upgrade and the mandated
  `run-as` reads. Release ≠ run-as per `docs/runbooks/desktop-build-pipeline.md` §3.1.
- **Metro port:** host `:8081` Metro belongs to the owner's quest-board project, so
  orbit's Metro was run on `:8082` with the device's `8081→8082` reverse; quest-board's
  Metro untouched. Reverse restored to `8081→8081` after the UAT.
- **DocumentsUI/SAF grant cycle:** the recurring "backup folder needs reconnecting" is
  a side effect of the 18.1 `pm clear com.google.android.documentsui` workaround (which
  orphans the app's persisted tree-URI grant), compounded by per-phase reinstalls and
  this Pixel's latent DocumentsUI `RefreshTask` NPE. A durable fix (re-request/persist
  the SAF grant gracefully on launch instead of relying on a one-time saved URI) is
  noted for a later phase.
