<assumption_delta_decision>
Detector fired: single AI suggestion → three suggestions is a singular→plural (generalization) transition. Today the lifecycle success shape carries ONE `suggestion` string (ai-suggestion-logic.ts:97 `confirm-replace`) and the provider returns one string (AiService.ts:92). Decision = **PROMOTE**: the three-suggestion set becomes the primary success representation (a `readonly string[]` of exactly three), replacing the single-suggestion shape — not added alongside it. The `confirm-replace` single-suggestion state is retired. Rationale: ADR-079 makes three-suggestion the product contract; keeping a single-suggestion branch alongside would leave a dead shape and a half-migrated union. The provider-layer `generate(): Promise<string>` stays single-draft (fan-out at the lifecycle boundary); that is an implementation seam, not a competing representation. Advisory, non-blocking.
</assumption_delta_decision>
