## Deviations from Plan

### Auto-fixed / implementation adjustments

**1. [Rule 2 - Testability] Pure tone and date-cap helpers added to `tri-state-last-spoke-logic.ts`**
- **Found during:** Task 2
- **Issue:** The plan's files list did not include `tri-state-last-spoke-logic.ts`. The Not-yet colour rule only existed inside the RN component, which node Vitest can only check by regex on the source.
- **Fix:** Added `lastSpokeSegmentTone(kind, selected)` (token keys) and `lastSpokeMaxDate(now)`. `TriStateLastSpoke.tsx` reads `colors[tone.*]` and passes `maximumDate={lastSpokeMaxDate()}`. `control-a11y-contract.test.ts` tests their behaviour and pins that the component uses them.
- **Commit:** `e5be42e1`, `d202714e`

**2. [Design detail] `maximumDate` is the end of today's local day, not local midnight**
- **Found during:** Task 2
- **Reason:** A midnight cap can make Android clamp a same-day pick. The end of the day keeps all of today pickable and still blocks tomorrow. It is built from local date parts, never a UTC slice (CLAUDE.md Conventions).

**3. [Scope guard] `updateMethodDraft` recomputes only when the region argument is passed**
- **Found during:** Task 3
- **Reason:** `ImportReviewScreen.tsx` and the archived `UpdateContactScreen.tsx` also call it. Recomputing with no region would mark every national-format number unusable there. Only Add and Edit pass the region, per the plan's "(Add and Edit)".

**4. [Process] Tracer gate run autonomously**
- The config has `auto_advance` off, so the tracer gate would normally return an interactive checkpoint. This plan is `autonomous: true`, `human_verify_mode` is `end-of-phase`, and the orchestrator ruled out device checks before plan 14. So the gate re-ran Task 1's `<verify>`, which passed, and execution continued.

**5. [Plan step with nothing to remove] "Remove the duplicate frequency message"**
- Neither screen rendered a second frequency message: `fieldErrors.frequency` was set but never shown. The picker's message is now the field's one error source, revealed on a blocked Save through `errorForced={fieldErrors.frequency !== undefined}`.

**Total deviations:** 5 (1 testability addition, 2 design details, 1 scope guard, 1 process note). **Impact:** none on scope. No recorded decision was reversed.
