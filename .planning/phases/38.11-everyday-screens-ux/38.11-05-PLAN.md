## Interfaces (verified on disk)

Its only production caller is `ProfileLayoutEditor.tsx:348` (the editor's `save`, which holds both `initial` and `draft`, `:291-301`). - `collapse_json` is a map `{ [moduleId]: expanded }` parsed by `parseProfileCollapseMap`; `setProfileCollapseOverrideCore` (`:40-58`) shows the read-modify-write pattern.
- `assignContactLayoutTemplate` `:390-414` clears on a real switch; keep as is.
- `ProfileLayoutEditor.tsx`: chooser page `:369-391`; editor page `:392-449` with `ScrollViewContainer` + three `ReorderableBucket`s, each a `NestedReorderableList` (`:191-203`, `scrollable={false}`, no `scrollEnabled`), inside a `Sheet` with `variant="expanded"` on the editor page (`:364-368`); the "Expanded by default"/"Collapsed by default" tertiary Button `:133-149`; existing `onSaveAsTemplate(layout)` and `onManageTemplates` props; the editor footer ALREADY has a "Save as template" button (`:432-440`) that calls `onSaveAsTemplate(createLayoutTemplateIntent(draft))`, which ContactProfileScreen (`:968-971`) wires to open the templates sheet with that draft.
- D-29 cause (verified at planning, T-04): `scrollBody` is irrelevant here: expanded sheets never wrap their body in a ScrollView (`SHEET_BODY_SCROLLS.expanded = false`, `src/components/ui/sheet-contract.ts:30-31`; `Sheet.tsx:105-114` renders a plain View for expanded). The warning comes from `@react-native/virtualized-lists/Lists/VirtualizedList.js:1155-1169`, which logs "VirtualizedLists should never be nested…" when a same-orientation FlatList sits in a ScrollView context and `this.props.scrollEnabled !== false`. `NestedReorderableList` renders a FlatList (`ReorderableListCore.tsx:1158`, `scrollEnabled={forceDisableScroll ? false : scrollEnabled}`, defaulting to true at `:113`). During a drag the library disables scroll via `setNativeProps({scrollEnabled: false})` and only re-enables the list if its `scrollEnabled` prop is true (`ReorderableListCore.tsx:445-448`); the outer `ScrollViewContainer` is handled separately (`:450-455`), so `scrollEnabled={false}` on the nested list leaves the container's scroll and drag auto-scroll intact.
- ContactProfileScreen passes `effectiveSource`, `layout`, `onSaveAsTemplate`, `onManageTemplates` to the editor (`:960-973`) and computes `hasContactPresentationOverride` (`:327-333`).
- `ProfileTemplateManager.tsx:368-371` header with a text "Back" Button.
