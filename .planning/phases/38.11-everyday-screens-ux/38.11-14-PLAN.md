  changes, no edits to the phone's own Contacts (memory note "test-phones-are-for-testing"; CONTEXT
  Verification "No real AI call").

  (CLAUDE.md repo layout; memory note "untracked-artifacts-folder").

  owner signed off in earlier phases unless this phase changed them (memory note "no-duplicate-device-tests").

  plan with a recommendation (memory note "surface-deferred-items-immediately").
