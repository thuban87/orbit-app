# Phase 38.11 Plan 13: Profile top, ⋯ menu and Move to Bin Summary

**The Profile top now has a full-width Edit Contact button above Compose Message and Call. The ⋯ menu is Snooze… · Unbind contact (plain) · Move to Bin (red, confirmed, no Undo) · Profile Layout · Background. The person's name appears in the top bar once the hero name scrolls away, open sections show an up chevron, and the Layout sheets name the current layout in plain words instead of raw ids like "contact-freeform".**

- **Task 3, D-57/D-28 (reviews T-11, T-17):**
