## Sampling Rate

- **Per task:** the task's own test files only (the ones it creates or rewrites), plus its cheap grep checks. Source: owner 2026-10-12 ("shouldn't the tests be testing the end results, not the intermediate steps?").
- **Per plan (its last task's verify):** `npx tsc --noEmit` plus every test file the plan touches, as one listed vitest run, plus `npm run check:colors` where the plan touches UI.
- **Per wave:** full post-merge gate `npx tsc --noEmit && npm run check:colors && npx vitest run` (CONTEXT § Verification; memory note `tsc-in-post-merge-gate`: vitest does not type-check).
- **Before `/gsd-verify-work`:** full suite, tsc and check:colors green.
- **Max feedback latency:** ~300 seconds.
