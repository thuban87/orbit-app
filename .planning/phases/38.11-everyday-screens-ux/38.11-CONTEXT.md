## Phase Boundary

**Objective:** Make the Profile and the contact forms follow the 38.9 standards and stop
contradicting what the user just did; give new contacts the Phase 39 defaults and never-contacted
people a clear status; and restructure the contact actions the owner found muddled: one contact
form (Update Contact retired), a slimmer + menu, a clearer ⋯ menu with an Edit Contact button on
the Profile, Archive renamed Bin, one snooze sheet everywhere, a Birthday tile, and a reworked
Profile backgrounds experience with its own Settings page.

**In scope**
- New-contact defaults: Bound + Monthly + Last spoke "Not yet", Relationship Basics open, "Not yet"
  looks selected on Add and Edit (D-01–D-04, D-22, D-25, D-44).
- Add Contact gains Birthday, Social battery, Links (behind See More) and Photo (D-48, D-77);
  duplicate-name "Open existing" (D-73); Edit's Birthday Clear (D-49); Year unknown asks for the
  year (D-61).
- Not-contacted-yet Orbit Status and an honest Unbound reason (D-05, D-23, D-24); Gravity with no
  interactions (D-74); plain explanations in the stat sheets (D-75).
- Birthday Relationship Overview tile and sheet (D-53, D-55, D-56, D-59); Custom… frequency on the
  Profile sheet (D-54).
- Profile top: "Compose Message" label (D-47), full-width Edit Contact button (D-63), name in the
  top bar after scroll (D-57), section chevrons (D-28), truthful Message/Call reasons (D-27).
- Profile ⋯: Snooze… (D-64), Unbind plain (D-68), Move to Bin with confirm (D-69, D-71); Save as
  template and Reset move into the Layout/Background sheets (D-65); Edit Contact leaves ⋯ (D-63).
- One snooze sheet for Profile tile, Profile ⋯, Contacts card and Contacts bulk (D-45, D-37).
- Update Contact retired and archived as reference; Memory off the + (D-62, D-66).
- Archive → Bin wording app-wide (D-69).
- Profile backgrounds rework: Settings page for backgrounds; compact choose-only cards (D-58).
- Layout editor: open/closed state survives edits; nested-list warning (D-60, D-29).
- Form fixes: live contact-method warnings, Last-spoke date cap, chip tone, Photo placeholder,
  Custom… error timing (D-30–D-32, D-35, D-36).
- Edit save / Archive navigation (D-26); 38.10 D-149 items: + clearance and history-page
  placeholder (D-41, D-42); sheet-header Back text (D-43); dead tracer (D-38).

**Out of scope**
- 39 D-76 "Did you send it?" → Phase 38.14 (39-AMENDMENTS-PENDING R-2).
- Group Log leaving the + → built in 38.15 with its Events-tab create button (D-72).
- A Log button on the Profile → owner research todo (D-52).
- Archived-Profile behaviour (archived status arm, menu gating, star), Profile Archive/Bind
  feedback beyond D-71, Merge in ⋯, Mute placement → 38.12 (D-06/H-24, D-07, D-25 rest, D-27/H-21,
  D-28/H-20, H-09, H-19, H-22), using this phase's Bin wording and ⋯ shape.
- Contacts list/search/Digest items → 38.13 (except the snooze conversions moved here by D-45);
  the half-open search sighting is dropped (D-78).
- Accessibility-label sweep and large-text items → Phase 40 (D-21).
- Custom-background contrast help (D-51); Show less on Add (rejected, D-50); Delete on the Profile
  (D-67).

**Preserved behavior**
- Not-yet creates no interaction; Today/date writes the first interaction atomically (D-01, D-12).
- Bind with no cadence needs a valid frequency (D-12); import stays Unbound (D-07).
- Never-contacted status rule and `getContactStatus` untouched (D-20).
- Frequency presets apply instantly (D-14 as amended by D-54).
- Duplicate names warn, never block (D-18); contact-method problems warn, never block (D-17).
- Archive-before-delete gate; Bin never empties itself (D-67, D-70).
- Hero Message → Compose and Contact Methods Message → SMS handoff unchanged (D-46).
- Custom-background photos get no extra contrast treatment (D-51).
