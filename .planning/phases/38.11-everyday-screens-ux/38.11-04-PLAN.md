<objective>
Add Contact offers Birthday (with Year unknown), Social battery and Links behind See More, created in the
same single create save as everything else (D-48). One shared Birthday control fixes the Year-unknown
2000 leak on Add and Edit (D-61) and gives Edit a Clear (D-49).

Decided here ("this plan only", within D-48's "the planner decides the composition"): links are
written INSIDE the create transaction through a new non-bumping `addLinksCore`; birthday and social
battery are new optional columns on the create INSERT. Placement: See More reveals Birthday and Social
battery inside the Identity section (below Category) and Links inside the Contact Methods section,
the same places Edit Contact shows them. When a year-unknown birthday is switched to "year known", the
picker opens on the stored month and day in the current local year (never 2000), so the year shown is
always one the user confirms.

Purpose: the owner wants the full record available at create (ledger Q-17) without silent data loss.
Output: create DAO extension, shared link-draft shaping, BirthdayField + logic, Add/Edit wiring, tests.
</objective>
