<objective>
**As a** user whose linked system contact changed, **I want to** update one Orbit contact from Contacts and choose exactly what to accept, **so that** additions I want land while nothing I care about is silently overwritten or deleted.

This is the thin end-to-end reconciliation slice for ONE contact: profile `Update from Contacts` → re-read live source → classify the five field families → resolve in a detail view (reusing the 20-02 FieldChoiceGroup/PhotoChoice) → apply only the selected values through the existing authoritative writers, plus the narrow last-reviewed memory that stops re-nagging. Bulk `Check linked contacts`, durable sessions, and the card grid are 20-04; missing-source relink is 20-05.

Purpose: prove the one-way source→Orbit reconciliation path never destroys Orbit data and reuses the shipped writers, not a new write path.
Output: `reconcile-diff` (pure), `reconcile-snapshot-dao`, `ReconcileDetailScreen`, and the per-contact entry point.
</objective>
