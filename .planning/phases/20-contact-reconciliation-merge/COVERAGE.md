No external API integration: Phase 20 (contact reconciliation & merge) performs no network/external-API calls. It reads the on-device Android system Contacts provider through the already-shipped native `orbit-contact-picker` module (delivered in Phase 19); reconciliation is strictly local, one-way (System Contacts → Orbit), and never writes back. All merge/reconcile/bulk-review state is on-device SQLite. There is no external service surface to enumerate.
