## Phase Boundary

**Objective:** The Contacts tab, search and Digest follow the 38.9 standards, keep the user's view,
and show what is going on. First, measure and fix the List view's memory and tap-latency problem.
Build the two Phase 39 prerequisites moved here (39 D-95, 39 D-98) and the class-A fixes 39 relies
on (39 D-100).

**In scope**
- List-view investigation (measure first) and fix with behaviour preserved (D-55, D-56).
- Population menu: a listed, selected-by-default Active Contacts row; All/Active exclusive (D-23, D-58).
- "Everyone's tucked away" empty state: real never-contacted button and an Unbound line (D-65).
- Class-A fixes: stale search after reopen (D-24), swipe row stays open (D-25), list-row TalkBack
  actions (D-26).
- Contacts fixes: dropped population taps (D-27), empty-state copy (D-28, D-30), Back closes search
  (D-29), Reset scrolls to top (D-31), single-card width (D-32), card "no interactions" text (D-33),
  Default sort label (D-35), Filters summary (D-36), search-result labels (D-37), blank list and
  stale "1 match" (D-44).
- Search: Unbound people on All Contacts searches (D-59), tighter typo tolerance (D-60).
- Selection mode rebuilt: bottom bar per mockup M3b, More… sheet, hidden control row (D-69, D-72,
  D-74, D-75, D-76), Select All / Deselect all and applicability (D-40), FrequencyPicker (D-39),
  sheet sizes (D-71), picker title and keyboard (D-70, D-43).
- Digest: Overlooked = everyone needing attention (D-61), Your Week period wording (D-63), day
  detail close / tappable rows (D-45, D-46), heatmap labels (D-47), birthday avatars (D-48), no
  page jump (D-49).
- 38.4 code-review leftovers (D-50, D-51, D-52) and the search-scope docstring (D-53).

**Out of scope**
- Snooze sheet (card + bulk): done in 38.11 (D-16).
- Digest drills changing the saved Contacts view: no change (D-62).
- Status/filter legend (D-64); visible row actions or card swipes (D-66).
- Line-3 prompt shortening (A-21) and Overlooked reason captions (C-13): dropped (D-68).
- Accessibility-label sweep, large text: Phase 40 (D-15).
- Bulk "Log Interaction" → "Group Log" label (39 D-100 F-05), F-04/F-21/F-26: Phase 38.14.
- Profile content-card margins / flatter sections: todo for 38.14
  (`2026-10-18-profile-content-card-margins.md`).
- Weekly digest notification cadence or weekday (D-08).

**Preserved behavior**
- Bound-only Contacts universe for every unsearched list, population and count (D-01, D-59).
- Local query changes keep rows visible; no skeleton per update (D-02, D-44).
- Swipe right logs / left edits; UI-thread tint; card view has no swipes (D-05, D-22, D-66).
- Reset keeps view mode (D-04).
- Digest drills persist the Contacts query (D-06, D-62).
- Your Week period in both Settings and Digest (D-07, D-63).
- Frozen selection universe; Back exits selection first; careful actions kept separate (ADR-102 survivors, D-18, D-72).
- Search text does not survive relaunch; Profile → Back keeps search (D-21).
