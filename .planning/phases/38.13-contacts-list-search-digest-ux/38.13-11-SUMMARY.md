## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] D-90 long-pressed card deselected on release of the press**
- **Found during:** Task 4 device re-check (6 Pro, debug)
- **Issue:** Long-press entered selection but the card read "Not selected" ("0 selected"). Pressability evaluates `onLongPress != null` at release to decide whether to cancel `onPress`. GridCard set `onLongPress` to undefined once selecting, so the release ran `onPress`, which was by then the toggle.
- **Fix:** while selecting, `onLongPress` is the toggle (long-press while selecting already toggled, on release).
- **Files modified:** `src/components/GridCard.tsx`, `src/components/grid-card-render.test.tsx`
- **Commit:** `97d01378`

**2. [Rule 1 - Bug] D-87 predictor overstated row heights**
- **Found during:** Task 4 device re-check (3a)
- **Issue:** Borders were added on top of `minHeight`; RN sizes border-box. The measurements were 52 dp More rows and 44 dp choices.
- **Fix:** borders count only when text sets the row height; the fit slack stays.
- **Files modified:** `src/components/bulk-sheet-fit.ts`, `src/components/bulk-sheet-fit.test.ts`
- **Commit:** `71c507d5`

**3. [Rule 2 - Correctness] More… keeps its rows and size while fading closed**
- **Found during:** Task 4 (D-87 implementation)
- **Issue:** with a content-sized sheet, a row removed by the chosen action (e.g. Remove from Favorites) would shrink the sheet mid-fade. This is the same class as B-WR-02 / B-WR-04 for Set Category.
- **Fix:** a snapshot of availability and count, taken while visible, drives the sheet's rows, title and size. The bar stays live.
- **Commit:** `6efefb72`

**4. [Rule 3 - Blocking] Sized sheets restructured for the sheet-consumer contract**
- **Issue:** `sheet-consumers-contract.test.ts` requires a literal or two-literal ternary `variant` so it can police nested scrolls.
- **Fix:** an expanded `<Sheet>` block with its own ScrollView, plus a compact/detail block, as OptionSheet does.
- **Commit:** `6efefb72`

**5. [Rule 2] More… row labels wrap inside the row (`flexShrink: 1`)** so a long label at large text cannot run past the sheet edge. The D-87 prediction counts the wrapped lines. `6efefb72`.

**6. Earlier (Tasks 1–2):** D-40's Bin-everyone step was blocked by the permission layer (owner B1). DB variants were built to reach checks the data set could not show. The tracer's one-device check prints 2 because both phones are attached, so every adb call passed `-s`.
