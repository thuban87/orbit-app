## 38.13-01: List-view measurement and owner checkpoint

**Summary.** A thorough measure-first plan. It protects the data set, keeps measurement builds in a separate directory under D-56, labels every figure with its thread, and ends at a blocking owner checkpoint. It has one design flaw: the B4 "memo" bisect will probably under-measure memoisation (see the plan 08 concern). Its results feed the owner's choice of fix direction.

**Strengths**
- Baseline pinned to `BASELINE_SHA`; builds come from a `git archive` copy in a separate build-host directory; `aapt2` evidence is kept (D-56, ADR-176).
- Data-loss guard: a WAL-aware copy of the phone's database is taken before overwrite, and on `INSTALL_FAILED_UPDATE_INCOMPATIBLE` the plan never uninstalls, it stops and asks.
- The checkpoint is never auto-approved. Option text carries no hidden assumption, and option-b names its plan cost (+1 plan).
- Perfetto host tools need owner approval before install.

**Concerns**
- **MEDIUM (Task 2, B4 bisect).** B4 is specified only as "memoised row host, stable renderItem and handlers, extraData for the maps" (01-PLAN:118).
  - Every read rebuilds each row's `line3` as a new object (`HomeScreen.tsx:922` `nextLine3ByContactId.set(row.id, { text… })`).
  - Every read also publishes a new seconds-granular `listNow` (`HomeScreen.tsx:820` `const now = localDateTime()`, `:935` `listNow: now`).
  - A memo patch that passes those props re-renders every mounted row on every publish. The publish follows every Population/Filter/Sort tap. That means the per-row native `updateGestureHandler` calls RESEARCH names as the latency mechanism still happen.
  - So B4 can understate what memoisation is worth, and FINDINGS could steer the owner toward F4 (re-implementing swipe) without need.
- **LOW.** The context cites "orchestrator ruling 5" (01-PLAN:66, :124). That ruling is not recorded in any phase artifact; RESEARCH Open Question 5 is the traceable source.

**Suggestions**
- In Task 2's B4 bullet, require scalar row props: `line3Text`/`line3Icon` in place of the `line3` object, and a day-granular key or a precomputed recency string in place of `now`. Have FINDINGS record whether row re-renders still happen per publish.
- Replace "orchestrator ruling 5" with "RESEARCH Open Question 5".

**Risk: MEDIUM.** The procedure is sound. The B4 measurement shape could mislead the fix-direction decision.
