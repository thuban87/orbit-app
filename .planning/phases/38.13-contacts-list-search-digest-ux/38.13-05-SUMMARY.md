# Phase 38.13 Plan 05: Contacts session reset, Back closes search, Reset scrolls to top, 38.9 empty states and real tucked-away buttons Summary

**A search term left over from an earlier mount can no longer silently filter Contacts. Android Back now closes an open search (after any open panel and after selection mode). Reset Dashboard View scrolls both the List and the Card grid back to the top. The filter and population empty states use the 38.9 EmptyState with plain glossary wording, and "Everyone's tucked away" has real "N Never Contacted →" and "N Unbound →" buttons.**

## Accomplishments

- **D-24:** HomeScreen's debounced search term now starts as `""` instead of the stored term. A mount-only effect clears the session search. It is declared before the debounce effect and before the focus read, and it is not inside a useState initialiser or an updater. Profile → Back still keeps the search, because Home stays mounted under a pushed Profile (D-21).
- **D-29:** `resolveHomeBack` is a pure priority function. HomeScreen's `hardwareBackPress` listener calls it with `shellTransientStore.getState().isAnyOpen()`, the selection mode and whether the search is open:
  - An open Population/Filters/Sort panel, the FAB dial or a picker: the listener returns false, so the root listener dismisses the transient.
  - Selection mode: exits selection.
  - An open search: `onToggleSearch()` closes and clears it, so `setSearchExpanded(` still appears exactly once.
  - Anything else: returns false.
- **D-31:** the dashboard session store now holds only `searchText`, `setSearchText` and `clearSession`. CardGrid gained an optional `listRef` prop. `resetDashboard` awaits `resetDashboardView` and `clearSession()`, then scrolls the List FlatList and the Card grid to offset 0 without animation. The view mode is unchanged: `resetDashboardView` keeps `viewMode` (checked in `dashboard-query-logic.ts:304-313`).
- **D-28 / D-30:** `dashboard-empty-copy.ts` supplies the copy, and HomeScreen renders the filter, Birthdays, Never Contacted and Snoozed branches through `EmptyState`, keeping their testIDs.
  - **Filter-empty:** "No contacts match these filters" / "Try fewer filters." with a **Clear filters** action, shown only while a filter is active. It calls `setFilters(getExecutor(), {})`; a failure shows an error snackbar with Retry. The "No favorites yet" onboarding copy is kept, with no action.
  - **Birthdays:** "No birthdays coming up" / "Birthdays shows people whose birthday is in the next 30 days." This matches the 0–30 day window in `dashboard-read.ts`.
  - **Never Contacted:** "Everyone's been contacted" / "Never Contacted shows people you haven't logged an interaction with yet."
  - **Snoozed:** "No one is snoozed" / "Snoozed shows people whose check-ins you've paused."
  - "Nothing here right now." and "Nothing in {label}." are gone.
- **D-65:** "Everyone's tucked away" keeps its heading and renders `tuckedAwayLines(counts)`:
  - **"N Never Contacted →"** is a tertiary Button. It calls `setPopulationsAndFilters(getExecutor(), ["not-contacted"], {})`, the Digest drill's save, with an error snackbar and Retry on failure.
  - **"N Unbound →"** is a tertiary Button that calls `navigation.navigate("UnboundContacts")`. Unbound did not appear in this state before.
  - The snoozed and Bin lines stay text.
  - New testIDs: `dashboard-empty-hidden-never-contacted` and `dashboard-empty-hidden-unbound`.

## Deferred / out of scope

1. **Informational (low): the empty population states have no action button.** The 38.9 EmptyState convention (D-20/D-71) gives every converted state "one action". This plan gave an action only to filter-empty, so empty Birthdays, Never Contacted and Snoozed show just an icon, heading and help line. A possible action would be "Show Active Contacts", which clears the population. That would need an owner wording call; I did not add it.
2. **Informational (low): the "Everyone's tucked away" state is not an EmptyState.** It keeps its own heading plus the lines and buttons, as the plan specifies, so it does not have the EmptyState icon disc. It sits left-aligned in the scrim, while the other empty states in the same scrim are centred. Worth a look in the plan-11 device pass.
