# Phase 38.13 Plan 04: Your Week day rows, re-tap close, steady period switch, weekday labels and Settings wording Summary

**Your Week day-detail rows now open the person's Profile or the group event. Re-tapping the selected day closes it. A period switch keeps the old week on screen until the new read lands, and a failed read of another period never leaves the stale week showing. The heatmap has weekday labels and a bold, underlined label for the selected day. Settings says plainly which days Your Week covers.**

## Accomplishments

- **D-46:** in DigestDayDetail, an interaction row with a contact and every group-event row are now `Pressable` buttons (role "button", same label and styles). They call `onOpenProfile(contactId)` and `onOpenEvent(id)`. A row whose contact is gone stays a plain View. The callbacks pass through YourWeekSection, DigestLoadedBody and DigestContent. DigestScreen navigates to `Profile` and `GroupEventDetail`, both registered in the Digest stack.
- **D-45:** `toggleYourWeekDay` returns `close` when the tapped day is already selected. `onSelectDay` then clears the selection and calls `clearDay()`, which retires any outstanding day read. Any other tap still selects the day and reads it.
- **D-49:** `onPeriodChange` no longer sets the loaded week to null, either when a switch starts or on rollback. The old heatmap and metrics stay until `loadPeriod` publishes the new week.
- **Retain on accept:** the reader's accept checks the selected day with `retainYourWeekDay` against the new window. A day tapped on the old heatmap mid-switch is cleared (and its day read retired) if it is not a real day in the new window. A day that is real in both windows stays, with its detail. The reader is now created below `clearDay`, so accept never reads a binding that is declared later.
- **Stale body:** `LoadedWeek` now records its `period`. When a read fails, `heldWeekSurvivesFailure` drops a held week that belongs to a different period, so the error body shows. A failed refresh of the period already shown keeps the week with the "Couldn't refresh Your Week" notice (B-WR-06 unchanged). `yourWeekPresentation` is unchanged.
- **D-47:** a weekday label row sits above the grid (`weekdayColumnLabels`, using the shared `WEEKDAY_SHORT`). It uses the fitted cell width and GAP, so cells are never resized (ADR-174) and is hidden from accessibility. The selected column's label is bold, with a 2dp textPrimary underline bar. The cell's 2dp border and `accessibilityState.selected` remain.
- **D-63:** the Settings > Interactions description now reads "Which days Your Week on the Digest covers." The period can still be set in both places, and the notification code was not touched.
