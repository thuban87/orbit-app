## Sampling Rate

- **Per task:** the task's own test files only, plus its cheap grep checks.
- **Per plan (its last task's verify):** `npx tsc --noEmit` plus every test file the plan touches, plus `npm run check:colors` where the plan touches UI.
- **Per wave:** full post-merge gate `npx tsc --noEmit && npm run check:colors && npx vitest run` (CONTEXT § Verification; memory note `tsc-in-post-merge-gate`).
- **Before `/gsd-verify-work`:** full suite, tsc and check:colors green; code review before the final device plan (memory note `code-review-before-device-pass`).
- **Max feedback latency:** ~300 seconds.
