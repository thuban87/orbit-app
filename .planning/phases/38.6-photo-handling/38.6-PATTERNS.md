### `src/services/photos/master-encode.ts` (service, transform) — NEW

**Analog:** `src/services/photos/photo-pipeline.ts` (crop path) and `src/services/import/import-photo.ts` (lazy-import, no-crop path).


Replace them with exported `MASTER_MAX_EDGE = 1024` and `MASTER_QUALITY` (must be < 1, because `compress` 1.0 gives lossless WebP).

Chainable manipulator call (photo-pipeline.ts:91-106). Keep the error wrap:
```ts
const rendered = await ImageManipulator.manipulate(rawUri)
  .crop(cropRect)
  .resize({ width: MASTER_SIZE, height: MASTER_SIZE })
  .renderAsync();
out = await rendered.saveAsync({ format: SaveFormat.JPEG, compress: MASTER_COMPRESS });
} catch (error) {
  Logger.error(LOG_SCOPE, `manipulate/encode failed for ${rawUri}`, error);

}
```
Lazy-import variant for node-testable services (import-photo.ts:34-46):
```ts
const { ImageManipulator, SaveFormat } = (await import(
  "expo-image-manipulator"
)) as typeof ExpoImageManipulator;
```
The three callers then drop their local constants: photo-pipeline.ts:41,44; import-photo.ts:16-17; reconcile-photo.ts:12-13 and 59-72. Keep each caller's `fs.resizeToMaster` injection seam (import-photo.ts:22, reconcile-photo.ts:19) and have it delegate to `encodeMaster`. `SaveFormat.WEBP` replaces `SaveFormat.JPEG`. Storage names stay `.jpg` (RESEARCH F-1/F-2, 38.2 D-09).

**Test:** existing mocks, e.g. `import-photo.test.ts:6` `SaveFormat: { JPEG: "jpeg" }`, must gain `WEBP`. The `:74` "512px master" assertion is an orphaned consumer, so update it in the same plan.
