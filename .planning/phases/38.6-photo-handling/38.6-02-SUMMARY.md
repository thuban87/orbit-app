## Accomplishments

- `YOUR_WEEK_DAY_SQL` returns `contactPhoto`: `c.photo` in the interaction arm, `NULL` in the group-event arm (same position, so the UNION stays column-aligned). Bind count is still 6. The legacy parity oracle carries the same column, and the EXPLAIN proof still shows index use. `DigestDayDetail` passes it to `Avatar`. This fixes the owner's named example.
- `listEligiblePendingAssists` returns `contact_photo`. `PendingConfirmationsSheet` renders a 40px `Avatar` beside each question: row layout, question `flex: 1`, no colour literal.
- `CandidateItem.photo` / `PhotoChoiceOption.photo` carry the canonical relative path through `Avatar`. `ReconcileGridScreen` and `MergeConflictsScreen` pass it and no longer import `resolvePhotoUri` (this clears the way for 38.6-03's screen ban). `DuplicateReviewScreen` and `ReconcileDetailScreen` still use their staging URIs.
- `PhotoChoice`'s staging `Image` uses `cachePolicy="none"`, because the reconcile staging path is reused across scans.
- `38.6-PHOTO-COVERAGE.md` covers:
