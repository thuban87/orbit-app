<objective>
Deliver the core capability: pick a contact photo from the library, frame it in the in-app Skia crop, and see it saved and rendered.

Phase Goal (user story): **As a** user, **I want to** set a contact's photo from my library and frame their face **so that** the person I'm reaching out to is instantly recognisable.

This is the first fully-wired photo slice. `PhotoSourcePicker` is the edit-only affordance (Add/Change/Remove) that launches the Android 13+ system Photo Picker via `launchImageLibraryAsync({mediaTypes:['images']})` — no camera, no runtime permission — and, on a pick, navigates to `CropPhotoScreen` with the raw cache URI and a serializable target descriptor. `CropPhotoScreen` is the repo's first Skia render-loop surface: pan + pinch over a fixed 1:1 viewport, transform driven ONLY by Reanimated shared values read into Skia via `useDerivedValue` (never `setState` per frame — CLAUDE.md), all draws tokenised. "Use photo" computes the source-pixel rect (Plan 04 geometry), runs the Plan 04 pipeline, then writes the target DAO (contact → `setContactPhoto`, profile → `setProfilePhoto`) and pops back so the avatar refreshes on focus. "Remove photo" clears the DB and deletes the old file inline.

Purpose: PHOTO-01 (library pick + Skia crop) + the replace/remove half of PHOTO-05.
Output: `CropPhotoScreen.tsx`, `PhotoSourcePicker.tsx`, the `CropPhoto` route, and the photo section in `EditContactScreen`.
</objective>
