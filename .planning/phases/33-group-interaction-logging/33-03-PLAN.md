<objective>
Implement live inheritance: the pure `group-inheritance.ts` resolver (which children follow which field; how to render inherit-vs-override) and the shared-value / event-date edit fan-outs on `group-events-dao.ts`. Editing a shared Channel/Tone/Duration rewrites only children still following that field; editing the event date rewrites every child's `occurred_at` (date is non-overridable); overriding sets the follow flag off; "Follow event …" sets it back on and re-resolves from the current event value. All fan-outs are one atomic transaction composing the recency `*Core` primitives (D-05, D-08) — each child edited through `editTouchpointFullCore`, the non-mutexed core extracted in Plan 01, never the mutexed `editTouchpointFull` whose nested `inWriteTransaction` would hang permanently (transaction.ts non-reentrancy).

Purpose: GRP-03 (shared values, live inheritance), GRP-04 (per-field override + "Follow event …" clear), and the atomic/future-safe fan-out portion of GRP-11/GRP-12.
Output: `resolveDisplay`, `computeFollowingChildren`; DAO `updateGroupEventShared`, `updateGroupEventDate`, `setParticipantOverride`, `clearParticipantOverride`.

Phase tracer note: the end-to-end data-spine tracer is in Plan 01; this plan expands the DAO with the inheritance fan-out on top of the proven `createGroupEvent`/recency spine.
</objective>
