## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| form input (title, note, date) → DAO | user free-text + dates cross into persistence |
| destructive participant/lifecycle actions → data loss | remove/delete are irreversible child deletions |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-33-17 | Tampering | future/invalid date submitted from the form | medium | mitigate | createGroupEvent/updateGroupEventDate reject future (locked copy); date non-overridable |
| T-33-18 | Repudiation / data loss | accidental permanent child delete via remove | medium | mitigate | Three-option Sheet with explicit destructive labelling; "Keep as individual" is the non-destructive default path |
| T-33-19 | Information Disclosure | Group Note surfaced as a participant note on detach | medium | mitigate | detachParticipant never copies group_note (enforced in Plan 05; UI shows Group Note only in group context) |
| T-33-20 | Tampering / integrity | optimistic UI shows success on a rolled-back save | high | mitigate | Never mark success unless the write committed; error copy + form preserved on failure (GRP-11) |
</threat_model>
