  a plugin-era DTO shape. **Phase 2's data layer is "derived-never-stored"** — status and day-counts
  are computed at query time, never persisted as columns. These fields are fine as a transient
  in-memory DTO now; Phase 2 must NOT inherit them as a SQLite row type.

stays behaviour/type-faithful; the labelling lives here and in the SUMMARY.
