    temp dir and move the generated files in. Steps: (1) run
    `npx create-expo-app@latest /tmp/orbit-scaffold --template blank-typescript` (blank-typescript,
    NOT the default router template — a single home shell needs no expo-router; this decision is
    recorded in SKELETON.md). (2) Copy the generated files into the repo root, preserving every
    existing file — copy `package.json`, `App.tsx`, `babel.config.js`, `metro.config.js` (if

    Verify the template resolved Expo SDK 57 — run `node -e "console.log(require('./package.json').dependencies.expo)"`;
    if it is not `^57`/`57.x`, run `npx expo install expo@^57` to pin it. (4) Install the pinned
    native stack via `npx expo install expo-sqlite expo-status-bar react-native-safe-area-context @react-native-async-storage/async-storage`
    (expo install resolves the SDK-57-correct RN 0.86 pin — NEVER bare `npm install` a native pkg,
    it pulls RN 0.87 and breaks the pin). (5) Install pure-JS + dev deps:
    `npm install zustand` then `npm install -D @biomejs/biome@2.5.8 vitest`. (6) Set `babel.config.js`
    to `presets: ["babel-preset-expo"]` only — do NOT add the reanimated plugin (that is a Phase 13
    dep). (7) Extend `.gitignore` by APPENDING Expo/native ignores (`/android`, `/ios`, `*.jks`,
    `*.keystore`, `.expo/`, `dist/`, `web-build/`) — append only, keep the existing graphify and
    settings.local.json entries intact.
  </action>
  <verify>
    <automated>test -f package.json && node -e "const p=require('./package.json'); const d={...p.dependencies,...p.devDependencies}; for (const k of ['expo','expo-sqlite','zustand','@biomejs/biome','vitest','@react-native-async-storage/async-storage']) { if(!d[k]) { console.error('MISSING '+k); process.exit(1);} } console.log('deps ok', d.expo)"</automated>
  </verify>
