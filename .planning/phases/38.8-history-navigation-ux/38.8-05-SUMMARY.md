# Phase 38.8 Plan 05: Heatmap Lens Items (Cycles paging, no-cadence Month fallback, full lens labels) Summary

**The Cycles lens now pages back and forward by whole preset-sized pages with Intensity following. A contact with no cadence shows Month with a short note instead of the persisted Cycles lens, and never writes the global lens through Cycles. The History lens row uses a new opt-in compact SegmentedControl density so the four labels can read in full.**

## Accomplishments

- **Cycles paging (D-25, D-26).** `pagedCycles` builds the displayed page as the unchanged `cycles()` series ending at `refDate`. `cyclesPrevRef` steps to the day before the page's first block. `cyclesNextRef` steps forward one page, clamped at today. `historyDayAfterCyclesNext` follows today again only when the page ends today. Only the page ending today flags a current cycle. `services/history/cycles.ts` is unchanged.
- **Rollover (D-04).** A past Cycles page stays put on a new local day. The first next after a one-day rollover lands on the old today (not following). The second lands on the new today and follows. Both refs are pinned exactly in tests.
- **Heatmap row.** For available cycles the nav row now renders. Its title is the page span ("Jan 1 – May 10"), its buttons read "Previous cycles" / "Next cycles", and next is disabled on the page ending today. Unavailable cycles have no nav row and keep the existing caption.
- **Preset change (D-26).** A preset change returns to the current page. It still clears the note and drops a pending jump scroll (D-55, C3-05).
- **No-cadence fallback (D-27, D-66, D-67).**
  - `resolveEffectiveLens` derives the lens History shows. `lensTapIntent` decides every tap.
  - Persisted Cycles with no cadence shows Month plus the note. Tapping the shown Month there is a no-op that keeps the page.
  - Any Cycles tap on a no-cadence contact shows the existing "Cycles need a set frequency for this contact." explanation and writes nothing.
  - Leaving the explanation for the persisted lens, or for Month when Cycles is persisted, writes nothing and returns to the current page.
  - 7 Days and Year taps still persist.
  - With a cadence every tap persists and resets the page, including a re-tap of the shown segment (C4-02).
- **Full lens labels (D-24).** `SegmentedControl` has a new `density` prop. `"regular"` is the default and is unchanged. `"compact"` applies the top-of-file `COMPACT_SEGMENT` tunables. Only the History lens row passes `density="compact"`. The preset row, Home, AI Personalization and Your Week call sites are untouched.
- **Folded-in fix (orchestrator).** Reworded the `HeatmapCellTarget` comment, which still said it opens the deleted context card. It now says taps jump to the stream and that `count` never decides emptiness (D-21). The ActivityHeatmap header comment was also brought current.

2. Intensity on the Cycles lens follows the paged span, through the existing `spanWindow` over the displayed blocks.
3. A paged-back Cycles view stops following today. A past page stays put on a new local day.
4. Changing the 5/10/15/20 preset returns to the current page and clears the empty-target note.
5. Changing the lens, including a re-tap of the shown segment, returns to the current page as before.
6. A contact with no cadence (tracking off or no interval) whose persisted lens is Cycles shows Month, with "Showing Month: this contact has no set frequency, so Cycles aren't available." under the lens row. Nothing is written to the global `history_lens`.

   - tapping the shown Month does nothing;
   - tapping Cycles shows "Cycles need a set frequency for this contact." with no write, whatever lens is persisted (D-67);
   - tapping Month from that explanation (persisted Cycles) returns to the fallback with no write (D-66);
   - tapping the persisted non-Cycles lens from the explanation returns to it with no write;
   - tapping 7 Days or Year persists as usual.
8. The History lens row is denser (gap 6, padding 4, font 16). Every other segmented control is unchanged.

## Surface to owner now (out of scope, plain language)

1. **Cycles titles have no year.** The Cycles page title uses month + day only, as the plan specified (for example "Mar 1 – Oct 22"). The cycle cells' spoken labels are the same. With 20 cycles of 30 days, one page covers more than a year, so a paged-back title can be ambiguous about which year it is. The 7 Days title has the same habit at year boundaries. *Recommendation:* add the year to the Cycles title when the span is not wholly in the current year (for example "Mar 1, 2024 – Oct 22, 2025"). It is a one-line change in `windowTitle`, and the label wording is your call. Otherwise leave it as is.
2. **A stale comment I couldn't touch.** The header comment in `src/services/history/cycles.ts` says callers fall back to the 7 Days lens when there is no cadence. It is now Month (D-27). That file is off-limits in this plan (D-09). *Recommendation:* fix the comment during Plan 06's docs update. It is comment-only.
3. **Presets show under the Cycles explanation (unchanged behaviour).** When a no-cadence contact shows the "Cycles need a set frequency" explanation, the 5/10/15/20 preset row still shows, and tapping it changes the global preset. This was already the case before this plan, and D-27 only covers the lens. *Recommendation:* leave it. The tap is an explicit choice of the preset, which applies to all contacts anyway.
