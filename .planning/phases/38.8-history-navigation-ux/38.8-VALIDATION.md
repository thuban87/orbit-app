## Sampling Rate (owner lean policy)

- **After every task commit:** run the quick command, limited to the area the task touched.
- **At the end of every plan:** run the full suite command, then a debug-build smoke on the 6 Pro: install, use the plan's feature once, no crash. No DEBUG perf runs.
- **Before the final device plan:** run the phase code review, then its fixes.
- **Phase gate:** a fresh agent runs the device pass on the 6 Pro. It includes the long-history measurement on the release build, then a 3a smoke at the end, then the owner's look-and-feel sign-off (D-30).
- **Max feedback latency:** ~120 seconds
