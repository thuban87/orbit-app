## Pattern Assignments

### `history-stream-logic.ts` (pure utility, transform)

**Analog:** `src/components/history/history-section-logic.ts`

- Export-only pure functions plus small state types and reducers named `xOnY`. See the read-state reducers `:123-165` (`initialHistoryReadState`, `historyReadStateOnStart/OnFail/OnPublish`) and the day state `:173-230` (`initialHistoryDayState`, `advanceHistoryDay`, `historyDayAfterPrev/Next`).
- There is no React import and no DB import. That is what lets it run under node vitest; HistorySection.tsx cannot load there.
- Mirror this for `buildStreamModel`, a `streamState` reducer (`initialStreamState`, `streamStateOnToggleYear`, `streamStateOnShowOlder`, `streamStateOnReveal`), `resolveHeatmapTarget`, `resolveMonthJump`, `nearestDays` (used by D-65 jumps), and `pickerModel`.
- Ordering: timestamp desc, then family rank, then id desc. Key records as `` `${family}-${id}` `` (RESEARCH Pattern 1).
- Local-date rule: `new Date(y, m-1, d)` from parts, as `src/services/history/window.ts:74-77` does. Never `new Date("YYYY-MM-DD")`.

### `history-stream-logic.test.ts`

**Analog:** `history-section-logic.test.ts:1-25`. It opens with a docblock that lists each function under test, then `import { describe, expect, it } from "vitest";` and named imports from `./history-section-logic`. It needs no mocks.

### `HistoryStream.tsx` (presentational)

**Analog:** `ActivityHeatmap.tsx`. It is props-in/callbacks-out, uses `StyleSheet.create`, takes colours from `useTheme()`, uses `testID` suffix conventions such as `` `${testID}-prev` ``, and prefers no local state so that the render test can call it as a function. The stream must render as plain Views (no nested ScrollView/FlatList). The target DayGroup reports via `onLayout`, and the parent measures it with `measureLayout(anchorRef, …)` (RESEARCH Pattern 3).

## Shared Patterns

- **Theme:** inside the section, `useTheme()` is called per row component. Sheet hosts call `useUnscopedTheme()` above `<Sheet>`. No literal colours (`check:colors`).
- **Dates/times:** `formatTimeMinuteOrFallback` and `formatDateTimeMinuteOrFallback` from `@/utils/dates`. `formatLocalDate`. Use `HistoryDayState.today` instead of `new Date()` in render.
- **Biome a11y header:** `// biome-ignore-all lint/a11y/useValidAriaRole: Orbit's Button/AppText \`role\` is a domain prop, not ARIA.` (`HistorySection.tsx:1`) on any new `.tsx` that uses `role`.
- **Comments cite ADRs 119/120/122/152/165/174 and "38.8 D-NN".** Never cite ADR-121 as governing.
- **Reads:** keep `createLatestRequestAuthority` and `historyReadStateOnStart` (no loading flash over loaded data).
- **Same-plan deletion rule:** removing `DateDetailSheet.tsx`/`HeatmapContextCard.tsx` must update the three readFileSync contract tests and the `biome.json` override list (`:30-58`) in that same plan.
