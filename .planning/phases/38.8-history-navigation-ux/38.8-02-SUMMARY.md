# Phase 38.8 Plan 02: History Stream Summary

**The Profile History section now shows the contact's records straight away: newest first, grouped year → month → day, below Intensity. The current year is open, older years are collapsed rows with interaction counts, and long years page with Show older without splitting a day. The Rolodex is archived in `docs/archive/history-rolodex/`, excluded from every tool, and the section is titled "History".**

## Accomplishments

- **`history-stream-logic.ts`** (pure, no React or DB). It orders all three families by timestamp desc, then interaction / lifecycle / knowledge, then id desc, with `${family}-${id}` keys. It builds years newest first; the current year is always present and empty when it has none. Year counts include interaction rows only. It also builds an all-family `dayIndex`/`days` for Plans 03/04. The view state (`openYears`, `shown`) is transient. Show older adds 20 to the visible count after day snapping. The two tunables sit at the top of the file.
- **`HistoryStreamRows.tsx`**. This is the sheet's row code, copied, with these deltas:
  - a two-line note;
  - a title-case direction ("Outbound · Great");
  - a group-event label inside the same single Pressable, also added to the accessible label;
  - no duration, sparkle or long-press;
  - a muted, read-only lifecycle row;
  - the knowledge row opens MemoryHistory.

  Every time and row label goes through `formatTimeMinuteOrFallback`. The stale "dormant until Phase 33" wording is gone.
- **`HistoryStream.tsx`**. It is presentational and built from plain Views:
  - an open year gets a year header, month headers, then day groups with a hairline divider, the day label on its own line and the rows indented beneath;
  - a collapsed year is one full-width "▸ 2025 · 34 interactions" button (`expanded: false`);
  - a tertiary "Show older" button appears only while older records remain.
- **`HistorySection.tsx`**. The Rolodex mount and import are removed. Two new hooks are added: the stream model (`useMemo`) and the view state (`useState`). Both sit above the error, loading and empty early returns. The stream renders right after `IntensityChart`. Expand and Show older update only the transient state. A row tap opens the existing InteractionDetail; a knowledge row uses the existing `onOpenKnowledgeChange`. The card, sheet, InteractionDetail, group-scope and conversion wiring are unchanged.
- **Archive (D-12/D-13).** The four Rolodex files were moved with `git mv` (history kept) into `docs/archive/history-rolodex/`, with a README. The tool exclusions:
  - `tsconfig.json` `exclude` re-lists Expo's six base entries plus `docs/archive`;
  - `biome.json` has `"!docs/archive"`, and the two stale Rolodex override paths are gone;
  - `.graphifyignore` lists `docs/archive/`.
- **Rename (D-60).** The `interaction-history` label is now "History", and the test expects "Expand History". The id and every persisted key are unchanged.

## Behaviour changes for the Plan 06 docs update (`docs/systems/interaction-history.md`, `docs/systems/profile.md`)

1. The Profile History section now reads, from the top:
   - the lens row and heatmap;
   - the context card (still the cell → card → See details sheet flow until Plan 03);
   - Intensity;
   - the **History stream**.

   The Rolodex wheels and drawer are gone, so the drawer → sheet path no longer exists.
2. The stream:
   - shows records newest first, grouped year header → month header ("October") → day label ("Today", "Yesterday", "Fri Oct 2");
   - renders only dates that have records, with no counts on days;
   - gives day labels an accessible full date with the year;
   - shows each day's records indented under its label, with a thin divider between days;
   - has no cards, no gap markers and nothing sticky.
3. Year handling:
   - only the current calendar year is open;
   - each older year that has any record (any family) is a collapsed row reading "<year> · <n> interaction(s)", counting interaction rows only, and a tap expands it;
   - a current year with no records shows "Nothing logged in <year> yet" above the collapsed years.
4. An open year shows its newest 20 records, extended to the end of that day. "Show older" adds 20 more, also day-snapped, and disappears when the year is fully shown. The tunables are `STREAM_INITIAL_VISIBLE` and `STREAM_CHUNK` in `history-stream-logic.ts`.
5. Equal timestamps sort deterministically: interaction, then lifecycle, then knowledge, then id descending.
6. Rows:
   - **Interaction:** the channel icon and label, the minute time, a title-case direction / No reply / quality line and up to two lines of note. A group-linked child also shows its group-event title in a small outlined label. The whole row opens InteractionDetail, and there is no long-press, sparkle or duration.
   - **Lifecycle:** muted and read-only, with the `EVENT_LABELS` label, the time and the detail.
   - **Knowledge:** the pencil icon, field name, time and a one-line value. It opens MemoryHistory.
7. Open years and Show older state are fresh on each Profile visit (each HistorySection mount). They survive revision re-reads while mounted and are never persisted.
8. The section title is now "History" on the Profile and in the layout editor. The id `interaction-history` and saved layouts and collapse state are unchanged.
9. The Rolodex code is archived in `docs/archive/history-rolodex/` and excluded from tsc, vitest, Biome and graphify. The `markerInteraction`/`markerLifecycle` tokens are kept.
