## Pattern Assignments

### `src/stores/confirm-store.ts` (store, event-driven)

**Analog:** `src/stores/snackbar-store.ts` (51 lines): a module-level Zustand store plus a free function exported for non-React callers. This shape matters because confirm callers include services (`services/reach-out/handoff.ts`) and hooks (RESEARCH Responsibility Map).

**Store + exported free-function pattern** (snackbar-store.ts:25-51):
```ts
interface SnackbarStore {
  snackbar: SnackbarMessage | null;
  show: (message: SnackbarMessage) => void;
  dismiss: () => void;
}
/** Shell-level transient feedback; intentionally in-memory and non-persisted. */
export const snackbarStore = create<SnackbarStore>()((set) => ({ ... }));

export const showSnackbar = (message: SnackbarMessage) =>
  snackbarStore.getState().show(message);
```
**What to copy:** `create<T>()((set, get) => …)`, then `export const confirm = (req) => new Promise<boolean>((resolve) => confirmStore.getState().enqueue({ id: nextId++, kind: "confirm", req, resolve }))`. Use a FIFO `queue` with `current = queue[0]`. A `resolveCurrent(value)` action shifts the queue.
**Constraints:** `dismissable` defaults to `!destructive` (D-06, ADR-086). It can be set to `false` explicitly where Cancel has a side effect (RESEARCH Pitfall 1: `BackupScreen.tsx:246`). There is also a `notice()` variant (D-27).
**Test analog:** `src/stores/shell-transient-store.test.ts:1-40`. Reset state in `beforeEach` (`store.setState({ … })`), then drive the store through `getState()`.
