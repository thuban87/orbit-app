# Phase 38.9 Plan 10: Shared header on the last 20 Settings-stack screens; single-Back contract final Summary

**The last 20 pushed screens now use the house header: Backup settings, Custom Fields, the import and restore flows, the five AI screens, Update from Contacts, the System builder, and the four flow endpoints. With the field editor open, Custom Fields still has the header. The System builder's Back now steps back inside the builder first (Preview to editing, Members to Definition) and only leaves from the Definition page, where it reads Cancel. 1. **Back from Import complete returns to the import setup screen.** Import complete replaces Import progress, so the screen below it is Import contacts setup (or Review import / Review matches), for an import that has already finished. The system Back already did this before this plan. Now there is also a visible Back button that does it. Recommendation: check it on the phone in Plan 17. If landing on the finished setup screen is confusing, make Import complete's header Back do the same as Done (one `onBack` line). Check complete has the same shape, so the same check applies.
2. **The Back control no longer looks disabled while a restore applies.** Restore preview's old in-body Back was dimmed and disabled during the apply. The header Back looks normal, but pressing it does nothing because the existing `beforeRemove` hold blocks it. Recommendation: accept this. The same is true of Import progress, which also shows its "Still importing" notice. If you want a visible hint, it would be a small ShellAppBar option, worth a separate decision.
3. **Look of the System builder Preview header over the canvas.** The Preview header uses the normal chrome scrim. A save error shows in a small glass box under it. Recommendation: include it in the Plan 17 screenshots.
