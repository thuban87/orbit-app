Q-18

Dialog look

D-27 themed dialogs replace Android Alerts

Every confirm, destructive confirm and one-button notice uses this card. The layout rules are already decided (ADR-174: one row when both buttons fit, otherwise stacked with Cancel first; destructive cannot be dismissed by tapping outside). The only question is how the card is drawn.

DLG-AToday's dialog: elevated card, hairline border.
DLG-BRecommendedSame card with a stronger border, matching Phase 39's lesson cards (39 D-80), so dialogs and lessons look like one family.

Already decided, shown for reference (no answer needed)

Q-19

Back button on the shared header

D-16 one header on every pushed screen

About 25 screens with their own boxed or in-page Back move onto the shared header. Today that header shows the word “Back” (16 screens). The Profile alone uses a chevron. Phase 39's mockup frames draw the word “Back”.

BK-ARecommendedWord “Back”, as on the shared header today. Fewest changes, and it matches Phase 39's frames.
BK-BChevron only, like the Profile today. The most compact; still read as “Back” by TalkBack.
BK-CChevron plus “Back”. The most explicit, and the widest.

Whichever wins, the Profile keeps its own top bar layout; 38.11 decides whether its glyph changes to match.

E-10 · F-08

Q-22

Switches

E-22 · K-29 · D-25 one shared switch

Each option shows on, off and disabled (disabled rows are dimmed and always show Off, per D-26). All 30 switches change together.

SW-AToday. In dark themes an off switch nearly disappears.
SW-BSame Android switch with stronger colours: the off track and thumb are clearly visible.
SW-CRecommendedOrbit's own switch: off is an outlined track with a small thumb; on is filled with a large thumb and a check. On and off differ by shape as well as colour.
Q-23

How dates read

C-06 · D-21 · D-23 one date formatter

One format for every date-only display. The examples assume today is Sat, Oct 10, 2026.

DT-0Today: raw stored dates in several places.
DT-ARecommendedHistory's existing style: no year when it's this year, year shown otherwise.
DT-BAlways show the year.

Weekday only where the day matters (upcoming items). Time only where it matters (events, interaction detail), as today. Storage dates are unaffected.
