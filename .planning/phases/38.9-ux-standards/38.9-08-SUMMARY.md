# Phase 38.9 Plan 08: House header — chevron Back, onBack, person line, all-stack single-Back contract Summary

**The shared child header now shows an icon-only chevron Back (or a close-glyph Cancel). It takes an `onBack` override that runs after open sheets and menus close, and a person line (avatar and name) that the chrome scrim backs over art. Update Contact, Log Interaction, Memory and the Add Note sheet now name the person. A source contract covers every pushed screen in all five tab stacks, with a pinned list of the 36 screens Plans 09 and 10 convert.**

## Performance

- **Duration:** about 25 min
- **Completed:** 2026-10-11T10:05Z
- **Tasks:** 3
- **Files modified:** 11 (4 created)

## Accomplishments
- D-44: the child Back is `<Icon name="back" />` (or `<Icon name="close" />` with label "Cancel" when `backKind="cancel"`). It keeps the 44dp target and hitSlop 8, and is wrapped in `GlassForegroundScope` when the scrim is scoped.
- D-16: `onBack?: () => void`. The handler still dismisses the top shell transient first, then calls the override if given, otherwise `navigation.goBack()`.
- D-45 / C5-M6: the header is now an outer column. The chrome scrim (absolute fill) and the bottom hairline moved from the row to that column, so they back the title row and the person line together. PersonLine is glass-scoped under the scoped branch. There is still exactly one `useArtTreatment(artComponent)` call, and the row's `onLayout` still feeds the compact math unchanged.
- `useContactHeader` reads `getContactHeader` locally, with a cancelled flag and a content-free log message (T-38.9-21).
- D-07: the contract reads the five stacks RootNavigator mounts (59 files, 54 pushed), excludes the five tab roots, and sorts every pushed screen into one of three groups: converted (16: child header, no in-body Back), KEEP_OWN_CHROME (Profile ADR-109, Capture S11), or PENDING_HEADER_CONVERSION (36 entries, each pinned to `in-body-back` or `header-less`). The categories were confirmed with the extended detector before committing; they match the plan's list (8 header-less). The 7 Settings children assertions are kept.
