## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Sheet scrim taps were swallowed**
- **Found during:** Task 2, while checking the Add Note sheet's scrim prompt
- **Issue:** BaseOverlay's full-height content frame (Sheets pass `flex: 1`) sat above the scrim as a touch target. Tapping outside any sheet did nothing, so dirty sheets could not show their scrim prompt.
- **Fix:** `pointerEvents="box-none"` on the frame, plus a contract test
- **Files modified:** `src/components/ui/overlay-base.tsx`, `src/components/ui/overlay-base.contract.test.ts`
- **Commit:** `fc962ca2`

**2. [Rule 1 - Bug] Digest birthday tag missing the weekday**
- **Found during:** Task 2 mockup match (DT-A draws "Tue, Oct 13")
- **Fix:** `formatDisplayDate(occurrence, { now: today, weekday: true })`; tests updated
- **Files modified:** `src/logic/digest-composition.ts`, `src/logic/digest-composition.test.ts`
- **Commit:** `6c85c7f4`
