## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Starfield dark: the checker's channel-wise text-bearing bound failed the TS card/chrome proof**
- **Found during:** Task 1
- **Issue:** The plan says to declare the checker's `textBearingBound`. For Starfield dark that bound is brightest `#2C2868`, a channel-wise synthetic colour (L = 0.0305). It is brighter than any real text-bearing pixel. Over it, the card and chrome proofs give `textSecondary` 4.36:1 < 4.5. The per-pixel checker passes the same file: `textSecondary` fails only on 0.170% of the canvas, which equals the allowed star union.
- **Fix:** The file has no pixel between its brightest non-star pixel (`#222544`, L = 0.0208) and its dimmest star (L ≥ 0.064). The declared brightest is now `#262452` (L = 0.0228), inside that empty band. `--check` gives the same signed union as `#2C2868`: 2,680 px, 0.170%, largest 9 px. So the same pixels count as text-bearing, and no star is re-admitted. No art, opacity, allowance or proof changed.
- **Files modified:** `src/theme/backgrounds.ts` (with a comment at the declaration)
- **Commit:** `da05a93`

**2. [Rule 1 - Bug] Starfield light: same issue at the dark end**
- **Found during:** Task 3 (the new bare proof)
- **Issue:** The checker's darkest bound `#CED9DC` (L = 0.679) gave bare `accentText` coral 4.37:1 at the presentation veil. The checker passes the file per pixel: coral fails only on the 446-px allowed union.
- **Fix:** The file has no pixel between L 0.3 and L 0.740 (the darkest non-star pixel is `#D6E0F2`). The declared darkest is now `#D3DDE0` (L = 0.709). `--check` gives the same union: 446 px, 0.028%, largest 13 px. Bounds brighter than about L 0.72 start admitting background pixels and fail `--check`, so the chosen bound keeps a margin.
- **Files modified:** `src/theme/backgrounds.ts`
- **Commit:** `39f39e9`

**3. [Rule 1 - Bug] Extrema self-test assumed no real variant has an allowance**
