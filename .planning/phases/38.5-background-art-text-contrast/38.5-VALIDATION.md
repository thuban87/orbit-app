## Sampling Rate

- **After every task commit:** quick run command + `npm run -s check:colors` on touched `src` files; `measure-background-extrema.py --check` whenever an asset or `src/theme/backgrounds.ts` changes.
- **After every plan wave:** full suite command + all asset checks.
- **Before `/gsd-verify-work`:** full suite green; H1/H2 on every shipped WebP; D-24 report and D-25 red-string report delivered; code review before the device pass; device rows done.
- **Max feedback latency:** 90 seconds
