# Phase 38.3 Plan 13: Profile History Reveal and Selector Retry Settlement Summary

**The Last Interaction tile and Status → View history now close the sheet, expand a collapsed History through the persisted collapse toggle, and scroll the Profile to the History section. The scroll is instant under reduced motion and there is no route. When the layout hides History, neither action exists. Frequency and Snooze Retry now settle only the selector that failed, through one shared runner.**

- **RG-021 / D-10, D-28 (Task 1, tracer):** `ProfileModuleHost.revealHistory()` closes the relationship sheet. ## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Scroll deferred to the expanded History layout for an expanding reveal**
- **Found during:** Task 1
- **Issue:** The plan scrolls to `hostY + historyY` right after starting the expand toggle, on the grounds that the header's y does not move. A React Native ScrollView clamps `scrollTo` to the current content height, though. History is last in the factory layout, so a collapsed History near the end of the Profile would land at the bottom of the viewport with its newly-mounted body off-screen. That fails D-10's "the Profile scrolls to it".
- **Fix:** Added the pure `createHistoryRevealScroll` controller to `module-host-model.ts`. It scrolls at once when no expand is needed. For an expanding reveal it waits for the first History `onLayout` rendered with History expanded, or scrolls immediately if the expand write fails. `toggle` now resolves to its committed readback (or `null`) so the reveal can settle.
- **Files modified:** `src/profile/module-host-model.ts`, `src/components/profile/ProfileModuleHost.tsx` (+ tests)
- **Commit:** `52a3e9c`

**2. [Rule 3 - Blocking] Optional `onOpenHistory` prop types moved forward into Task 1**
- **Found during:** Task 1
- **Issue:** Task 1 passes `undefined` for the History action when History is hidden. `RelationshipOverview` and `ProfileRelationshipSheets` still required the prop, so Task 1's `tsc` gate could not pass.
- **Fix:** Task 1 made only the prop types optional. Task 2 then implemented the D-11 behaviour: the informational tile and `historyAvailable`.
- **Commit:** `52a3e9c`

**3. [Rule 2 - Test coverage] Added `relationship-overview-render.test.tsx`**
- **Found during:** Task 2
- **Issue:** The plan's behaviour list covered only the model. Nothing asserted that the Last Interaction tile loses its button role and `onPress`.
- **Fix:** Added a node render test using the host test's hook/primitive mocking pattern.
- **Commit:** `d8efeaa`
