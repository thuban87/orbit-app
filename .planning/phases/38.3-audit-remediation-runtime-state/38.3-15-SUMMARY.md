# Phase 38.3 Plan 15: Truthful Your Week Day Detail Summary

**The selected day's detail now has explicit `idle | loading | loaded | error` states. "No activity on this date." shows only after a read succeeds and returns nothing.** Each tap, Retry, or refresh that keeps the selected day starts a new request with its own token. An older read can never publish over a newer one, even for the same date. This closes Phase 38 review WR-01 (D-16).

## Accomplishments

- **`your-week-section-logic.ts`** adds the `YourWeekDayDetail` union and four pure functions:
  - `startDayRead` always moves to `loading{date, token}`.
  - `settleDayRead` and `failDayRead` change state only when it is `loading` and the token matches.
  - `clearDayDetail` returns `idle`.
- **`YourWeekSection`** replaces the `dayRows` array with a `YourWeekDayDetail` state and a ref mirror. It also adds a `createLatestRequestAuthority` for day reads.
  - `loadDay(date)` runs in this order: `begin()`, `startDayRead`, `await applyUatFault("digest-day-read")`, `readYourWeekDay`, then `settleDayRead`. On a failure it runs `failDayRead` and logs a content-free `Logger.error`.
  - Every publish is gated on `isCurrent(token)`.
  - Heatmap selection, the detail's Retry, and Plan 14's retained-day refresh all call `loadDay`.
  - A period change, a rollback, or a day that falls outside the new window calls `clearDay`. That invalidates the authority and sets the state to `idle`.
  - The date-only guard `selectedDay === date` is gone.
- **`DigestDayDetail`** now takes `state` and `onRetry`:
  - `loading`: the date label plus an `ActivityIndicator` (`colors.accent`, "Loading activity for {date}").
  - `error`: "Couldn't load this day" plus a tertiary `Button` labelled "Retry" ("Retry loading this day").
  - `loaded` with no rows: "No activity on this date."
  - `loaded` with rows: the same list as before, moved into a plain render function.
- **`docs/systems/digest.md`** is updated in three places:
  - Your Week flow step 7 describes the implemented contract.
  - Gotcha 7 (the former "invariant 6") is rewritten.
  - The Key Files table gains `DigestDayDetail`.
  - A new Changelog row records the WR-01 closure.
