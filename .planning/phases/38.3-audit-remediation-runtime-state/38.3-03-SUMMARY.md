# Phase 38.3 Plan 03: Participant Override Value Edits Persist Summary

**Both participant editors now build their Save patch through one pure builder, `src/logic/group-participant-patch.ts`. Editing a Channel, Tone or Duration value that was already overridden (follow stays false before and after) is sent as `{ follow: false, value }` and persists. This includes null, null → value, and a value equal to the parent. Follow state is never inferred from equality (reliability-testing/AUD-REL-006, ADR-125).**

## Accomplishments

- **Root cause removed.** `ParticipantOverrideEditor.changeValue` flips follow to false only when a value changes. Both inline builders emitted a field only when its follow boolean changed, so a false → false value edit produced an empty follow patch and `saveParticipantEdits` no-opped. `buildParticipantFollowPatch` adds the rule: if both states are overridden and the value differs, emit the new value.
- **ADR-125 preserved.** `{ follow: true }` is emitted only when the draft says the field follows. That only happens through the editor's explicit "Follow event" action. An override edited to equal the parent value stays detached. The DAO test also shows that a later parent Tone change does not fan out to that child.
- **Direct fields unchanged.** `buildParticipantFieldPatch` keeps the change-only semantics for Direction, Connected and note. An untouched draft yields `{}` / `{}`, so the DAO's empty-patch no-op still applies (proven: no data-revision bump).
- **One builder, two editors.** `EditParticipantScreen.save()` and `EditGroupEventScreen.saveParticipant()` replaced about 70 lines of duplicated inline builders with the two calls. Everything else in both functions is unchanged: single-flight, `bypassRef`, navigation, error copy, and the post-save reload.
- **Proof.** `group-participant-patch.test.ts` has 26 cases: a 6-transition matrix for each of channel/quality/duration, plus null and multi-field cases and the direct-field patch. `group-events-dao.test.ts` adds 6 round-trip cases through the real `saveParticipantEdits`. With the old follow-changed-only rule temporarily restored, exactly the 4 false → false round-trip cases fail (Channel, Duration, Tone null ↔ value, equal-to-parent). They pass with the fix.
- **Doc sync.** `docs/systems/group-events.md` gets a new layer row and a Key Files row, How-It-Works step 6, Gotcha 10, and a 38.3 Changelog row.
