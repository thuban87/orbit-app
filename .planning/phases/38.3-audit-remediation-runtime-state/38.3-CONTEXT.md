<decisions>
## Implementation Decisions

Restated from the dossier and the audit synthesis — not new owner rulings. Owner rulings from the
discuss session get appended here as D-07+.

- **D-01:** The authoritative contract is the 38.3 dossier. Per-group detail is
  `docs/audits/2026-09-pre-release/synthesis/REMEDIATION-GROUPS.md` (RG sections listed above);
  finding evidence is in the linked `*/DOMAIN-AUDIT.md` packets.
- **D-02:** Preserve RG and **packet-qualified** finding IDs in every plan (bare `AUD-REL-00N` is
  ambiguous). Organize plans around state ownership and end-to-end workflows, not audit domains;
  integration verification must prove convergence from user action to visible state.
- **D-03:** Preserve independent tab histories, Digest as the initial landing surface, and
  transient-first Back behavior. No universal event bus, no new state library, no persistent Digest
  cache/snapshot, no broad navigation reset or new top-level tab.
- **D-04:** A committed write must never replay because a later read/presentation step failed.
  Pending, failed, empty, and successful outcomes stay distinguishable where audited.
- **D-05:** Investigation gate — the **RG-020 accessibility subset**
  (`ui-accessibility/AUD-UIA-022`) needs on-device Contacts/TalkBack traversal before it is treated
  as confirmed. The confirmed panel-dismissal bug proceeds independently.
- **D-06:** RG-023 covers successful Assist publication only; `react-native/AUD-RN-013` (write-
  failure feedback) stays deferred. RG-035 fixes the five uncontested branches only — the
  ContactPicker read-error empty-state fallback (Phase 22 prescribed, CF-02) is **not** changed
  without a new owner decision.
</decisions>
