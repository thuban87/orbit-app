<objective>
Restore Home interactivity after every panel dismissal (RG-020: `react-native/AUD-RN-001`, S1 confirmed). Root cause (verified on disk): `DashboardOverlayHost.dismiss` calls `close()` (nulls `request`) and THEN reads `getState().request?.onDismiss()`, so the owner's `onPanelOpenChange(false)` never runs and Home's separate `panelOpen` state (`HomeScreen.tsx:508`) stays `true` — both wrappers stay `pointerEvents="none"` / `no-hide-descendants`.

Fix by capturing the request before clearing (research "RN-001 host fix") AND deriving Home's `panelOpen` from the panel store so presentation and inertness share one owner and cannot desync again.

The accessibility grouping subset (`ui-accessibility/AUD-UIA-022`) is explicitly NOT touched: D-05 gates it on an on-device TalkBack traversal that must run AFTER this fix (Plan 16).

Plan against the dossier (D-01); packet-qualified IDs (D-02); preserve in-tree panels, transient-first Back and `no-hide-descendants` while open (D-03, ADR-095).
Spec-less probe fallback: skipped (visible) — ROADMAP requirement IDs were TBD; the ADR-095/D-05 constraints are authored as descriptor-less prohibitions.
</objective>
