## Pattern Assignments

### `src/utils/latest-request.ts` (NEW)

**Analog:** `src/hooks/use-category-catalog-refresh.ts`

Coordinator factory with injected deps (lines 15-36):
```ts
export function createCategoryCatalogRefreshCoordinator(input: {
  read: () => Promise<CategoryCatalog>;
  commit: (categories: CategoryCatalog) => void;
  reportFailure?: (source: CategoryCatalogRequestSource) => void;
}) {
  let generation = 0;
  return {
    async request(source) {
      const requestGeneration = ++generation;
      try {
        const categories = await input.read();
        if (requestGeneration === generation) input.commit(categories);
      } catch {
        input.reportFailure?.(source);
      }
    },
    invalidate(_reason: "blur" | "unmount"): void { generation += 1; },
  };
}
```
Note the gap: the analog does **not** gate `reportFailure` on the generation. D-23 says errors must be gated too, so `isCurrent(token)` has to guard the error publication as well.

React wiring (lines 42-70): keep the callback in a ref (`commitRef.current = onCommit`), build the coordinator lazily once in a `useRef`, request on focus, `invalidate("blur")` in the focus-cleanup, and `invalidate("unmount")` in a `useEffect` cleanup. Do not put animation or lifecycle values in deps (PERF-002).

### `src/stores/shell-refresh-store.ts` (+foreground revision)

**Analog:** itself, lines 4-31. Add a second counter in the same shape (`foregroundRevision` / `publishForegroundRefresh` / `useForegroundRefresh`), using the same skip-initial-revision idiom:
```ts
export function useShellRefresh(onRefresh: () => void): void {
  const revision = useShellRefreshStore((state) => state.revision);
  const initialRevision = useRef(revision);
  useEffect(() => {
    if (revision === initialRevision.current) return;
    initialRevision.current = revision;
    onRefresh();
  }, [onRefresh, revision]);
}
```
Do not add a new store library or bus (D-03).

## Shared Patterns

- **Theme tokens:** every new loading, error or disabled state uses `useTheme()` colours: `colors.accent` for spinners, `colors.textSecondary` for captions, `colors.surface`/`colors.border` for containers. No literals (`check:colors` gate).
- **Logging:** `Logger.error(LOG_SCOPE, "<msg>", err)` from `@/utils/logger`. The stale-cold drop uses debug level.
- **Write failure:** use an Alert as Compose does. Leave the durable state intact and keep the surface retryable.
- **Commit vs read:** use separate try blocks. A read failure after a commit is never "not saved" (D-04, RG-018 coordinator).
- **Dates:** use `formatLocalDate()` on focus, resume and revision. No timers (D-22).
- **Dev probes:** use the `uat-probes.ts:16-29` `DevSettings.addMenuItem` plus lazy-`require` pattern, guarded by `__DEV__`.
