## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | vitest 4.1.10 (`environment: "node"`, render-free — no component mounting by recorded convention) |
| **Config file** | `vitest.config.ts` |
| **Quick run command** | `npx vitest run <touched test files>` |
| **Full suite command** | `npx vitest run && npx tsc --noEmit && npm run check:colors && npx biome check src` |
| **Estimated runtime** | quick ~1–5 s; full suite several minutes |
| **Mounted lifecycle** | Not available in node. Ordering logic is extracted into pure controllers tested with deferred promises; mounted behavior is proven on the Pixel (debug build, Metro :8082, logcat `Logger.debug` markers, dev-menu probes in `src/__dev__/uat-probes.ts`). |

---

## Sampling Rate

- **After every task commit:** quick command on the touched suites
- **After every plan wave:** full suite command (vitest + `tsc --noEmit` + `check:colors` + biome) — vitest green ≠ tsc clean
- **Before `/gsd-verify-work`:** full suite green AND device-UAT plan rows recorded
- **Max feedback latency:** ~5 s per task (quick run)
