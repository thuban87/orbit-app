## Accomplishments

- Added migration 018 and registered schema target 18: global-default scope, `history_retained`, nullable `field_group`, and the UID-unique `custom_field_value_history` table/index, without changing normalized current-value constraints.

## Decisions Made

- The public field creator refuses `scope='contact'`; Phase 31 owns scoped creation and its durable ownership, owner-purge, and edit-filtering bundle.
- Value history stores the exact prior raw TEXT in an additive table. The `custom_field_values` pair uniqueness and `field_history` roles remain unchanged.
- History append happens before the edit upsert in the existing outer transaction, so null-first-set and unchanged writes append nothing while clearing a non-null value retains the prior value.
