| Property | Value |

| **Estimated runtime** | quick suites: about a minute; full suite: several minutes (measure on first run and record here) |

---

## Sampling Rate

- **After every task commit:** the task's own `<automated>` command (the table below).
- **After every plan wave:** the full suite command, including `npx tsc --noEmit` and `npm run check:colors`.
- **Before the device pass (Plan 16):** the orchestrator's phase code review (`38.7-REVIEW.md`) and its fixes are committed, then Plan 16 Task 1 re-runs `npm test`, `npx tsc --noEmit`, `npm run check:colors` and `npx biome check src`.
- **Before `/gsd-verify-work`:** full suite green; Plan 16 release measurements recorded against the locked gates.
- **Max feedback latency:** one task's quick suites.
