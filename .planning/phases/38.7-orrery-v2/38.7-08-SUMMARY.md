# Phase 38.7 Plan 08: Ambient clock, base bake and the D-44/D-49 release spike Summary

**V2 now idles on one quantised ~30 Hz ambient value and blits a GPU-baked base while still. Base snapshots are disposed only under the H3 ledger. One release spike build measured both phones, and the owner adopted the recommendation (D-64): world-plane rings, the frame-clock driver, an opaque SurfaceView canvas and the bake on. G1, G5 and G6 still fail on the 6 Pro and carry to Plan 16. The 6 Pro's 120 Hz idle is reported, and a diagnostic is pending.**

## Performance

- **Duration:** ~4 h 40 m (15:53Z → 20:33Z), including two owner round trips
- **Tasks:** 4 of 4. Task 3 was the owner's decision. Task 4 set world-plane defaults only (no ring field).
- **Files:** 21 (9 created, 12 modified)

## Accomplishments

- **Ambient clock (D-49).**
  - `useOrreryAmbient(host, reducedMotion)` produces quantised ms, or −1 under reduced motion.
  - Two drivers: frame-clock (`useClock` plus a reaction that writes only on change) and interval (a JS timer stopped by the reduced-motion twin; no per-vsync callback).
  - The stars and the sun read the ambient value. `useClock` now appears only in `ambient-clock.ts`.
- **Base bake (D-49, C-H2).** After `BAKE_AFTER_STILL_TICKS` (15) still ticks, with no switch, gesture or camera motion, the base is drawn into a device-pixel offscreen surface and blitted 1:1. Any change falls back to live on the same frame.
  - Snapshots are `base`-layer ledger objects (`baseHandle`), and the base picture acks like the other layers.
  - Retirement disposes on the UI thread. A stale-epoch result is disposed immediately.
  - Teardown disposes the snapshots, then the surface.
  - Device check: GL mtrack is +30 MB with the bake on.
- **Spike seams (D-59):**
  - a DEBUG dev-menu override, reached only via a `__DEV__`-guarded require;
  - a release URL selector, compiled in only with `EXPO_PUBLIC_ORRERY_SPIKE=1`. Every canvas mount logs `orrery-spike host=…`.
- **Release spike:** exactly one release build (`c445dba0`). Results are in 38.7-SPIKE.md. Headlines:
  - the TextureView caps at 22–27 presents/s;
  - the SurfaceView reaches Recenter 36/s and adb pan 53/s at Size 120;
  - the bake gives −28 % of a core at idle at All Contacts;
  - 0 ANR and 0 crashes on both phones in every scenario (main had 7 crashes);
  - the 3a's idle CPU is 30 % vs main's 99.9 %.
- **Decision recorded (D-64):** host defaults in code, dated amendments to the dossier's D-44/D-49, CONTEXT D-64, and `## Decision` in SPIKE.
