## Deviations from Plan

1. **Owner stopped the testing.** The owner declined all further device testing. Task 3 (the recorded windows), the
   G8 feel ratings, the Task 4 portrait scenario, the D-11 churn set and the TalkBack check are recorded as "not
   measured — owner declined further testing (2026-10-05)". None is a pass or an acceptance.
2. **The measurement battery ran too long.** The release battery ran 22:03 to past midnight. That crossed a local
   date, so a second fixture re-anchor and compare were needed. The D-11 churn set then stuck twice and the agent was
   stopped. The battery as planned (both phones, owner windows, portraits, churn) was more than one device session can
   carry under D-66. A future release pass should time-box it and run the owner's window first.
3. **The portrait scenario was removed.** It was not run, so the fixture never left the baseline data and no
   post-portrait restore was needed.
4. **Source changes in a no-source plan, owner-directed.** The plan said "MUST NOT change any source file". The owner
   ruled FV-1 = fix and directed the framing reversal, and he found the focus card tap bug. All three were fixed here at
   his direction (`cd08e8c0`, `c84742de`, `fd502ba5`), with tests. The framing change reverses recorded behaviour (D-19
   cluster-panel obstacle, the feedback-framing rule); the owner approved that explicitly (D-79).
5. **A second release build and a Drive delivery.** The plan allowed exactly one release APK and no Drive copy. A fix
   release (`09c6c579` code, SHA-256 `2af90914…`) was built to check the fixes on the 6 Pro, and it was delivered to the
   owner's Google Drive as `orbit-38.7-release-2026-10-05.apk` **with his explicit approval**.
6. **The owner tested on his Moto Razr.** The sign-off came from the owner's own hands-on on his personal Moto Razr
   (map stays put, focus card taps, smoother camera moves), not from the planned recorded windows on the test phones.
   This replaces the G8 recorded-window ratings; it is not a measured number.
7. **Referenced evidence committed late.** `38.7-16-OWNER-WINDOW.md`, `evidence/16-release/frb-release-excerpt.txt` and
   `switch-release-compare.mp4` were referenced by committed docs but untracked. They are committed in `4a86e88b`.
