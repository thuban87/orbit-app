<objective>
Ship the durable data layer for the Default Interaction Channel preference (CAPT-11): one new `app_settings`-only migration (head+1 = **027**, verified on disk), the DAO read/write/validate wiring, and declare-only backup portability. This is the foundation the Log Interaction screen (34-04) consumes to initialize the channel and to persist the remembered value on a successful ordinary save.

Per D-01/D-02 the dossier (§P, §Q) and planning-notes (R-16) are ground truth; per D-03 this phase ships schema as application code via the `PRAGMA user_version` runner and never assumes a migration number. **This phase ships NO `interactions` migration** — CAPT-15's vocabulary migration was already shipped by Phase 32 (migration 025); a second `interactions` UPDATE is the double-migration STOP-AND-ASK hazard (owned by 34-02's verification).

Purpose: give ordinary logging a portable, validated channel default without AsyncStorage and without touching the shared `interactions` table.
Output: migration 027 + test, extended `app-settings-dao` + test, declare-only `PORTABLE_SETTINGS_KEYS` + test.
</objective>

Detector fired (`assumption-delta scan 34` → detected:true, `optional` signals). CAPT-11 turns a previously derived/fixed interaction Channel into a **chosen** durable preference.
- **Noun now primary:** the interaction's `channel` remains the primary field; the Default Interaction Channel preference is a new *scoped* seed for it.
