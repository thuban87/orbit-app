# Phase 24.1 — Physical-device UAT results

installed release build. Nothing is inferred from code or selectors. The device data
(deliberately created UAT records) was preserved throughout — no data clear, no reinstall.

## Environment notes

- Release build is **not debuggable** → `run-as` DB inspection is unavailable, so every
  result is UI-observable only (matches the owner's chosen UAT method).
- Two harness artifacts encountered and worked around (not app bugs):
  1. **Soft-keyboard occlusion.** The "Save current value" button for a current-state
     field sits near the bottom; with the IME up, taps there hit the keyboard. Closing
     the keyboard and scrolling the editor to mid-screen made Save commit reliably.
  2. **adb tap on small/list Pressables** occasionally needs plain `input tap` vs.
     `input touchscreen tap`; contact-picker rows needed plain tap.
