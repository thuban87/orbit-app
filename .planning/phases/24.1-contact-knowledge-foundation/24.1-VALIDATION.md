## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Vitest (node environment) with the `node:sqlite` executor via `src/db/__testkit__` (extensionless `.test.ts` DAO/migration suites that run migrations to `TARGET_VERSION` and exercise SQL node-side) |
| **Config file** | project `vitest` config (repo runs `npm test`) |
| **Quick run command** | `npx vitest run src/db/<module>.test.ts` |
| **Full suite command** | `npm test` |
| **Estimated runtime** | quick ~2–5s per module; full suite ~30–60s |

> `.tsx` screens (the "Things to Remember" surface, Recently Deleted screen, history drill-in) are verified by on-device Pixel UAT, not node tests. Colour compliance is checked with `npm run check:colors`; types with `tsc --noEmit`.

---

## Sampling Rate

- **After every task commit:** `npx vitest run <touched module>.test.ts` + `tsc --noEmit` (+ `npm run check:colors` for UI tasks)
- **After every plan wave:** `npm test` (full node suite) + `biome` on changed files
- **Before `/gsd-verify-work`:** full suite green + on-device Pixel UAT of the surface/editor/Recently-Deleted flows
- **Max feedback latency:** ~5 s (quick module run)
