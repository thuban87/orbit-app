# Phase 24.1 — API / AI Integration Coverage

No external API integration: Phase 24.1 builds the local additive knowledge model and UI (typed Memories + registry, relationships, current-state history, soft-delete + Recently Deleted, and the unified "Things to Remember" surface). Per-item AI permission and any AI egress are Phase 24.2. 24.1 sends no Memory to AI; Group Notes are never sent under any state. The Memory-type registry carries `aiDefault`/`searchable` as declared metadata with no consumer in this phase.
