## Phase Goal

**As a** person tending my relationships, **I want to** keep several links per contact and tap to open them, **so that** their LinkedIn, Instagram, and personal site are one tap away.

**This slice (Plan 07):** the contact_links CRUD DAO + the links editor, integrated into the edit form. After this plan a user adds/edits/removes several links on a contact and taps one to open it.

<objective>
Build the `contact_links` child-table CRUD DAO and the repeatable LinksEditor, and wire links into the edit form's assembly + UI. The table already exists (migration 1) — this is DAO + UI only.

Purpose: CRUD-04 (many links, add/edit/remove, optional label, ordered, tappable). Per CONTEXT Area 2: optional label, no autocomplete (deferred), open as web URL with `https://` prepend + `Linking` try/catch, insertion order via `display_order` (no drag UI — deferred).

</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| link url/label → DAO | User-entered URLs/labels cross into SQL |
| link url → OS browser | A user-entered string is handed to the OS via Linking |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-04-02 | Tampering (SQL injection) | contact-links-dao | high | mitigate | Every value `?`-bound; no interpolated identifier; mutations both-key scoped with assertOneChange |
| T-04-09 | Elevation (malicious scheme) | link open | medium | mitigate | Prepend `https://` when no scheme so a raw `javascript:`/`file:` string is not honoured as typed; `Linking.openURL` in try/catch; no `canOpenURL` probe |
| T-04-03 | Tampering (mis-scoped mutation) | update/remove link | medium | mitigate | Scoped by (id, contact_id) + assertOneChange — a mismatched pair throws instead of touching another contact's link |

Local-first; link open hands off to the OS browser (no contact data leaves the device beyond the URL the user chose to open).
</threat_model>
