<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| shared payload → rendered/stored text | Untrusted title/prose is displayed and written on pick. |
| capture flow → background lifecycle | resetOnBackground can drop an unwritten payload. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-10-01 | Tampering / Info-disclosure | preview + single-tap write | medium | mitigate | The payload is rendered as text and written `?`-bound via `addFuel`; never executed/interpolated. The url is stored only — never opened (grep gate asserts no Linking.openURL). |
| T-10-04 | Denial (data loss) | write-on-pick timing | medium | mitigate | The fuel row is written the INSTANT a face is tapped, before any prompt; the whole flow is in-app (no system picker, no permission dialog) so a background can't silently lose an unwritten payload. |
| T-10-05 | Info-disclosure | captured url | low | accept | Capture stores the url canonical and never auto-opens it during capture (link-open stays behind the 04-07 https-only allowlist, out of scope). |
</threat_model>
