<objective>
Wire the installed `expo-share-intent` into the app: wrap the tree in `ShareIntentProvider`, add the react-navigation `linking` config (with `navigationRef`) that redirects an incoming share intent to the `Capture` route on both cold start and background, and add the `Capture` route to the param list. This is the plumbing that turns a system share into a mounted picker screen.

Purpose: The library provides no auto-navigation — the documented react-navigation integration is a `linking` config using `ShareIntentModule` + `getShareExtensionKey`/`getScheme`. This plan owns that plumbing so the screen (10-05) is a plain route.
Output: `src/navigation/linking.ts`, the `Capture` route type, and the App.tsx wiring.
</objective>
