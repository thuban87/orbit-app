<objective>
Create the single pure, node-tested resolver that maps an incoming share payload to a fuel row's display text + canonical url, and recomposes the display text when the user adds an optional note — the `note — label` composition. This is the correctness core CAP-03 hinges on, and the first of the three Wave-0 node-test files.

Purpose: Keep all payload parsing and note composition in one react-native-free module (the `compose-logic` / `dashboard-empty-logic` pure-resolver idiom) so every branch is proven off-device and the `.tsx` screen just renders the result.
Output: `resolveCapturePayload()` and its `CapturePayload` type, fully node-tested.
</objective>
