| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-11-05 | Tampering / DoS | `updateAppSettings` hour fields | high | mitigate | Reject any hour that is not an integer in [0,23] BEFORE the UPDATE; the read side also clamps in fire-instant (11-05) as defense-in-depth. |
| T-11-06 | Tampering | migration 002 | high | mitigate | Additive + defaulted only; no edit to migration 001; every seed value `?`-bound, only the runner's integer user_version is interpolated (runner.ts). |
| T-11-07 | Information disclosure | settings storage choice | medium | accept | SQLite-in-app-private DB (allowBackup=false already set) is the decided backup-native home (OQ-1); no new network path, no secret. |
</threat_model>
