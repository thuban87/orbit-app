## Sampling Rate

- **After every task commit:** Run the quick command on the touched suites.
- **After every plan wave:** Run the full suite command, including `tsc --noEmit`. vitest passing does not mean tsc is clean.
- **Before `/gsd-verify-work`:** Full suite must be green.
- **Max feedback latency:** ~60 s per task.
