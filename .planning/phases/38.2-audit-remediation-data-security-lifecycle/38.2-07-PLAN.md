Plan against the dossier (D-01); packet-qualified IDs (D-02); optional encryption, preview-before-write and user-owned backups preserved (D-03); no wire-format change (D-10). Per D-19, the off-thread copy, stall deadline and cleanup ship here; the ingress byte ceiling VALUE and the acquisition deadline (`BACKUP_INGRESS_ACQUIRE_MS`) are measured and owner-signed in Plan 15 before they are enforced. The acquisition deadline ships disabled rather than with a provisional value: D-19's ungated list names only the off-thread copy, the stall deadline and cleanup, and on a cloud provider (Drive SAF) that downloads the whole file inside `openInputStream()` an acquire deadline acts as an unmeasured total-duration cap on large backups. Disabling it loses no resource bound, because an abandoned-but-blocked acquisition keeps its `MAX_CONCURRENT_INGRESS` slot until it returns whether or not a deadline fired (review N4). D-13 sets the export staging lifetime.

Output: bounded async native copier + JVM tests, patched general share module, JS guards/cleanup, export staging lifecycle, `backup-cache-sweep.ts`.
