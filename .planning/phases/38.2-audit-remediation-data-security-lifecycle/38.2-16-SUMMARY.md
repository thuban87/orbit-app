4. `1ad2343`, `696b363` — every source option (and the photo choice) read `Contacts (android)`; now names the phone contact.
5. `c8d16c0`, `618cf2b` — `Resume your import?` interrupted every picker/permission round-trip and the same sweep could delete not-yet-committed staged photos.
6. `dbffa51` — same resume/staging race for the linked-contacts check.
7. `c2d7ad1` — undecodable picked image left the crop screen silently stuck.
8. `be539b6` — the ADR-154 notes re-read leaked one `contact-picker-*.photo` per imported contact.
9. `779b5ce` — backup share granted only the system chooser; now grants only the chosen app (ADR-155). Drive's stall proved to be environmental.
