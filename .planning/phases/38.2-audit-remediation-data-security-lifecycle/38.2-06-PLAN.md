    - "A newer normal photo write (crop, import, reconcile promote) always wins over stale restore recovery in both interleavings: canonical writes and journal finalization serialize on one process-local per-canonical-path lock; a normal writer persists its bytes and then retires every journal row for that canonical path; the drain re-reads its row under the lock before touching bytes (reliability-testing/AUD-REL-003)"
    - "If a newer normal write fails, the pending recovery row is left intact and a later drain still recovers it"
    - "Journal delete intents are idempotent (duplicate `delete:<path>` inserts are no-ops, including a retained row from an earlier interrupted restore)"
    - "A canonical file is deleted only when no live row references it (contacts.photo, profile.photo, custom_field_values.value, exact string) AND no pending finalize row targets it; otherwise the intent retires without deleting — delete by derivation, protect by any reference"
    - "The drain never deletes pending files that belong to an in-flight staging session; a staged-then-committed restore/merge photo can no longer be lost to a foreground transition during staging (the latent recovery-task staged-file deletion bug)"

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| SQLite references ↔ filesystem masters | Ownership is SQL identity; files cannot join the transaction |
| foreground drain ↔ in-flight staging | Recovery must not consume bytes a live operation owns |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-38.2-06-01 | Tampering (integrity) | stale recovery overwrites a newer photo | high | mitigate | Per-path lock + persist-then-supersede + drain re-check (Task 1) |
| T-38.2-06-02 | Tampering / data loss | delete of a live referenced file | high | mitigate | `mayDeleteCanonicalCore` reference predicate (Task 2) |
| T-38.2-06-03 | Tampering (integrity) | drain deletes in-flight staged bytes | high | mitigate | Staging-session registry skipped by orphan cleanup (Task 2) |
| T-38.2-06-04 | Tampering | path injection into deletes | medium | mitigate | Delete targets only from derived builders or DB strings passing `SAFE_RELATIVE` |
