    - "A newer normal photo write (crop, import, reconcile promote) always wins over stale restore recovery in both interleavings AND across process death: canonical writes, journal finalization, delete intents and sidecar reconciliation serialize on one process-local per-canonical-path lock, and every owned writer SETTLES every journal row targeting its canonical path (finalize rows applied, delete intents executed under the reference predicate, in journal id order) BEFORE it mutates the canonical file — so no journal row created before the write can survive past the file replacement, and there is no post-replacement journal retirement for a kill to interrupt (settle-then-write; codex review #2; reliability-testing/AUD-REL-003)"
