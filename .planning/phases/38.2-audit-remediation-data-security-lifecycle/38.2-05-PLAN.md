<objective>
Close the widget snapshot access boundary (RG-001; `security/AUD-SEC-001`) by delivering widget bitmaps inline to RemoteViews and removing the library's exported, unauthenticated image ContentProvider — the OS widget binding becomes the only authorization boundary.

Plan against the dossier (D-01); packet-qualified IDs (D-02); no weakening of existing controls (D-03). The inline-bitmap approach is the chosen fix; the non-exported-provider + host-grant fallback (O-2) is a launcher-trust decision and is NOT planned — if device verification (Plan 16) shows inline bitmaps fail (bitmap-memory or binder limits), stop and ask the owner.

Output: `patches/react-native-android-widget+0.22.0.patch`, runbook manifest assertion, doc updates.
</objective>
