## Required Delete Failure Matrix

Inject a thrown error after each stage: contact reassignment, pending-import default update, category-rule deletion, category-System override deletion, category-System preference deletion, active-selection fallback, Profile presentation deletion, Dashboard filter update, order normalization, tombstone write, and final category-row delete. After every rejection, compare the complete pre-operation database snapshot and assert that `data_revision` did not advance. A successful deletion must advance it exactly once.
