## Decisions Made

- Kept menu placement pure and deterministic while using a React Native `Modal` as the assistive-technology boundary.
- Combined category-System preference and override totals in one UI row while preserving separate DAO fingerprint counts.
- Used the DAO fingerprint as the sole mutation authority; stale previews refresh without performing any write and retain a target only if it still exists.
