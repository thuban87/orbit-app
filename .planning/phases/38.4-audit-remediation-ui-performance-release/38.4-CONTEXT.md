### Visual / product rulings (owner, 2026-09-26)

- **D-12 (owner): RG-029 contrast is a foreground-only fix.**
  - Keep Standard Light glass (`CARD_GLASS_OPACITY` standard 0.5), the veil and all artwork unchanged. No opaque wash, no hue retune.
  - Functional text on glass over Standard assets moves to a foreground token that passes the **real worst-case composite**. The audit found secondary text at ~2.3:1 on Dusk, ~2.9:1 on Mesh and ~4.3:1 on Paper.
  - Fixing the proof is part of this decision: the test must evaluate the relevant extremum for each foreground (the darkest pixel for dark text) across assets, palettes and accents. It currently checks only `brightestPixel`.
  - `AUD-UIA-002`: Backup/Restore primary labels use `onAccent` (ADR-084), and the destructive branch uses a verified danger foreground.
  - If no existing token passes without retuning a protected hue, **stop and ask**.
- **D-13 (owner): RG-033 heatmaps auto-size and center.**
  - The owner reports that Your Week does **not** overflow on the narrow Moto Razr, but leaves obvious empty space on the right.
  - The Your Week grid computes cell size from the measured available width, bounded by a sensible min and max so it doesn't balloon on wide screens, and is **centered horizontally**.
  - Every day stays visible, with no horizontal scroll.
  - Other heatmaps (`ActivityHeatmap`) get the same fit-to-width guarantee. Centering them is planner discretion and is reviewed on the device pass.
  - `AUD-UIA-021` (layout-preview gap/column geometry) is unchanged: the preview must match the actual rows.
- **D-14 (owner): RG-036 uses a persistent visible text label above each passphrase field** (current / new /
  confirm, etc.) in the app's existing form-label style. Secure entry, accessible names and encryption behavior
  are unchanged.
- **D-15 (owner): RG-037 Settings chrome.**
  - **Remove the in-body Back** on every Settings child and keep only the `ShellAppBar` header Back. The owner would rather have fewer Back buttons; the header one stays for accessibility and SHELL-03.
  - Known sites: `SettingsAIScreen`, `SettingsOrreryScreen`, `SettingsAppearanceScreen`, `SettingsNotificationsScreen`. Sweep all children.
  - Root rows get the Phase 37 `[DECIDED]` spec: icon + title + subtitle + chevron (`phase-37-settings-personalization-dossier.md` §root rows). The planner picks glyphs from the existing semantic icon set (ADR-086), and the owner reviews them on the device pass.
