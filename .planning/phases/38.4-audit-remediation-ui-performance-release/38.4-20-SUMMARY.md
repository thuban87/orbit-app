### D-61: Android blur off (owner ruling, folded in, TDD)
- In `GlassSurface`, `blurMethod="dimezisBlurViewSdk31Plus"` is now `blurMethod={ANDROID_BLUR_METHOD}`, where `ANDROID_BLUR_METHOD = "none"`.
- **Why "none" rather than dropping the BlurView on Android:** I read expo-blur 57's `ExpoBlurView.kt`. Without a `blurTarget`, the Dimezis path falls back natively to `setBackgroundColor(tint.toBlurEffect(intensity))`, a roughly 22–25% tint layer. The NONE path paints exactly the same layer. Removing the BlurView would drop that layer, and the D-61 requirement is "visual result unchanged".
- `blurMethod` is Android-only, so iOS behaviour is unchanged.
- `glass-surface-blur.contract.test.ts` pins the constant and fails on any `dimezisBlurView` anywhere in `src`.
- Runbook Pitfall 13 was added.
