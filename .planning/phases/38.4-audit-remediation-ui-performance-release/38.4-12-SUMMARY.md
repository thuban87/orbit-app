## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Events error copy told the user to "go back"**
- **Found during:** Task 1
- **Issue:** The load-error body said "Please go back and try again." The Events root no longer has a Back (D-22), so that instruction is now wrong.
- **Fix:** Changed it to "Try opening it again in a moment.", Digest's existing wording. The list rereads on focus.
- **Files:** `src/screens/GroupEventsScreen.tsx`
- **Commit:** `016679e`

**2. [Rule 3 - Blocking] RN's TypeScript `ViewProps` omit `nextFocusForward/Up/Down`**
- **Found during:** Task 3
- **Issue:** `tsc` rejected the props on `Pressable`/`AnimatedPressable`. React Native supports them at runtime: `ViewPropTypes.js`, `BaseViewConfig.android.js`, and `ReactViewManager` → `setNextFocus*Id`.
- **Fix:** Added a `ViewPropsAndroid` module augmentation in the new file `src/types/react-native-android-focus.d.ts`, which the plan's file list did not include.
- **Commit:** `b1b6be6`

**3. [Planner-bucket implementation detail] Dial subscription isolated in `TabNavigatorContainer`**
- The plan put `const fabDialOpen = shellTransientStore(selectFabDialOpen)` in the `RootNavigator` body. It now sits in a small wrapper in the same file that renders `children`, so a dial toggle does not re-render `Tab.Navigator`. The grep acceptance strings and the key-link pattern are unchanged.

**4. [Test placement] Events timestamp assertion lives in `timestamp-consumer-contract.test.ts`**
- The plan's Task 1 behavior list put it in the tab-root contract. It was placed with the `CONSUMERS` table instead, as the Plan 07 summary directs for new consumers. `docs/systems/interaction-history.md`, which is outside the plan's file list, got the matching consumer-table sync.

**5. [Test correction during RED] `dialFocusCycle` unresolved-tag case**
- One RED expectation was wrong: it expected an unresolved FAB tag to also blank the FAB's outgoing link. It was corrected to the specified rule, where only a link whose *target* is unresolved is `undefined`. This happened before any GREEN commit.
