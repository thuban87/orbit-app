     - Everywhere else it is absent: Standard Light Dawn/Paper, the `none` background and every Galaxy background render exactly as today.
   - **Which sites (D-36):** the site list must be complete. The old §5 list came from a grep of six tokens (29 sites). Task 3 therefore starts with an AST enumeration of EVERY text/glyph foreground with no glass or opaque backing over the shell art, and commits it as inventory Table D.    - **Why the failing set is effectively every bare foreground on a Standard-art route (numbers in CONTEXT D-35):** in Standard Dark, bare `textPrimary` peaks at 2.97:1 (Dusk, dense veil), below even AA_LARGE. In Standard Light, bare `textPrimary` on Dusk is 1.31–3.00.
   - The owner rejected light-text/dark-veil and halo alternatives, and wants no scrims beyond the failing sites.
   - **Verified on disk:**
     - `ChromeScrim` draws `colors.surface` at `chromeScrimOpacity` and wraps its children in `GlassForegroundScope`.
     - `chromeScrimOpacity` is 0.5 in Standard Light. In Standard Dark it is 1.0 (the mismatched-regime opaque band), so the Standard Dark backing is opaque `surface` `#191C22`, over which `textPrimary` is 14.41 and `danger` 6.15.
     - The existing chrome-scrim proof (`surface.test.ts` ~:600-663) already shows the glass palette clearing AA over Dusk and Mesh at both extrema.
   - **The pitfall this plan must avoid:** the scope changes only colours read by a hook called *inside* it. Every F-1 site today reads `colors` from its host's top-level `useTheme()`. So does Digest's own ChromeScrim notice (`DigestScreen.tsx:227` vs `:247-251`); the Digest case is one of the out-of-scope reads that Plan 20 (D-34) sweeps. Wrapping such a site without moving the colour read would leave root `danger` `#B21D22` at about 2.23:1 on Dusk.
     - `BareTextBacking` mounts a `ScopedPalette` render-prop reader inside the scrim and hands its children the palette read there.
     - Plan 20 reuses `ScopedPalette` for its glass-scope read-site sweep.
   - The condition reuses existing state: `useTheme()` package and mode, plus the theme store's `standardBackground`, which `ThemeProvider` and `BackgroundHost` already select.
