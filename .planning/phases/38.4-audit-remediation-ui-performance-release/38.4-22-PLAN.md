- Verified on disk at planning; the executor re-verifies:
  - Orbit's mode is its own store. `ThemeProvider` resolves "system" through `useColorScheme()` (`src/theme/theme-provider.tsx` ~:52-75; `resolveMode` in `theme-presets.ts`).

No new dependency is needed if the activity theme is DayNight-capable.
  - The known hazard: once overridden, `useColorScheme()` reports the override, so Orbit's own "System" mode must map to `unspecified`.

**2. D-48 (`OA-D1`; RG-040 follow-on).** Remove `READ_EXTERNAL_STORAGE` / `WRITE_EXTERNAL_STORAGE` (`maxSdkVersion 32`) **only if proven 100% unused**. With any doubt, keep them and surface the evidence.
