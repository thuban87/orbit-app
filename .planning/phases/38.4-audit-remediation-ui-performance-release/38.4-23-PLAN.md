**2. D-56 (`OA-C2`; supersedes D-45): a permanent border on the FAB, on every screen.** The accent-filled FAB merged visually with Backup settings' accent-filled buttons. The owner first asked for a border on that page only (D-45), then ruled for a permanent border everywhere, made in the FAB component.
- `UniversalFab.tsx` paints the FAB disk with `backgroundColor: colors.accent` (`styles.base`: `FAB_SIZE`, `borderRadius: FAB_SIZE / 2`, `elevation: 6`; ~:454-483 at planning).
- *Fix:* one unconditional `borderWidth` + `borderColor` on that Pressable. *Planner pick (D-56):* `onAccent` at 2dp. `onAccent` on `accent` is the ADR-084 pair `accents.test.ts` validates for every curated accent, so the ring reads against any accent-filled button beneath. Both values are top-of-file tunables in `universal-fab-logic.ts`. The owner judges the look on the device (Plan 17).
- The accent disk is opaque, so the memory hazard about `elevation` over a translucent fill does not apply.

Plan against the dossier (D-01); cite D-52 / D-56 and `OA-E3` / `OA-C2` in commits (D-02).
