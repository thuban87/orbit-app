# Phase 38.4 Plan 21: UI fixes (D-44, D-49, D-47) and bulk-import Bound/Unbound batch lifecycle (D-57, D-58) Summary

AI Data Permissions now reconciles every number with the list (a list line plus per-contact AI-accessible counts). Both resume prompts scroll their body at large text and keep their buttons fixed, and the layout editor's live preview is hidden behind one flag. Bulk import can bind a whole batch at one frequency. The choice is stored on the import session by migration 032 and reaches every bulk create path, including a resume, Combine and Duplicate Review. Every create seam now takes the lifecycle as an explicit, required parameter, so the single review's Bound choice is honoured. Import Complete no longer offers the Unbound-contacts bridge.
