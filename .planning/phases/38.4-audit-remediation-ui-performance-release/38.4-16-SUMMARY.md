# Phase 38.4 Plan 16: Placeholder and accent-text roles on glass, plus the D-62 panel blur close. Summary

**Every input placeholder now uses `textPlaceholder`, so placeholders on Standard-Light glass no longer read like typed text. The 64 Table C sites that painted the accent fill as text or glyphs now use `accentText`, and the one glass site reads it inside its GlassSurface. Two contracts lock both changes. The owner-ruled D-62 fix closes an open Contacts control panel when Contacts loses focus, so it no longer swallows the first Back or tab re-tap on another tab.**
