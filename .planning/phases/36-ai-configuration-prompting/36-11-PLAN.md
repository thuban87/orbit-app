<objective>
Close the physical-device OpenRouter authorization gap by replacing the failed ASSUMED A3 custom-scheme provider callback with the owner-approved temporary on-device localhost callback.

Purpose: OpenRouter rejects `orbit://openrouter-auth` as its `callback_url` and silently returns a signed-in user to its ordinary site. An otherwise identical request with a supported HTTP(S) callback reaches authorization. The approved correction makes OpenRouter call a one-shot listener bound to `127.0.0.1` on the phone. The existing custom scheme may remain only as a credential-free localhost-response wake signal so Chrome can foreground Orbit; it is no longer sent to OpenRouter and never transports code, verifier, state, or key. This is the approved reversal of RESEARCH assumption A3, not a weakening of D-13: PKCE S256, mandatory matching state, exact destination validation, and one-time consumption remain fail-closed.

Output: a local Android Expo loopback module, revised OpenRouter OAuth orchestration and focused tests, a rebuilt native debug client, and passing evidence for the two blocked OpenRouter UAT checks.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OpenRouter/Chrome -> phone loopback listener | Untrusted browser HTTP reaches a temporary native server and carries the one-time code plus returned state. |
| Native loopback module -> JavaScript OAuth orchestration | Attempt-local callback material crosses the Expo bridge in memory for independent validation and exchange. |
| Orbit -> OpenRouter key exchange -> SecureStore | A validated code/verifier is exchanged remotely; only the returned API key may cross the existing durable secret boundary. |

| T-36-11-02 | Tampering | Another local process or malformed browser request races the callback | high | mitigate | OS-assigned port, one live attempt, exact GET/Host/path/query cardinality, constant-time-equivalent exact state comparison where available, one-time atomic consumption, and server close before exposing the code; exercised by real-socket JVM tests. |
