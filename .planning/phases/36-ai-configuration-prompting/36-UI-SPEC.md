# Phase 36 — UI Design Contract

> Visual and interaction contract for the AI Configuration & Prompting subsystem. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Ground truth:** the milestone-2 dossier (`docs/dossier/milestone-2/phase-16-ai-configuration-prompting-dossier.md`) + its planning-notes appendix, and ADR-049 / ADR-051 / ADR-078 / **ADR-107** / ADR-079. 36-CONTEXT.md is a shim over these. Where this spec restates a behavior, the ADR/dossier wins on conflict.
>
> **All colours resolve through theme tokens** (`src/theme/`). This spec names palette-token KEYS (`accent`, `danger`, `surface`, `textPrimary`…), never hex. No hardcoded colour anywhere, including Skia (no Skia surfaces in this phase).

## Design System

| Property | Value |
|----------|-------|
| Tool | none — mature bespoke React Native / Expo design system already in `src/theme/` + `src/components/ui/` |
| Preset | not applicable (RN app, not React/Next.js/Vite web; shadcn gate does not apply) |
| Component library | Orbit primitives: `AppText`, `Button` (5 roles), `GlassSurface`, `Sheet`, `Modal`, `ConfirmDialog`, `AccordionSection`, `SegmentedControl`, `Snackbar`, `ContactPicker`, `FilterChipRow`, `Icon` (local `icon-registry`) |
| Icon library | local `@/components/icons/icon-registry` (theme-toned `Icon`; destructive/warning glyph = reserved `warning`) |
| Font | Space Grotesk (display/heading) + Inter (body/label/caption), resolved via `AppText` role → `TYPOGRAPHY` |

**Reuse-first mandate.** This phase adds several new AI-config surfaces but must NOT introduce new primitives where an Orbit primitive exists. Selectable connection lanes use `GlassSurface` cards + `AccordionSection` for expandable setup, not new controls. Confirmations use `ConfirmDialog` (destructive role). Writing Style options use `SegmentedControl`. The contact preview picker is the canonical `ContactPicker`. Bulk-permission selection reuses `BulkActionSurface` patterns.

## Spacing Scale

Source of truth: `src/theme/tokens/spacing.ts` (`SPACING`). All values are multiples of 4 except the intentional grid-aligned `md = 12`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, chip inner padding |
| sm | 8px | Compact element spacing, inline control gaps |
| md | 12px | Dense row inner padding (list rows, model cards) — intentional (documented in token file) |
| base | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, gap between conceptual groups |
| xl | 32px | Major section breaks within a management destination |
| 2xl | 48px | Screen-level top/bottom breathing room, empty-state vertical centering |

Exceptions:
- **44×44 minimum touch target** (`MIN_TOUCH_TARGET`, `button-roles.ts`) — a floor, not a spacing token. Every icon-only control (Disconnect, Refresh Models, section reorder handle, Details toggle, overflow menu) pads up to 44 even when the glyph is smaller.
- No new spacing values may be introduced; dense AI-settings/forms use `md`/`base` inner padding with `lg` between groups.

## Typography

Source of truth: `src/theme/tokens/typography.ts` (`TYPOGRAPHY`) — 5 semantic roles over exactly 4 sizes and exactly 2 weights. Screens consume roles via `AppText`, never raw sizes.

| Role | Size | Weight | Line Height | Usage in this phase |
|------|------|--------|-------------|---------------------|
| display | 28px | 600 | 34 (1.2) | Management-destination titles (AI Settings landing) — sparing |
| heading | 20px | 600 | 25 (1.25) | Section headers (Connection, Model, Writing Style, Personalization Context, AI Data Permissions, Preview What Orbit Sends) |
| body | 16px | 400 | 24 (1.5) | Explanatory copy, disclosure text, personalization body text, error descriptions |
| label | 14px | 600 | 20 (1.4) | Control labels, connection/model card titles, permission type names, CTA labels |
| caption | 14px | 400 | 20 (1.4) | Secondary metadata — pricing lines, token estimates, "Updated …" freshness, new-items-only notes, summary counts |

OS text scaling must still reflow (line heights are absolute px derived from the multiplier, not clamps). No fifth size, no third weight.

## Color

Source of truth: `ThemePalette` (`src/theme/theme-types.ts`), resolved at render via `useTheme().colors[key]`. 60/30/10 maps to Orbit's package × mode surface system (`src/theme/tokens/surface.ts`); cards are `GlassSurface` (glassy in the matched art-tone regime, opaque otherwise).

| Role | Token | Usage |
|------|-------|-------|
| Dominant (60%) | `background` | Screen background (with `BackgroundHost` veil); bare-chrome text gets `ChromeScrim` backing |
| Secondary (30%) | `surface` / `surfaceElevated` (via `GlassSurface`, `dense` density for these form/settings screens) | Connection cards, model cards, personalization section cards, permission rows, disclosure/notice surfaces |
| Accent (10%) | `accent` (fill) / `accentText` (link tone) / `onAccent` (on-fill text) | See reserved-for list below |
| Destructive + warning-emphasis | `danger` (fill) / `onDanger` (on-fill text) | Destructive control fills AND warning-emphasis text/glyph (its documented dual role) |

**Accent (`accent` fill) is reserved for — explicit list, never "all interactive elements":**
- The single Primary CTA per surface: **Connect with OpenRouter**, **Save**, **Choose this model**, **Connect** / **Reconnect**.
- The ON track of the **AI Enabled** master toggle and per-item/section enable toggles (RN Switch on-state).
- The selected-state indicator on the **active connection** card and the **selected model** row.

**`accentText` (link/tertiary tone) is reserved for:**
- **Browse all models**, **Review existing …**, **Refresh Models**, **Preview What Orbit Sends**, **Details** (error expand), **Preview with contact…** — text-only tertiary actions.

**`danger` is reserved for (two documented uses only):**
- Destructive-button fill (with `onDanger` label + reserved `warning` glyph): **Disconnect OpenRouter**, **Remove <provider> key**, **Delete section**, **Turn off access** (bulk disable confirm).
- Warning-emphasis TEXT/glyph (NOT a destructive fill): the **Needs Attention** notice, the **model-unavailable** notice, the **context-overflow** notice, and validation errors (invalid endpoint URL). This is `danger`'s authored dual role per `theme-types.ts`; it introduces no new token.

**Guardrail:** Needs Attention is an attention state, not a destructive action — it renders as a restrained tonal `GlassSurface` notice with a `warning` glyph in `danger` tone and a Primary/Secondary repair button, never as a full `danger`-filled slab. Status hues (`statusStable/Wobble/Decay`, `rogue`) are contact-orbit states and must NOT be repurposed for AI state.

## Surface Inventory & Interaction Contracts

Prescriptive contracts for each distinct surface this phase owns. (Compose-side surfaces are consumed by Phase 35's ComposeScreen; this phase owns their AI-availability/repair/disclosure behavior and copy.)

### 1. AI Enabled master toggle & AI-off simplified state (AICFG-01)
- A single `Switch` (accent on-track) at the top of the AI area. Label **AI Enabled** (`label`).
- **AI OFF:** collapse the full config hierarchy to a simplified state — the toggle, a `caption`/`body` preservation note (see Copywriting), and a persistent **Manage saved connections** escape-hatch (Secondary button) that opens connection management WITHOUT re-enabling AI. Do NOT leave the full expanded hierarchy visible when off.
- **AI ON:** reveal the six-section hierarchy (Connection · Model · Writing Style · Personalization Context · AI Data Permissions · Preview What Orbit Sends) as `AccordionSection`s or routed destinations.
- `AI off` and `AI misconfigured` are distinct states — off never renders as Needs Attention.

### 2. Connection lanes (AICFG-02/03) — selectable cards, one active
- `GlassSurface` selectable cards (NOT literal radio buttons), grouped **Recommended** (Connect with OpenRouter) and **Advanced Setup** (Connect directly to a provider → OpenAI / Anthropic / Gemini; Custom Endpoint). OpenRouter gets slightly stronger prominence (first, recommended chip).
- Each card expands (`AccordionSection`) to reveal setup/status inline.
- Mutual exclusivity: exactly one active connection; the active card shows the accent selected-state indicator. Others may be **configured but inactive** (a `caption` "Saved" marker) — switching never deletes them.
- Starting setup on a new lane must NOT deactivate the working connection; the new lane becomes active only on success (E). Cancel/failure leaves the prior connection active.
- Removal is separate & deliberate (destructive) — see Copywriting.

### 3. OpenRouter connection + curated-first model picker (AICFG-04)
- Setup uses OpenRouter's **browser authorization** flow (no manual key paste). A single Primary **Connect with OpenRouter** CTA launches it. (New egress host + browser-OAuth path is already owner-decided in the dossier — do not widen.)
- Model picker is **Orbit-owned**, curated-first: a small curated set of cards, then a **Browse all models** (`accentText`) path into the broader catalog with search.
- Model cards show `label` model name, `caption` underlying provider, an Orbit recommendation reason (Balanced / Cost efficient / Lightweight — simple & capable), and **real current/cached input+output pricing** (never `$ / $$ / $$$`). Deeper context-window/metadata under a **More Info** disclosure.
- Recommendations and prices are runtime/catalog data — never hardcoded model IDs or prices in the UI.

### 4. Model catalog refresh & freshness (AICFG-04)
- Renders instantly from bundled/cached catalog (offline-safe — no blocking network on open). Auto-refresh on the **first AI/model-settings open of a new local day** (use `formatLocalDate()` for the day boundary, never `toISOString().split('T')[0]`). Explicit **Refresh Models** action (`accentText`). On refresh failure, keep cached data and show an inline `caption` failure note. Show an **Updated <local date/time>** freshness `caption` where helpful.

### 5. Direct BYOK & Custom Endpoint (AICFG-02) — Advanced
- BYOK: per-provider key entry (OpenAI/Anthropic/Gemini) → key goes ONLY to SecureStore (`ai-key-store`), never into a form-serialized patch (ADR-049). Curated + broader catalog + manual model-ID escape hatch.
- Custom Endpoint: labelled **Advanced**; wording states **OpenAI-compatible HTTPS** only (not arbitrary HTTP). Fields: base URL, optional credential, model id, discovery where supported. URL validated through the shared `validateCustomEndpoint` before persistence (rejects malformed/credentialed/`.local`/non-public → `danger` inline error). Show the Custom retention caveat (`CUSTOM_RETENTION_CAVEAT`).

### 6. Needs Attention / repair (AICFG-05)
- Distinct from OFF. When AI is ON but the active connection/model is invalid/expired/unavailable: state = **Needs attention**, config preserved, no silent switch to another saved connection or model.
- Renders as the restrained warning notice (see Color guardrail) with cause-appropriate repair actions: **Reconnect**, **Replace key**, **Choose another model**, **Change AI connection**.
- Compose replaces normal AI actions with an **AI needs attention** notice routing to repair — AI does not silently disappear.
- Model unavailable → explicit copy + reselection required (no silent substitution).

### 7. Writing Style (AICFG-06)
- Structured `SegmentedControl` rows: Tone (Casual / Balanced / Polished), Length (Concise / Normal / Detailed), Directness (Gentle / Balanced / Direct). Each dimension offers a **Use custom guidance instead** opt-out. Plus a freeform multi-line field for self-authored guidance. Labels are tunable but must stay small and understandable.

### 8. Personalization Context sections (AICFG-06)
- Ordered list of user-created sections, each a `GlassSurface` card with: title (`label`), long-form body, an enable/disable toggle (accent on-track), a drag reorder handle (44px target), and an overflow menu (rename / edit / delete / replace). Ordering is organizational only (does not alter semantic weighting — say so plainly if surfaced).
- Add via **paste text** (primary power-user path) or **import .txt / .md** (copied into a local editable record; no live file link). No DOCX/PDF, no rich text, no folders/nesting/version history.
- Enabled = sent; Disabled = stored locally, not sent. No second per-section permission flag (distinct from Contact Knowledge).

### 9. Token/context + cost estimate (AICFG-07)
- Personalization Context surfaces an estimated context size in tokens (`caption`), recalculated with debounce after meaningful edits (never per-keystroke network calls).
- For OpenRouter, also show **estimated input cost per generation** from cached/fresh selected-model pricing (input only). Direct/Custom show token size + **Cost estimate unavailable for this connection.**
- **No artificial context ceiling and no silent truncation.** True model-capacity overflow is surfaced explicitly as a warning notice requiring deliberate resolution (reduce/disable context, change personalization, or pick a larger-context model).

### 10. Central AI permission manager (AICFG-10)
- Two complementary areas, NOT a contact × field matrix:
  - **Defaults for new information** — type/field-level defaults (default OFF), including **interaction notes** as a covered type. A prominent `caption` note: changing a default affects **new items only**; offer **Review existing…**.
  - **Review existing AI-enabled information** — `ContactPicker`-style contact search, `FilterChipRow` for knowledge/type + an "Enabled only" filter, contact drill-in, semantic labels (never storage ids), and summary counts.
- Bulk **disable** supported directly (destructive confirm). Bulk **enable** supported ONLY behind an explicit impact confirmation showing what/how much becomes AI-accessible. No "Enable everything" shortcut; no separate "Disable all" emergency command.
- **Guardrails (ADR-107 / ADR-078 / D-07):** the manager covers Contact Knowledge items + AI-enabled interaction notes only. **Off Limits never appears here as an AI-egress toggle** (Off Limits is never transmitted to AI in any form — ADR-107). **Group Notes never appear here** and are never AI-eligible.

### 11. Transparency surfaces (AICFG-11/12)
- **First-use disclosure** (once, on first successful setup): lightweight modal naming the active connection's real data path (OpenRouter + underlying model provider / the selected direct provider / the configured custom endpoint). The exact-prompt first-send acknowledgement is retired (ADR-079) — never gate generation on an `ai_ack_*` value nothing sets.
- **Settings — Preview What Orbit Sends:** whole-prompt-system review (Orbit system instructions, Writing Style, enabled Personalization Context, placement rules, output contract), with an optional **Preview with contact…** (canonical `ContactPicker`) resolving a real example including that contact's permitted context, latest-three interaction projection, and other applicable material. Readable sectioned view + optional raw/resolved view for power users. **Credentials NEVER displayed.**
- **Compose — contact-specific review** (separate, per-generation): "Sharing N items with AI about <contact>" then the actual contact-specific items. Deliberately omits global boilerplate (system prompt, global Writing Style, general personalization, output contract).
- Both inspectors must resolve from the SAME prompt construction — a review that drifts from bytes sent is worse than none.

### 12. Generation failures & sanitized diagnostics (AICFG-13/14)
- Failures translate to human-readable categories (see Copywriting) with an optional **Details** affordance showing ONLY sanitized metadata. Compose state is preserved; never silently fail over.
- No user-facing diagnostic dump: the sanitized diagnostic event carries safe metadata only (operation, lane, model id, status/category, correlation id, build/OS version, approx token count, item count, elapsed time). It NEVER carries contact names, notes, memories, Group Notes, Off Limits text, personalization/Writing Style text, Message Focus text, prompt bodies, credentials, raw request bodies, generated output, or raw provider responses.

## Copywriting Contract

Copy direction is from the dossier (§B/F/N/V/AB/AF/AG/AH) and code (`CUSTOM_RETENTION_CAVEAT`). Exact wording may be tuned at implementation as long as meaning holds; counts (N, M) are runtime data.

| Element | Copy |
|---------|------|
| Primary CTA — OpenRouter | **Connect with OpenRouter** |
| Primary CTA — model pick | **Choose this model** |
| Primary CTA — save config | **Save** |
| Repair CTAs | **Reconnect** · **Replace key** · **Choose another model** · **Change AI connection** |
| Tertiary links | **Browse all models** · **Review existing…** · **Refresh Models** · **Preview What Orbit Sends** · **Preview with contact…** · **Details** |
| AI-off preservation note | "AI is off. Your connections, models, personalization, and permissions are saved and will return when you turn AI back on." |
| AI-off escape hatch | **Manage saved connections** |
| Inactive-connection marker | "Saved" |
| Empty — Personalization Context | Heading: "No personalization yet." · Body: "Add a section or paste text to tell Orbit how you write and what matters to you." |
| Empty — permission review | "AI can't access any contact information yet." |
| Empty — model catalog offline | (never blank) render cached models; if truly none: "No models available. Connect and refresh to load the catalog." |
| Loading — catalog refresh | "Refreshing models…" (non-blocking; cached list stays visible) |
| Freshness indicator | "Updated {local date}" (via `formatLocalDate()`) |
| Type-default new-items note | "Changing this affects new items only." + **Review existing…** |
| Permission summary count | "AI can currently access information from {M} contacts · {N} items" |
| Compose contact review | "Sharing {N} items with AI about {contact}" |
| Context/cost estimate | "Estimated context · ~{tokens} tokens · ~${cost} input cost with {model}" |

| Needs Attention (Compose) | "AI needs attention" + repair route (no silent disappearance) |
| Custom endpoint caveat | "This is an endpoint you configured. Orbit can't control how it handles the data it receives." (`CUSTOM_RETENTION_CAVEAT`) |
| First-use disclosure | "Orbit only sends information you've allowed for AI. Your request is sent through {active connection path}. You can review exactly what Orbit sends at any time." |
| Error — connection | "AI connection needs attention." |
| Error — rate limit | "Rate limited — try again shortly." |
| Error — billing | "Insufficient credits or a billing issue with your provider." |
| Error — context | "Context too large for this model." |
| Error — provider down | "The provider is temporarily unavailable." |
| Error — custom endpoint | "Your custom endpoint returned an error." |
| Error — generic | "Couldn't generate a suggestion. Try again." |
| Bulk-enable impact confirm | "This will make {N} items across {M} contacts available to AI. Enable?" Confirm: **Enable access** |

**Destructive confirmations** (all via `ConfirmDialog`, destructive role — `danger` fill + `onDanger` label + `warning` glyph):

| Action | Confirmation copy | Confirm label |
|--------|-------------------|---------------|
| Disconnect OpenRouter | "Disconnect OpenRouter? The OpenRouter credential is removed from this device. Your model selection and personalization are kept." | **Disconnect** |

| Delete personalization section | "Delete '{title}'? This personalization section is permanently removed." | **Delete** |
| Bulk disable permissions | "Turn off AI access for {N} items across {M} contacts?" | **Turn off access** |

## UI Considerations

> Shape-rooted UI STATE coverage. Empty/error COPY lives in the Copywriting Contract above; this table references those rows rather than restating them.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|

| empty | Permission review (no AI-enabled info) | ✅ covered | Renders "AI can't access any contact information yet." |
| loading | Model catalog refresh | ✅ covered | Non-blocking "Refreshing models…"; cached list stays rendered (offline-safe read path) |
| error | Generation failure categories | ✅ covered | Eight human-readable categories + sanitized-only Details; Compose state preserved |
| error | Custom endpoint validation | ✅ covered | Invalid/non-public URL refused pre-persistence with `danger` inline copy |
| error | Model unavailable / Needs Attention | ✅ covered | Explicit warning notice + repair actions; no silent substitution |

| overflow | Assembled request exceeds model context window | ✅ covered | Explicit overflow notice requiring deliberate resolution — never silent truncation |
| zero-one-many | Permission summary & Compose contact-review counts | 🧪 backstop | Copy templates carry {N}/{M}; needs a device/held-out check that 0-item and 1-item render grammatically (no explicit fixture yet) |
