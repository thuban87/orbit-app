<objective>
Deliver the transparency and failure surfaces: the lightweight first-use disclosure, the whole-system
Preview What Orbit Sends (with optional contact preview), the separate Compose contact-specific review,
the eight human-readable generation-failure categories, and the sanitized diagnostic seam — all resolving
from the same prompt construction so what the user sees equals what is sent, and never leaking private
content into diagnostics.

Purpose: Transparency is only trustworthy if the inspector equals the payload, and the diagnostic seam is
only safe if it is a strict allowlist. Both are enforced here.
Output: `ai-diagnostics.ts`, extended `ai-suggestion-logic.ts` + `settings-ai-logic.ts`, `AIPreviewScreen`,
`AIFirstUseDisclosure`, `AIComposeContextReview`.

**Decisions honored (CONTEXT.md):** D-08 (lightweight first-use disclosure naming the real data path; exact-prompt first-send ack retired per ADR-079 — generation never gated on ai_ack_*), D-11 (sanitized diagnostics carry safe metadata only — never contact/prompt/output/credential content; no silent failover).
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| failure → diagnostics | a diagnostic event could leak private content if not allowlisted |
| resolved prompt → inspector | the inspector must equal the payload, and must not expose credentials |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-36-25 | Information disclosure | PII in telemetry | high | mitigate | ai-diagnostics is a strict node-pure allowlist; no free-text param; negative content scan test |
| T-36-26 | Information disclosure | credentials shown in inspector | high | mitigate | inspectors read only the resolved prompt string/sections; resolved object exposes no secret; test-asserted |
| T-36-27 | Repudiation/transparency | inspector/payload drift | high | mitigate | both inspectors call the single resolvePrompt; equality test |
| T-36-28 | Elevation/misconfig | restored install falsely Ready | high | mitigate | availability requires a valid local credential; a restored install with none routes to Needs Attention (ADR-049) |
| T-36-29 | Information disclosure | silent failover masking a wrong path | medium | mitigate | no silent failover; failure preserves state and surfaces a category + repair |
</threat_model>
