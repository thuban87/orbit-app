## Data-safety record

The invalid-id probe used a temporary, locally built Android sqlite helper only under
`run-as com.bwales.orbit` because the Pixel image has no `sqlite3` shell binary. The
app was force-stopped before direct access. Original values were recorded before the
write and restored exactly afterwards. The temporary helper was removed during closeout.

The Category/global precedence probe also force-stopped the app before a transaction.
The original state was: no `profile_category_presentation` row for category `1` and
`app_settings.profile_background_template_uid=NULL`. It temporarily used existing
app-owned template UIDs only, then deleted the category-1 row and restored the global
column to `NULL`; a re-read reported `0` rows and `<NULL>`. The System-picker probe
ended with exact original `galaxy_background=<NULL>` and
`standard_background=<NULL>`, confirmed by re-read. `files/orbit_sqlx` and its
`/data/local/tmp` copy were removed before relaunch.
