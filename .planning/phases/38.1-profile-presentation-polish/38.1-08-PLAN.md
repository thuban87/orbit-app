<objective>
Reduce normal Contacts Grid cards to two rows (name + recency) by removing the routine profile excerpt, while preserving the List view's third-line excerpt and the Grid's search-match third line. Per the real data flow (review H3), this is done by GridCard OMITTING its routine `line3` render in non-search mode — NOT by gating the `selectLine3` List selector, which would wrongly affect the List that §L keeps. Planned against the authoritative dossier §L (D-01); this is the code half of the §Q "Contacts Grid density" group (D-03) (the bounded audit + device UAT half is Plan 09).

Purpose: today normal Grid cards render a truncated third-line excerpt (the precomputed `line3` prop) that adds noise; §L keeps it out of the normal Grid but keeps it in List and keeps a distinct search-match line in Grid. The Grid card's search-match line comes from `searchResult`/snippet, independent of the routine `line3` prop, so removing the routine line3 render leaves search untouched.
Output: GridCard no longer renders the routine line3 in non-search mode (name + recency only); the host stops computing the now-dead card-mode line3; List (selectLine3/ListRow) untouched; component render tests.
</objective>
