## Pattern Assignments

### D-04 — Orrery overlay tint · `src/theme/tokens/surface.ts` (config, transform)

**Analog (sibling token in the same file):** `CARD_GLASS_OPACITY` + `cardTintOpacity()`, verified `surface.ts:151-181`.

Copy this shape for a NEW, decoupled treatment. Do NOT edit `CARD_GLASS_OPACITY` (galaxy `0.05` / standard `0.5`) or `cardTintOpacity` — they stay byte-for-byte (D-04).

```ts
// surface.ts:151-181 — the existing card model to MIRROR, not mutate
export const CARD_GLASS_OPACITY: Record<ThemePackage, number> = {
  galaxy: 0.05,
  standard: 0.5,
};
export function cardMatchesMode(themePackage: ThemePackage, mode: ResolvedMode): boolean {
  return themePackage === "galaxy" ? mode === "dark" : mode === "light";
}
export function cardTintOpacity(themePackage: ThemePackage, mode: ResolvedMode, density: SurfaceDensity): number {
  return cardMatchesMode(themePackage, mode)
    ? CARD_GLASS_OPACITY[themePackage]
    : SURFACE[themePackage].densityOpacity[density];   // <-- the OPAQUE fallback the new treatment must NOT do
}
```

**New treatment pattern:** add `ORRERY_OVERLAY_TINT_OPACITY: Record<ThemePackage, number>` + a pure `orreryOverlayTintOpacity(pkg, mode): number` that returns a **translucent** value in ALL FOUR combos — the key divergence from `cardTintOpacity` is it must NOT fall through to `SURFACE[pkg].densityOpacity` (the opaque band) in the mismatched regime (D-04: orrery canvas is a controlled dark render surface). Tint colour stays the `surface` token (`tintTokenKey: "surface"`, verified `surface.ts:102,114`).

### D-04 AA proof · `src/theme/tokens/surface.test.ts` (test, transform)

**Analog (the exact composite-over-brightest-pixel loop):** verified `surface.test.ts:186-206`.

```ts
// surface.test.ts:186-204 — copy this loop, substituting the orrery backdrop + new token
for (const [id, slot] of Object.entries(BACKGROUND_SLOTS)) {
  const pkg = slot.package;
  for (const mode of MODES) {
    const regime = cardMatchesMode(pkg, mode) ? "glassy" : "opaque";
    it(`${id} @ ${pkg}/${mode} (${regime}): foregrounds over the card on the brightest pixel meet AA`, () => {
      const palette = resolvePalette(pkg, mode);
      const tint = palette[SURFACE[pkg].tintTokenKey];
      const composite = alphaComposite(tint, slot.brightestPixel, cardTintOpacity(pkg, mode, "presentation"));
      assertForegroundsAA(composite, palette, `${id} @ ${pkg}/${mode} ${regime} card`);
    });
  }
}
```

**New block:** for each of 4 `pkg×mode` palettes compute `brightestOrreryPixel = max-luminance({palette.textPrimary, ...palette.starPalette})` (per `OrreryWorld.tsx:272-273,521`, `Polaris.tsx:30`), then `assertForegroundsAA(alphaComposite(palette.surface, brightestOrreryPixel, orreryOverlayTintOpacity(pkg, mode)), palette, ...)`. Primitives in scope already: `alphaComposite` (`surface.ts:324`), `contrastRatio`/`AA_NORMAL=4.5`/`AA_LARGE=3.0` (`contrast.ts:20,22,67`). The binding constraint is the mismatched palettes (Pitfall 2). Existing card AA tests MUST still pass (proves `CARD_GLASS_OPACITY` untouched).
