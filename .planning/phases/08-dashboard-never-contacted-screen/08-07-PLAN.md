## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-08-16 | Information disclosure | dashboard read path | high | mitigate | listDashboard scopes off_limits/ai/archived in-query; the screen performs no `.filter()` on private data; async on-device reads only; expo-image makes zero network calls for file:// avatars (local-first). |
| T-08-17 | Denial of Service (UI stall) | freshness / read path | medium | mitigate | Async `getAllAsync` only (never the sync variants that block the JS thread); cancelled-flag guard prevents stale-result clobber. |
| T-08-18 | Tampering (stale data after headless write) | freshness mechanism | medium | mitigate | Re-query on focus + AppState→active + pull-to-refresh — NOT the connection-scoped change listener, which is structurally blind to the headless widget/notification "mark contacted" write. |
