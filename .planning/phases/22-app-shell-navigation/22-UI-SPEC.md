# Phase 22 — UI Design Contract

> Visual and interaction contract for the App Shell & Navigation phase. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Platform note:** orbit-app is React Native / Expo (Android-first), local-first, portrait-locked. There is **no shadcn / no Tailwind / no web DOM** — shadcn is not applicable to RN and the registry gate below is N/A. The design system is the on-disk **theme-token** system in `src/theme/` (CLAUDE.md: *all* colours resolve through `useTheme().colors.*`; `theme-presets.ts` is the single file where a colour hex may appear, including in Skia). This spec documents the **existing** contract this shell must draw through, not a new one. Every value below was read from disk this session.
>
> **Scope reminder (CONTEXT D-04/D-05, RESEARCH):** Phase 22 owns *exposure and routing only* — the shell chrome (four-tab bottom nav, universal six-action FAB speed dial, shared contact picker, commit-truthful Quick Log snackbar, app bars, Back/Discard-Keep, insets/keyboard/haptics/a11y). It does **not** own the forms behind the actions it launches; four of the six FAB actions route to themed placeholder screens that Phases 24/33/34 replace.

## Spacing Scale

The codebase uses a **2/4-based scale that is NOT a strict 8-point grid** (grep of all `src/` style values, most-frequent first: `8`, `12`, `10`, `16`, `14`, `4`, `24`, `20`). This is the established reality; the shell must match it rather than impose an idealized 8pt scale that would clash with every existing screen.

| Token (de-facto) | Value | Usage in shell chrome |
|-------|-------|-------|
| xxs | 2–4px | Icon-to-label gap, hairline insets |
| xs | 6–8px | Speed-dial action row internal gap, chip padding |
| sm | 10–12px | List/picker row vertical padding, snackbar internal padding |
| md | 14–16px | Default screen gutters, app-bar horizontal padding, FAB label padding |
| lg | 20–24px | Section breaks; FAB offset from screen edge |
| pill | 999 | Fully-rounded chips / FAB / snackbar affordances |

Exceptions (shell-specific, deliberate):
- **FAB:** 56×56px, `borderRadius: 28`, anchored `right: 20`, `bottom: 28` (existing `AddSpeedDialFab` geometry — keep it so the universal FAB lands in the same place).
- **Minimum touch target: 44×44px** for every shell control (tab items, FAB, FAB action rows, picker rows, snackbar Undo/Retry, app-bar Back and overflow). This is the established codebase target (`FilterChipRow`/`OverflowMenu`/`SegmentedControl` all `minHeight: 44`) and a hard SHELL-14 requirement. Use `hitSlop` where the visual is smaller than 44px.
- **Bottom content clearance:** screens must clear the tab bar + safe-area inset via `useBottomTabBarHeight()` — never a hardcoded bottom padding (RESEARCH "Don't Hand-Roll"; dossier §J forbids ad-hoc inset math).

## Typography

The codebase uses more than the template's 3–4 sizes (grep: `13`, `15`, `16`, `24` dominant; `18`/`20`/`22` for headings; weights `400`/`600`/`700`). Documenting the **shell-relevant** subset — the shell must not invent new sizes/weights.

| Role | Size | Weight | Line Height | Shell usage |
|------|------|--------|-------------|-------------|
| Body / control label | 15–16px | 400 (regular) | ~1.4 | Picker row names, snackbar message, discard-dialog body |
| Emphasis / active | 15–16px | 600 (semibold) | ~1.4 | Active tab label, FAB action labels, primary snackbar action |
| Small / secondary | 13px | 400–600 | ~1.35 | Tab captions under icons, picker secondary line (recency/snoozed marker), "+N more" |
| App-bar / screen title | 18–22px | 600–700 | ~1.25 | Root tab branded title, child-screen title |

Rules:
- Weights are limited to **400 / 600 / 700** (no new weights; the single stray `500` is not a shell convention).
- Text must **reflow, not truncate or shrink** under OS font scaling (SHELL-14 / a foreshadow of THEME-07) — do not lock chrome heights that would clip scaled labels; tab labels may wrap or hide-label at large scale rather than ellipsize the icon away.

## Color

60/30/10 mapped onto the `space-dark` dark palette (the only shipped palette; `light` falls back to `dark` until Phase 23 authors it).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `background` `#0B0E1A` | App background behind tabs, screens, scrims |
| Secondary (30%) | `surface` `#141828` / `surfaceElevated` `#1D2235` | Tab bar surface, app bars, picker sheet, snackbar body, speed-dial rows, overflow menu |
| Accent (10%) | `accent` `#6C8CFF` | See reserved-for list below |
| Destructive | `danger` `#E5484D` | Destructive-action emphasis only (e.g. the "Discard changes" affordance in the unsaved-changes dialog); native `Alert` `style:"destructive"` needs no token |

Accent reserved for (explicit — never "all interactive elements"):
- The **active** bottom-tab item (icon + label) — inactive tabs use `textSecondary` over `surface`.
- The **FAB** resting fill and its expanded primary affordance.
- The Quick Log **success snackbar's Undo** action, and the error snackbar's **Retry** action.
- The **primary/confirming** control in the shared contact picker and the Discard/Keep dialog's **Keep** (non-destructive) action.
- Selection/focus emphasis (e.g. the pressed picker row) — via `accent` at reduced opacity or an `accent` border, not a filled-accent blanket.

Not accent-driven: ordinary body text (`textPrimary`), secondary/caption text (`textSecondary`), inactive tabs, dividers/borders (`border` / `borderStrong`), scrims (`background` at opacity). **Relationship status is never conveyed by the shell** — status hues (`statusStable`/`statusWobble`/`statusDecay`/`rogue`) belong to contact cards/orrery, not to shell chrome; the shell must not repurpose a status token for a nav/FAB affordance.

Scrims (speed-dial backdrop, picker backdrop, dialog backdrop): `background` at opacity (the codebase idiom — e.g. dropdown scrim `colors.background` @~0.85), never a raw `rgba()` literal.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (FAB) | FAB has no single label; expanded it reveals **exactly six actions in fixed order** (CONTEXT D-05): **Add Contact**, **Quick Log**, **Log Contact**, **Group Log**, **Update Contact**, **Memory**. These labels are locked — any five-action text is stale (AF-03). FAB button `accessibilityLabel`: "Add / capture" (collapsed), announced open/closed. |
| Quick Log — success | Snackbar: **"Logged"** with an **Undo** action. Shown **only** after `recordTouchpoint()`'s transaction resolves (SHELL-11 — never optimistic). Haptic: success. |
| Quick Log — error | Snackbar: **"Couldn't log"** with a **Retry** action. Shown on `.catch()` — the app must never claim success without a commit. Haptic: warning. |
| Undo confirmation | On Undo tap, silently remove the just-written interaction and recompute recency (no second snackbar; the row simply disappears). |
| Missing-contact deep link | Native `Alert`: **"This contact is no longer available."** then reset to Dashboard root (existing verbatim copy at `widget-linking.ts`; this IS the SHELL-05 requirement — keep it, do not reword lightly). |
| Empty-state — contact picker (no matches) | Picker body when a search yields nothing: **"No matching contacts"** (see UI Considerations `empty`). Archived contacts surface via search only; snoozed contacts appear with a snooze marker but remain selectable. |
| Empty-state — contact picker (no contacts at all) | If the user has zero contacts, the picker shows **"No contacts yet"** with a pointer to Add Contact. |
| Destructive confirmation (unsaved work) | Leaving a workflow with meaningful unsaved changes prompts a dialog (SHELL-07): title **"Discard changes?"**, actions **Keep editing** (non-destructive, `accent`) and **Discard** (destructive, `danger`). |
| Placeholder routes (unbuilt FAB actions / Group Events) | Themed placeholder screen copy: **"Coming soon"** heading + one line naming the owning phase's feature (e.g. "Group logging arrives with Group Events."). Registered as real semantic routes (deep-link-ready) per the `types.ts` placeholder pattern — Phases 24/33/34 swap the screen with zero shell change. |

Tone: terse, sentence-case, verb-first for actions. No exclamation marks. Snackbar copy stays ≤ ~2 words for the action label so it fits the 44px target.

## UI Considerations

> Shape-rooted UI *state* coverage for the shell surfaces (tab shell, FAB speed dial, contact picker, Quick Log snackbar, app bars). Empty/error COPY lives in the Copywriting Contract above; this section covers state coverage and references those rows.

Applicable state considerations resolved: 6 covered, 2 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | contact-picker (list-collection) | ✅ covered | Zero-match search renders "No matching contacts"; zero-contacts renders "No contacts yet" + Add-Contact pointer (Copywriting rows). Archived excluded from default list, reachable via search only. |
| loading | contact-picker (async reads: favourites/recency/alpha) | ✅ covered | Picker opens immediately with a calm loading state; reads are on-device SQLite (fast) — no blocking network on any shell read path (CLAUDE.md local-first). No spinner-over-blank-tab: the migration gate keeps the navigator unmounted until the DB is ready (Pitfall 2). |
| error | Quick Log write (snackbar) | ✅ covered | Commit-truthful: success snackbar only on resolved transaction; failure → "Couldn't log" + Retry (SHELL-11). Never a success claim without commit. |
| populated | tab shell / speed dial (static-content) | ✅ covered | Four tabs always present; FAB always shows the six fixed actions regardless of data or current tab. |
| overflow | speed-dial actions / picker rows (list-collection) | ✅ covered | Six actions is a fixed, non-scrolling set (fits one column above the FAB). Picker rows virtualize via `FlatList`; long contact lists scroll, not clip. |
| zero-one-many | FAB context (from Profile vs global) | ✅ covered | From a Profile the picker is pre-selected/skipped (SHELL-09); global entry opens the shared picker; Group Log routes directly with no shell pre-picker (D-05). |
| long-text | tab labels, FAB action labels, picker names (static-content) | 🧪 backstop | Under large OS font scale labels must reflow/wrap or hide-label rather than shrink or ellipsize the icon away (SHELL-14). Verify on-device with max font scale (held-out visual UI-state check on the Pixel). |
| partial | partially-swiped/transient layer on tab retap & Back (list-collection) | 🧪 backstop | Active-tab retap and Back both dismiss the topmost transient layer (speed dial / picker / open modal) FIRST, then act (SHELL-02/03). System Back == visible Back via one resolver. Verify on-device: Back with speed dial open dismisses the dial, does not exit the app. |
