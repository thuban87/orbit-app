# Phase 38.14 Plan 05: Interaction sheet and History Summary

**The interaction sheet now shows the note right after When, hides "Connected" for In Person and event children, and keeps Edit and Delete pinned at the bottom (they stack when they don't fit). "Make this an event" is a visible text button, and a delete ends with an "Interaction deleted" snackbar. History's Intensity now says "2 logs · about ⅕ of your monthly rhythm" and the bar shows that share. The heatmaps carry month labels, weekday initials and preset captions, the Year grid is centred, and In Person and Bound / Unbound rows have their own icons.**

## Accomplishments

- **D-66 / D-26 / D-30 / D-33 / D-64 (sheet rows).** `buildDetailRows` now takes `GroupLinkedDetailInput`, a superset of the old input type, so existing callers still type-check. It returns Channel, When, Note, Direction, Connected, Tone, Duration. Channel and direction values come from `CHANNEL_LABEL` / `DIRECTION_LABEL`, and an unmapped value shows as itself. A legacy channel now reads "Unspecified" / "Other" where the row used to be omitted. The Connected row is dropped for `channel === "In Person"` and for any record where `isGroupLinked({ groupEventId })` is true.
- **D-66 / D-26 (sheet actions).** The Sheet gets `scrollBody={false}`. The header, rows and group card scroll in an inner `ScrollView`, and a pinned block follows it:
  - the error line, when there is one;
  - "Make this an event", as a tertiary Button, shown when the interaction is not group-linked and `onConvertToGroup` is set;
  - `ConfirmActions`, with Edit / View profile / Delete.

  The `OverflowMenu` and its import are gone, and so is the old no-wrap action-row style. `InteractionDetail.tsx` was added to `EXPECTED_OPT_OUTS`.
- **D-58.** After `deleteTouchpoint` → `notifyWidgetDataChanged()` → `bumpShellRefresh()`, the sheet shows `showSnackbar({ kind: "warning", label: "Interaction deleted" })` and then calls `onDeleted()`. There is no Undo. Both hosts (HistorySection, GroupEventDetailScreen) get the snackbar with no changes on their side.
- **D-65.** Four pure helpers:
  - `intensityShare` = count × cadence ÷ window. It returns 0 for any input that is not positive or finite, so it never gives NaN or Infinity.
  - `intensityShareCaption` builds the share line.
  - `averageGapPhrase` builds the gap line and never says "0-day".
  - `rhythmName` names the contact's rhythm.

  `IntensityLine` shows the share line, then the gap line (capitalised, left out when the gap is unknown). The empty state is unchanged. `IntensityChart`'s bar is `clamp(intensityShare(...), 0, 1)`.
- **D-35.** `src/services/intensity-logic.ts` and `src/services/history/intensity-window.ts` are untouched (`git diff --name-only 73e434c0..HEAD` lists neither). `intensity-logic.test.ts` and `profile-metrics.test.ts` pass with no edits.
- **D-36 / D-37.**
  - **Year:** a `MONTH_SHORT` caption line (textSecondary, `testID ${testID}-year-month-<row>`) sits directly above each two-week row that holds a month's 1st. The Year grid has `alignSelf: "center"`. `yearCellEdge` (13) and the 8 / 4 gaps are unchanged, so a row is still 238 dp.
  - **Month:** a weekday-initials row (S M T W T F S, Sunday-first like `buildMonth`) sits inside the day grid at the cell width and gap, so `fitHeatmapCell` is untouched.
  - **Cycles:** each preset chip carries the caption "cycles" and the spoken label "Last N cycles".
- **D-47.** Three new names in the icon registry: `in-person` (hand-left), `bound` (link) and `unbound` (unlink). `CHANNEL_ICON["In Person"]` and `EVENT_ICON.bind` / `unbind` use them. No History filter was added (D-06).
- **D-33 (History).** The stream row's local `DIRECTION_LABEL` is deleted. The row reads `DIRECTION_LABEL` and `CHANNEL_LABEL` from the glossary for the visible channel label and the spoken label.
