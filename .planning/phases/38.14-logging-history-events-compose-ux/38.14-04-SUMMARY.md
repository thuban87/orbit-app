# Phase 38.14 Plan 04: Logging forms agree Summary

**All five `TouchpointRefineForm` surfaces now offer Message / Call / In Person, plus a record's own Other / Unspecified only when the saved record holds it. The date dialog cannot pick a day after today. A saved custom duration reopens as its minutes, and the "None" readout is gone. Controls read their labels truthfully from one glossary map. Log Interaction, Edit interaction and Group Log keep the focused field above the keyboard. An empty History day opens at the current time of day, and saving Edit interaction confirms "Changes saved" and publishes the widget notify plus the shell refresh.**

## Accomplishments

- **D-60 channels.** `channelOptionsFor(stored)` returns the three, plus `{ other, "Other" }` or `{ unspecified, "Unspecified" }` only for that stored value. The form's internal five-entry list is deleted and its default is now the three. The hosts:
  - Edit interaction keeps a new `savedChannel` state, set in `load` from the loaded row.
  - Edit Event uses `event.channel` from the refreshed saved event.
  - `ParticipantOverrideEditor` uses `participantDraft(participant, event).value.channel`.
  - Group Log passes `ORDINARY_LOG_CHANNEL_OPTIONS` and keeps its In Person default.
  - There is no "No channel" choice anywhere.
- **D-24.** The date dialog has `maximumDate={parseLocalDateTime(now)}`. The `isCombinedInFuture` guard for today's time stays.
- **D-31.** `customMinutesSeed` turns 1020 s into "17" (a preset or none gives ""). `customMinutesDisplay` keeps what the user typed while it matches the value, and otherwise follows the stored duration. `showDurationReadout` hides the readout for none.
- **D-39 (form half).** The date control's accessibility label is "Date & time", the same as its visible label. The More / Hide options toggle reads `moreOptionsLabel` both visibly and aloud.
- **D-33 / D-64.** `CHANNEL_LABEL` and `DIRECTION_LABEL` are now in `src/constants/glossary.ts`. The channel options (log-interaction-logic) and the direction options (the form) read from them, so Direction now shows Outbound / Inbound / Mutual instead of lower-case values. Stored values are unchanged.
- **D-34.** The three hosts run `useKeyboardCentering`, wrap their content in `<KeyboardCenteringProvider value={centering}>` and render `{bottomSpacer}` last. The form's note and custom minutes, and Group Log's title and Group Note, call the context on focus and blur. All of them stay raw `TextInput`s, so the multi-line notes keep their line breaks. The provider's scope comment now names 38.14 D-34.
- **D-61.** `seedOccurredAtForDay` replaces the midnight seed. With no prefill (the empty month), the form still seeds now. `history-section-logic.test.ts` is green and unchanged.
- **D-58.** After `editTouchpointFull` the save runs `notifyWidgetDataChanged()`, then `bumpShellRefresh()`, then the success snackbar "Changes saved", then goBack.
