### Performance (release build, Pixel 6 Pro only)

**Thread coverage:** `dumpsys gfxinfo` measures only the UI/render thread. It says nothing about the JS thread, where React Native jank usually lives. "High input latency" counts are inflated by adb-injected swipes and are not a user-facing signal. `am start -W` TotalTime runs to the activity's first frame, not to the JS-rendered Digest content.

Cold start (`am start -W`, screen on, LaunchState COLD): **151 / 156 / 163 ms; median 156 ms.** The screen-off runs report LaunchState UNKNOWN with WaitTime ~3010 ms, because nothing draws while the screen dozes. That is not a launch time.
