# Phase 38.12 Plan 21: Import lifecycle effects, Import review and bulk setup Summary

**Every import path (single review, bulk driver, Review matches import-new, bulk Combine) now awaits one `applyImportLifecycleEffects(exec, { anyBound, anyUnbound })` that also schedules Unbound birthdays when that setting is on. A finalize failure after a contact is created no longer reads as a failed import. Import review uses Edit Contact's birthday control, a button-role Import and effective-region warnings. Bulk setup reads Bound then Unbound and shares one lifecycle sanitiser with resume. The flow host now reaches ImportComplete from every bulk and single-import exit.**
