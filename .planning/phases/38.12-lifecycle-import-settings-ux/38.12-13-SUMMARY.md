# Phase 38.12 Plan 13: Import photo budget and already-linked review Summary

**Before an import with backup encryption on, Orbit now estimates the backup through the real exporter (stat-only photo sizes plus 62 KB per incoming photo contact). If the photos may not fit under the encrypted cap, or the size cannot be checked, it shows a four-choice sheet (smaller / without / continue / back) on both picker paths. An already-linked single pick shows "Already in Orbit as <name>" with Open instead of an editable form.**

## Accomplishments

- `import-photo-budget.ts` builds the export manifest with a stub reader. The reader records each photo's file size and returns a fixed non-empty placeholder, so a saved Profile background no longer throws. The size is the UTF-8 JSON length, minus the placeholders, plus ceil(size×4/3) per photo. If the exporter still fails, the result is null and is logged.
- `routePickedImport` runs the guard before `acceptPickedContacts`:
  - With encryption off, it does no estimate and asks nothing (F-5).
  - Over the cap, it asks with `{ projectedBytes }`. A null estimate asks with `null`, which shows the unknown-size sheet (E-1).
  - "Go back" discards every picked copy and returns `cancelled` with no session.
  - With no decider, the import fails closed (F-3). A failed encryption read counts as ON.
- "Smaller" never keeps a full-size-only photo:
  - When a thumbnail exists, it uses the thumbnail.
  - Otherwise it downscales to 256 px.
  - If the downscale fails, the photo is dropped.
  - A photo already no wider than 256 px is kept as is and not discarded (B-9).
- `PhotoBudgetSheet` and `usePhotoBudgetPrompt` are hosted on Settings → Contacts (system picker, through startContactImport) and on the legacy picker. On the legacy picker, Go back keeps the list and its selection.
- Host forwarding: startContactImport carries `host` to the legacy route and into routePickedImport, which passes it to ImportReview and BulkImportSetup (A-1, D-110).
- D-137: the legacy picker reads `{ preferFullSize: true }`, and Settings' `readByLookupKeys` forwards the options it receives from withNotes.
- D-53: the review's load resolves an actively linked pick (`resolveAlreadyLinked` + `finalizeSessionIfTerminal`) and renders `ImportReviewAlreadyLinked`, which has Open and Done; Done, header Back and system Back go to `finishFlow`. onImport's own `already_linked` branch is kept as a race fallback.
- Task 4: the API-37 picker-session reader now checks `Event.TYPE_BIRTHDAY` like the other two readers (grep count 3).
