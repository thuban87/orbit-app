# Phase 38.12 Plan 23: Import complete names and the legacy picker Summary

**Import complete now shows only the outcomes that happened. Each one lists the people in it: Imported, Linked, Already in Orbit, Skipped by you, Skipped — no name, Couldn't import and Needs review. Every row lands in exactly one outcome, sorted by its current status, so a person rescued by Retry appears once, under Imported. Tapping an imported or linked name opens that person through the flow host. The legacy picker for phones below SDK 37 now has a "Not now" way out on both denied states, a retry when the contact read fails, and keeps the user's selection when an import fails. Import runs inside the import-flow guard and carries the host. The lifecycle sanitiser moved into one leaf module.**

## Accomplishments

- **Summary buckets (D-55, F-1, B-2, B-3):**
  - `summaryBucketFor` is one switch on `row_status`. `imported` and `linked` ignore any leftover `failure_reason`.
  - Only `skipped` rows split further: `already_linked` goes to Already in Orbit, `name-required` to Skipped — no name, and a NULL reason to Skipped by you. Any other reason goes to Couldn't import.
  - One `LEFT JOIN contacts` query names every row.
  - `birthdayUnreadable` keeps its meaning: imported rows with a present but unreadable phone birthday.
- **Import complete (D-55, D-109, D-110):**
  - A titled card ("Imported (3)") renders only for a non-zero outcome.
  - Each card lists up to `IMPORT_COMPLETE_NAME_PREVIEW` (5) names, then "Show all".
  - Imported and linked names are 44 dp buttons labelled "Open <name>" that call `openContactFromFlow(navigation, host, contactId)`.
  - The birthday notice appears only when its count is above zero.
  - "Review possible matches" passes `host: route.params.host`.
- **Legacy picker (D-57, D-110):**
  - Denied state: "Try again", plus "Open Settings" after 2 denials as before, plus "Not now".
  - Permanently denied: "Open Settings" and "Not now".
  - "Not now" calls `exitFlow(navigation, host ?? DEFAULT_FLOW_HOST)`.
  - A failed contact read shows an EmptyState: "Couldn't read contacts", with "Try again" re-checking access and reloading.
  - When an import fails, the list and the selection stay and an error snackbar appears.
  - The import runs inside `withImportFlowActive`, and `routePickedImport` gets `host`.
  - An empty search shows "No contacts match" with a "Clear search" action.
  - The body has a bottom safe-area inset under Import.
  - All text goes through AppText roles. Permission actions use the shared `Button`.
- **Folded mid-phase (from 38.12-21's deferred items 1-2):**
  - `src/db/import-lifecycle.ts` holds `ImportLifecycle`, `UNBOUND_IMPORT` and `sanitiseImportLifecycle`.
  - The DAO's `effectiveSessionLifecycle` now calls the shared sanitiser and re-exports the type and the constant.
  - `import-session-read.ts` imports the sanitiser from the leaf module, not from a screens file.
  - `bulk-import-setup-logic.ts` re-exports it for its existing importers.
