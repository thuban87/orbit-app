# Phase 38.12 Plan 09: Backup Format 9 Favourites and Honest Restore Counts Summary

**Backups now carry favourite membership in format 9. Replace-all restores exactly the backup's favourites, and Merge only ever adds favourites. Old mutes come back as indefinite snoozes. The restore reports people counts and its steps, and the preview compares this phone's people with the backup's.**

## Performance

- **Duration:** about 20 min

- **Tasks:** 3 (1 tracer, 2 TDD)
- **Files modified:** 19

## Accomplishments
- **Format 9 (D-112).**
  - The new `FORWARD_MIGRATIONS[8]` step gives every contact in a v8 file `favourite: 0`.
  - `favourite` is validated as a 0/1 marker at the parse boundary (T-38.12-21).
  - Export emits membership for every contact, including an Unbound contact's dormant rank (D-21).
  - `BACKUP_FORMAT_VERSION = 9`, so an older app refuses a v9 file with "update first".
- **Restore semantics (D-113).**
  - Replace-all ranks the backup's favourites 0..n-1.
  - Merge runs a separate pass over every backup favourite and sets only a missing rank. It never clears a rank, never touches `modified_at`, and never resurrects a contact a newer tombstone deleted.
  - A Merge whose only change is such a favourite now applies it, instead of returning early as "nothing to do".
- **Legacy mute (D-98, D-134).** The single contact upsert maps `remindersOff = 1` to `snooze_until = '9999-12-31', reminders_off = 0`. This covers every format and both modes, and closes the gap 38.12-01 flagged.
- **People counts (D-59).** The applied result gains `people: { before, restored, removed }`. These counts are read inside the transaction before `replaceAllReset`. The existing row totals are kept for their consumers (38.12-18 rewires them).
- **Progress (D-69).** `onProgress` reports `"safety-backup"` just before the Replace-all safety backup runs, and only when one runs. It then reports `"restoring"`.
- **Preview data (D-60).**
  - New `countContactsNotInBin`.
  - New `loadBackupForRestorePreview(exec, input)`, which adds `phoneContacts`. The file side adds `backupContacts`.
  - `relatedRowCount` now sums every row array in the manifest except contacts and tombstones.
