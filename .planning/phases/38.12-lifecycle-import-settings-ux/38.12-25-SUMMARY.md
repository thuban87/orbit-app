# Phase 38.12 Plan 25: Resume prompts ask once; paused work on Settings rows Summary

**The import and check resume prompts now ask once per paused session (a `resume_prompted_at` marker written when the sheet is actually shown, cleared on Resume), share one prompt sheet, and the paused work stays findable as "Finish your import / Finish adding photos / Finish your check (N left)" on the Settings rows, with a Resume / Discard and start new / Cancel check before a new import.**

## Accomplishments

- **Marker DAO** (`src/db/resume-prompt-dao.ts`): four `*Core` writers for composition inside an open transaction, and four locked wrappers each running its Core in `inWriteTransaction`. Marking keeps the first time (`WHERE resume_prompted_at IS NULL`); neither writer touches `modified_at`. No Core is called outside `src/db/`.
- **Side-effect-free reads (D-56):** `getNewestResumableImportSession` keeps today's resumable set (pending OR `PHOTO_OUTSTANDING`) and returns `peopleLeft` (pending + needs_review + failed, F-2), `photosLeft` and the marker. `discardStaleImportSessions` is the separate launch cleanup, touching only older *pending* sessions. The reconcile side mirrors it (`getNewestResumableReconcileSession`, `discardStaleReconcileSessions`, `countReconcileCardsLeft` over `card_status IN ('unresolved','partial')`). The old discarding reads are removed and every consumer moved.
- **Sweeps:** both run their stale cleanup first, then offer the newest session only when its `resume_prompted_at` is NULL and no screen has it open.
- **Prompts:** both write their marker on visible mount through the locked wrapper and clear it on Resume (best-effort, logged). The import prompt says "N people are left to import. Discard drops them; nothing already imported changes."; the check prompt says "N contacts are left to check. Changes you already applied stay applied." Both add **Not now**. The photo-only import copy and its "Later" stay as they were (B-6). `resumeImport` is exported unchanged.
- **Shared layout:** `src/components/ResumePromptSheet.tsx` holds the modal, scrim, bounded ScrollView, actions-outside-scroll, safe-area insets and onAccent label. Both prompts render through it.
- **Settings → Contacts & Relationships:** on focus it reads the newest paused import and check and shows them on their rows. Tapping Import contacts while people are left asks `choose({ title: "Finish your last import first?", confirmLabel: "Resume", secondaryLabel: "Discard and start new", cancelLabel: "Cancel" })`. Resume clears the marker and goes through `resumeImport` (a failed-only session lands on Import complete). Discard drops the session and starts the new import. If only photos are left, the row opens the photo recovery and no pre-check is asked (B-6).
