# Phase 38.12 Plan 15: Settings → AI tells the truth Summary

**AI Connection now reloads on focus and reads each lane's key presence on the device. The active lane with a key reads "Connected", with "Change model" as its primary button and Disconnect demoted. The AI hub shows "OpenRouter · <model name>" with Ready / Needs attention, has one "Style and Context" row, and its master switch reads "Use AI suggestions". No provider call was added anywhere.**

## Accomplishments
- **AI Connection (D-84, K-36).**
  - `connectionCardState` takes `hasCredential`. The active lane with a credential is "connected"; an active Custom lane counts as connected without one, since its credential is optional.
  - The page reloads on every focus (`useFocusEffect`, replacing the mount-only effect).
  - `readLaneCredentialPresence` reads presence for each saved lane through `readCredentialPresence`. Only booleans reach UI state.
  - A connected card leads with a primary "Change model". The lane's connect action steps down to a secondary button ("Reconnect", "Replace key" or "Save changes"), and Disconnect / Remove key is a tertiary control. The confirm dialog is still destructive.
  - "Recommended" and the default OpenRouter expansion stay (D-17).
- **Custom Endpoint prefill (D-88).** The endpoint and model fields fill from the saved connection on load, until the user types in them. The credential field is never prefilled. A failed load shows the load error, and a good reload clears it.
- **Model picker (D-88, 38.4 #21).** The standalone "Current model" row shows the catalog name. It falls back to the id only when no name is known.
- **AI hub (D-85, D-126, D-130, D-88).**
  - `loadAiHubSnapshot` returns readiness, the active connection and the model's display name, all from the reads the hub already made.
  - The Connection row shows "<provider> · <model name>" with "Ready" / "Needs attention" under it. The Model row shows the model name.
  - One "Style and Context" row opens AI Personalization at the top.
  - The master switch reads "Use AI suggestions".
  - Each focus reload clears the error first and again on success.
- **Shared row and card (D-119).** The master switch, the hub rows and the AI-off row are `SettingsRow`s in `SettingsSectionCard`s, and every testID is kept. AI Connection's sections ("Recommended", "Advanced Setup") are `SettingsSectionCard`s.
- **Fold (38.12-16 deferred item 2).** The inline personalization edit form reads "Edit section". The Add form still reads "New personalization section".

## Decisions Made
See `key-decisions` above. Two of them are worth reading in plain terms:
- On a connected card, the lane's own connect button stays but steps down to secondary, with a label that fits a connected lane. Removing it would leave no way to recover from an expired OpenRouter token, short of Disconnect then Connect. The labels reuse existing repair wording: "Reconnect" and "Replace key". "Save changes" (Custom) is new.
- The Connection row shows provider and model, and the Model row also shows the model name. Each row shows its own current value, so the name appears twice.
