## Phase Boundary

**Objective:** Make the people-lifecycle screens (Bin, Restore, Bind/Unbind, snooze), merge, Check
linked contacts, import and every Settings page follow the 38.9 standards and give clear outcomes;
fix the correctness defects found there (re-prompting linked-contact checks, favourites lost on
restore, a Bin Profile that pretends to be live); build Phase 39's possible-match tap (39 D-75) and
the truthful AI connection state (39 D-100); and leave the interfaces Phase 39's first run needs.

**In scope**
- Lifecycle on the Profile: Bin Profile banner and gating (D-34, D-35, D-93); Restore/Bind/Unbind
  feedback with Undo (D-32, D-33); no Snooze while Unbound (D-94); mute folded into Snooze (D-96,
  D-98); star on Unbound (D-36); Bind card shows the saved frequency (D-95); ⋯ sizing (D-42).
- Bin and Unbound lists (D-31, D-39, D-40); Unbound row in Settings (D-97).
- Merge: Profile entry (D-99), searchable picker (D-43), complete summary (D-44), photo-field fixes
  (D-129, D-131), per-person update from Contacts (D-100).
- Check linked contacts: stop re-prompting (D-45), apply semantics (D-47, D-102), feedback and
  wording (D-46, D-48, D-49, D-103, D-104), paused-check behaviour (D-105).
- Import: Review matches rebuilt as list + sheet (D-51, D-52, D-107), already-linked check (D-53),
  import screens (D-54, D-108), Import complete (D-55, D-109), flow endings (D-110), paused import
  (D-56, D-111), LegacyContactPicker (D-57), 38.4 leftovers (D-58), full-size photos (D-118).
- Backup and restore: favourites in a v9 format (D-112, D-113), restore result/preview/confirm
  (D-59–D-61, D-66, D-67), focused restore pages with steps (D-69, D-114), backup folder and file
  names (D-62, D-116), Back up now (D-115), export dialog, titles, icons (D-63–D-65), intake
  hardening (D-117), passphrase show/hide (D-124), 39 restore interface (D-68).
- Custom fields, categories, Systems: error state and tap-to-fix (D-70), Review now (D-121),
  summary grammar (D-71), Quarantine copy (D-72), category delete (D-73), labels and builder (D-74–
  D-76), history screen (D-106), one list pattern (D-120).
- Settings pages: shared row and card on every sub-page (D-119), Notifications (D-77, D-78), phone
  region (D-79), Appearance (D-80, D-81, D-82), labels (D-83, D-130), About line (D-125).
- AI settings: K-36 (D-84), hub values and rows (D-85, D-126), sections and permissions (D-86,
  D-88), Writing Style (D-87, D-127), Preview (D-89, D-128).
- Layout-template Save (D-90), stale docs (D-91), Phase 39 amendment rows (D-92).

**Out of scope**
- Writing Orbit's contact info back to the phone's Contacts → backlog (D-101).
- About licences → Phase 40 (D-123).
- Showing the picked backup file's name (rejected, D-122).
- Search on the Bin list (not requested; ledger N-06).
- Phase 39's first-run entries and exits (restore from Acquire, import cancel/deny, finish on
  Digest, Tutorials row) — 39 builds them on this phase's interfaces (D-18).
- Accessibility-label sweep and large-text items → Phase 40 (39-LEDGER Batch 14 R3).
- Renaming any canonical term (D-05); "Deep Space" (D-26).

**Preserved behavior**
- Restore and permanent delete only in the Bin; Move to Bin confirms with no Undo; no Delete on the
  Profile; the Bin never empties itself (D-10, D-20, D-93).
- Unbind stays a confirmed, plain-styled ⋯ action (D-11); purge keeps its impact summary (D-02).
