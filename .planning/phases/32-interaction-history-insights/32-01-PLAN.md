<objective>
Ship the irreversible on-device data foundation the whole phase stands on: migration 025 (Tone/channel value remap + nullable `duration` seconds + `allow_ai INTEGER NOT NULL DEFAULT 0` on `interactions`, plus `history_lens`/`history_cycle_count` on `app_settings`), every literal consumer of the old `quality`/channel vocabulary updated in lockstep, and the shared `TouchpointRefineForm` extended with Tone/channel labels, an optional Duration control, and an Allow-AI toggle.

Purpose: This is the highest-risk work in the phase (RESEARCH: "60% data-layer surgery"). A partial vocabulary rename silently corrupts AI context and the weekly digest on real users' unreachable devices; a wrong default on `allow_ai` reverses an owner privacy decision. Getting the migration + consumer lockstep right unblocks the aggregation seam (Plan 03), the Edit route (Plan 04), and every UI surface.
Output: migration 025 + its test, database.ts registration (TARGET_VERSION=25), remapped read/DAO consumers, extended refine form, declare-only backup allowlist.
</objective>
