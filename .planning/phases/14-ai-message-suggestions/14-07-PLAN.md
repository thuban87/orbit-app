The module needs no manifest permission beyond the app's existing INTERNET grant; keep `AndroidManifest.xml` minimal like the analog. Add OkHttp to the module `build.gradle` only if it is not already resolvable from the React Native classpath.</action>

| Custom URL host → DNS resolution | A user-controlled hostname may resolve to a private/LAN address (DNS-rebinding / SSRF). |
