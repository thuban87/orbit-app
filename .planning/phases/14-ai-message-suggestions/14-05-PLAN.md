<threat_model>
## Trust Boundaries

| Boundary | Description |
|---|---|
| profile navigation → Compose | Serializable intent asks Compose to initiate a potentially billable request. |
| async provider response → editable draft | Untrusted asynchronous completion can alter user-authored text. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-14-14 | Tampering | draft replacement | critical | mitigate | Pure lifecycle requires request-id freshness and explicit confirmation before replacing a non-empty draft. |
| T-14-15 | Denial of service | Compose request | medium | mitigate | One active request with Cancel, timeout, unmount/navigation cleanup, and stale-result invalidation. |
| T-14-16 | Repudiation | profile request intent | medium | mitigate | Consume-once route state prevents duplicate generation on refocus/re-render. |
| T-14-17 | Elevation of privilege | generation side effects | high | mitigate | UI flow calls only context/resolver/service; tests/spies assert no touchpoint, last-contact, contact, fuel, or cache write path. |
</threat_model>
