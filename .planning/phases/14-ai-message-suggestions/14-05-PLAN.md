## Trust Boundaries

| Boundary | Description |
|---|---|
| profile navigation → Compose | Serializable intent asks Compose to initiate a potentially billable request. |
| async provider response → editable draft | Untrusted asynchronous completion can alter user-authored text. |
| Compose → app_settings (ack only) | The single permitted settings write on the generation path. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|---|---|---|---|---|---|
| T-14-14 | Tampering | draft replacement | critical | mitigate | Pure lifecycle requires request-id freshness and explicit confirmation before replacing a non-empty draft. |
| T-14-15 | Denial of service | Compose request | medium | mitigate | One active request, one owned AbortController + timeout (H4), stale-result invalidation on cancel/unmount/navigation. |
| T-14-16 | Repudiation | profile request intent | medium | mitigate | Consume-once route state prevents duplicate generation on refocus/re-render. |
| T-14-17 | Elevation of privilege | generation side effects | high | mitigate | The generation path calls only context/resolver/service + the single ack writer; write-spy tests assert no touchpoint/last-contact/contact/fuel/cache write. |
| T-14-22 | Information disclosure | first-send gate | high | mitigate | Egress is blocked until the exact contact-specific ResolvedPrompt is acknowledged; ack persists per provider (H5). |
</threat_model>
