## Trust Boundaries

| Boundary | Description |
|---|---|
| device → selected provider | Prompt and BYO key cross an outbound network boundary. |
| Custom URL input → native transport | User-supplied endpoint controls a potential egress destination; connection-time enforcement lives in Plan 07's module. |
| provider response → app | Untrusted `unknown` JSON must be validated before it becomes a draft. |
