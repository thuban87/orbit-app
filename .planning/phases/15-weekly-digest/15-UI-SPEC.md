# Phase 15 — UI Design Contract

> Visual and interaction contract for the Weekly Digest ("your week") screen, the dashboard
> "Your week" entry point, and the Settings digest toggle row. Generated by gsd-ui-researcher,
> verified by gsd-ui-checker.
>
> **This is a pure READ surface (dossier 14 Cluster A/B).** No new schema for the screen, no
> destructive actions, no writes. Every colour resolves through `useTheme().colors.*` — the digest
> reuses EXISTING tokens only and adds NO new status colour (dossier `digest → theme`; `check:colors`
> gate). All decisions here are grounded in the code on disk (CLAUDE.md "review the code"); real
> file:line citations back every reuse claim.

## Spacing Scale

Grounded in the shipped screens (`HomeScreen.tsx`, `NeverContactedScreen.tsx`, `SettingsScreen.tsx`).
All values are multiples of 4 except the two documented odd-radius exceptions the app already ships.

| Token | Value | Usage | Precedent |
|-------|-------|-------|-----------|
| xs | 4px | Tight inline gaps, trailing-cluster gap | `ContactCard.tsx:250` (`trailing.gap:4`) |
| sm | 8px | Compact element/list-row gap, chip gap | `NeverContactedScreen.tsx:240` (`listContent.gap:8`), `FilterChipRow.tsx:95` |
| ~ | 10px | Card/row inner gap, header gap | `HomeScreen.tsx:602/605` (`content.gap:10`, `header.gap:10`) |
| md | 12px | Screen-header gap, row padding, section gap, avatar-cluster gap | `SettingsScreen.tsx:1610/1624/1635`, `ContactCard.tsx:218` |
| lg | 16px | Screen padding, footer-entry horizontal padding | `HomeScreen.tsx:600` (`content.padding:16`), `NeverContactedScreen.tsx:193` |
| xl | 24px | Empty-state top margin, major vertical break | `HomeScreen.tsx:675` (`emptyState.marginTop:24`) |

Touch-target floor: **44px** — every interactive row/glyph uses `minHeight: 44` (and `minWidth: 44`
for glyph buttons). Precedent: `HomeScreen.tsx:590-591`, `FilterChipRow.tsx:99`, `ContactCard.tsx:219`.

Corner radius: **10px** for cards/rows/entries (`ContactCard.tsx:222`, `SettingsScreen.tsx:1634`),
**8px** for the Back control and inputs (`NeverContactedScreen.tsx:204`), **12px** for the sheet
(`SettingsScreen.tsx:1681`).

Exceptions: the status-ring `borderRadius:7` / avatar `size/2` are geometric (circle) radii, not
layout spacing — inherited unchanged from `ContactCard.tsx:233` / `Avatar.tsx:80`. Digest introduces
no new spacing value.

## Typography

Grounded in the shipped role ramp. The app already ships **three** weights (400 / 600 / 700) applied
consistently across every screen; the digest MUST match that ramp for cross-phase visual consistency
(CLAUDE.md "review the code", ROADMAP "one launch sweep"-style single-source discipline). Declaring a
narrower 2-weight set for this one screen would make it inconsistent with the dashboard and Settings
it sits beside — so this deliberately keeps the established 3-weight / role-based scale rather than the
generic 2-weight template default.

| Role | Size | Weight | Line Height | Colour token | Precedent |
|------|------|--------|-------------|--------------|-----------|
| Screen title ("Your week") | 24px | 700 | default | `textPrimary` | `NeverContactedScreen.tsx:209`, `SettingsScreen.tsx:1619` |
| Empty-state heading | 18px | 700 | default | `textPrimary` | `HomeScreen.tsx:680`, `NeverContactedScreen.tsx:231` |
| Group sub-label ("Drifting" / "Gone quiet") | 13px | 600 | 18 | `textSecondary`, `textTransform:"uppercase"`, `letterSpacing:0.5` | `SettingsScreen.tsx:1626-1629` (`sectionHeading`) |
| Row label / backlog entry / person name | 15–16px | 600 (labels) / 400 (person name) | default | `textPrimary` | `SettingsScreen.tsx:1637-1639` (label 16/600), `ContactCard.tsx:241-242` (name 15/400) |
| Body / empty-state body / gentle line | 15px | 400 | 21 (~1.4) | `textSecondary` (body) / `textPrimary` where lead | `HomeScreen.tsx:683-685`, `NeverContactedScreen.tsx:234-236` |
| Day tag ("Tue") / helper / count line | 13px | 600 (day/count) / 400 (helper) | 18 | `textSecondary` | `SettingsScreen.tsx:1695-1698` (helper 13/400/18), `HomeScreen.tsx:608-609` (count 13/600) |
| Inline tappable name (gentle line) / "+N more →" | 14–15px | 600 | default | `accent` | `HomeScreen.tsx:656-658` (`manageText` accent link idiom) |

Weights: **400 regular · 600 semibold · 700 bold** (established app set). Sizes reused from the shipped
ramp: 13 / 15 / 16 / 18 / 24. No net-new size or weight is introduced by this phase.

## Color

Active palette: `space-dark` (`theme-presets.ts:22-96`). The 60/30/10 split below describes the digest
screen; every value is an existing token — **no new colour, no raw hex** (`check:colors`).

| Role | Token (value) | Usage |
|------|---------------|-------|
| Dominant (60%) | `background` (#0B0E1A) | Screen root fill (`View` over `colors.background`, mirroring `NeverContactedScreen.tsx:87`) |
| Secondary (30%) | `surface` (#141828) | Overlooked `ContactCard` fill, the backlog-nudge entry fill, any grouped row (`ContactCard.tsx:123`, footer-entry idiom `HomeScreen.tsx:372`) |
| Secondary support | `surfaceElevated` (#1D2235) | Category chip on reused `ContactCard` only (`ContactCard.tsx:198`) — not otherwise used by the digest |
| Accent (10%) | `accent` (#6C8CFF) | ONLY: inline tappable names in the gentle line, the "+N more →" affordance, the "Your week" dashboard entry's pressed feedback, and the Settings digest Switch "on" track |
| Status — rogue | `rogue` (#E0904A) ring + `rogueExtinguished` (#3E4A6B) | Overlooked "Drifting" (rogue) contacts, rendered via the reused `ContactCard` status ring (`ringVisual(status, colors)`, `ContactCard.tsx:113`). The digest READS the shared rogue constant, never recomputes it (CONTEXT / dossier `digest → data/log`) |
| Status — gone-quiet | `statusDecay` / `statusWobble` (inherited via `ContactCard`) | "Gone quiet" (Rarely-responds slipped) contacts inherit whatever status the reused card computes — the digest adds no status colour of its own |
| Text primary | `textPrimary` (#E6E9F5) | Titles, headings, person names, row labels |
| Text secondary | `textSecondary` (#8B93B0) | Lead phrases, body copy, day tags, group sub-labels, helper text |
| Border | `border` (#2A3048) | Row/entry/back-control outlines |

Accent reserved for: **inline tappable names in the gentle effortful line, the "+N more →"
tap-through, the "Your week" entry's pressed state, and the Settings digest Switch "on" track — nothing
else.** Whole-row tap targets (retrospective person rows, overlooked `ContactCard`s, the backlog entry)
use `textPrimary` for their label and signal tappability by being a `Pressable` row, exactly as the
dashboard/never-contacted rows do (`ContactCard.tsx:154-155`, `HomeScreen.tsx:375`) — they do NOT tint
their text accent.

Destructive / `danger` (#E5484D): **NOT used.** This phase has zero destructive actions (pure read
surface). The `danger` token must not appear on any digest surface.

## Screen Anatomy — "Your week" digest screen

Chrome mirrors `NeverContactedScreen` / `SettingsScreen`: themed root over `background`, a header row
with a `goBack` Back control (`border` outline, `textSecondary` label) + a 24/700 title "Your week";
native-stack `headerShown:false`. Sections render top-to-bottom in this fixed order:

1. **Retrospective — "Reached this week"**
   - Optional gentle lead phrase (15/400 `textSecondary`): **"You caught up with these people this week"** — shown only when the list is non-empty.
   - A LIST of people, most-recent-first (reverse-chronological in the trailing 7-day window). Each row = `Avatar` (size 40–48, `Avatar.tsx`) + name (15/400 `textPrimary`, one line, tail-ellipsis) + a right-aligned day tag ("Tue", 13/600 `textSecondary`). The whole row is a `Pressable`, `minHeight:44` → Profile.
   - **NO headline scoreboard count** — no bold "N reached" figure anywhere (locked: resolves the ⚠ streak-caution; a bare number is REJECTED, CONTEXT § Retrospective / dossier Deferred).
   - Empty retrospective but overlooked present: a single calm no-guilt line (15/400 `textSecondary`): **"No catch-ups logged this week"**.

2. **Gentle effortful line** (quiet aside — BELOW retrospective, ABOVE overlooked; conditional, rare)
   - One line, 15/400 `textSecondary`, NOT a heading, NOT tinted rogue/danger: **"A few recent conversations have felt effortful."**
   - Directly beneath it, the named people as small tappable names (14–15/600 `accent`) → Profile. Wrapping row of inline names.
   - Shown **only when clearly real** (conservative "skews hard" threshold — a planning tunable; the design steer is "err toward NOT showing, never routine", CONTEXT § gentle line).

3. **The overlooked** — gently sub-labelled groups, most-slipped first, backlog last:
   - **"Drifting"** (rogue) — group sub-label (13/600 uppercase `textSecondary`), then up to ~6 rows rendered with the reused `ContactCard` (its status ring carries the `rogue` token via `ringVisual`). Then **"+N more →"** (accent) when the group exceeds the cap.
   - **"Gone quiet"** (Rarely-responds that have slipped) — same sub-label + `ContactCard` rows + "+N more →" pattern; ordered after Drifting.
   - **Backlog nudge (last)** — ONE gentle line with a count: **"{N} people you added but never reached"** (singular: "1 person you added but never reached"), rendered as a single `Pressable` entry in the dashboard footer-entry idiom (`surface` fill, `border` outline, 16/600 `textPrimary`; `HomeScreen.tsx:363-378`) → **NeverContacted** screen. The backlog is NOT re-listed inline (CONTEXT § overlooked).
   - Cap ~6 per group keeps the section calm; the "+N more →" destination (in-place expand vs a filtered list) is a planner decision — the affordance copy, accent token, and 44px target are locked here.

4. **Unified empty state — "all quiet this week"** (when retrospective AND every overlooked group AND the backlog are empty AND no gentle line fires)
   - Heading 18/700 `textPrimary`: **"All quiet this week"**.
   - Body 15/400 (line-height 21) `textSecondary`: **"No catch-ups to look back on, and no one's slipping. Enjoy the calm."** — calm, no-guilt, NO CTA nag (the Sunday push fires unconditionally; a genuinely empty week lands here by design, dossier Cluster D).

`testID` convention (for uiautomator device-UAT, per project memory "verify UI on the Pixel
yourself"): `digest-root`, `digest-back`, `digest-retrospective`, `digest-reached-row-{contactId}`,
`digest-gentle-line`, `digest-overlooked-drifting`, `digest-overlooked-gonequiet`,
`digest-overlooked-more-{group}`, `digest-backlog-nudge`, `digest-empty-all-quiet`.

## Interaction & State Contract

| State | Trigger | Presentation |
|-------|---------|--------------|
| Loading | Screen opened (cold from notification tap, or warm from the entry) | Header + title render instantly; section bodies stay blank until the three reads resolve under a `cancelled`-flag guard (the shipped focus-effect reload pattern, `NeverContactedScreen.tsx:66-82` / `HomeScreen.tsx:137-169`). No spinner, no skeleton flash. Distinguish "loading" from "empty" with a null-vs-loaded sentinel so the "all quiet" state never flashes before data arrives (planner). |
| Populated | Reads returned with data | Sections 1–3 as in Screen Anatomy, in fixed order. |
| Partial empty | Retrospective empty but overlooked present (or vice-versa) | The empty side shows its calm one-liner ("No catch-ups logged this week"); the other side renders normally. |
| Unified empty | All sections empty, no gentle line | The "All quiet this week" state (section 4) only. |
| Error | A digest read throws | Calm error, mirroring the dashboard error idiom (`HomeScreen.tsx:396-404`): heading 18/700 `textPrimary` **"Couldn't load your week"**, body 15/400 `textSecondary` **"Try opening it again in a moment."** Re-runs on next focus; no nag, no destructive retry. |

**Tap contract (all locked, CONTEXT § Digest screen taps):**
- Every name — retrospective rows, overlooked `ContactCard`s, gentle-line names — taps → **Profile** (`navigation.navigate("Profile", { contactId })`).
- Backlog nudge → **NeverContacted** screen.
- Back → **dashboard** (reuses 11-notify's `singleTask`/`onNewIntent` back-stack; dossier `digest → notify`).
- **NO badge / count** on any icon, nav entry, or the entry affordance (locked, dossier "decided without you" #6).

No animation is added (the digest is static content; the app's Skia render-loop / focus-pause rules
in CLAUDE.md do not apply to this screen).

## Dashboard Entry Point — "Your week"

Location: the existing `HomeScreen` top bar (`HomeScreen.tsx:485-515`), a `flex-end` row currently
holding the `◎` Orrery button and the `⚙` Settings gear. The "Your week" action lands **alongside**
these (CONTEXT / project_constraints).

| Property | Value |
|----------|-------|
| Form | A discreet **text** action "Your week" (glyphs read as icons; a short text label reads as a retrospective link and stays unambiguous) |
| Placement | Leftmost item in the top-bar row, so the `◎`/`⚙` glyph cluster stays grouped on the right |
| Type | 15/600 `textSecondary`; pressed → `accent` (mirrors the `◎` button's pressed-state idiom, `HomeScreen.tsx:493-502`) |
| Touch target | `minHeight:44`, adequate horizontal padding |
| a11y | `accessibilityRole="button"`, `accessibilityLabel="Your week"`, `testID="dashboard-your-week-entry"` |
| Action | `navigation.navigate("Digest")` |
| Badge | **None** — no count, no unread dot (locked) |

This is additive to the Sunday push, not a replacement (dossier "decided without you" #3, accepted).

## Settings — Weekly digest toggle (4th notification type)

A 4th per-type toggle row in the Notifications section of `SettingsScreen` (`SettingsScreen.tsx:608`),
inserted **after "Birthday alerts" (`:703-738`) and before "Show names on lock screen" (`:741`)** — so
the three notification *types* (decay · birthday · digest) sit together and the lock-screen visibility
modifier stays below them.

| Property | Value |
|----------|-------|
| Row shell | Reuse `styles.row` exactly: `surface` fill, `border` outline, radius 10, padding 12, gap 10 (`SettingsScreen.tsx:1631-1636`) |
| Label | "Weekly digest" — 16/600, `textPrimary` when `masterOn` else `textSecondary` (the gated-label idiom, `:674-678`) |
| Control | `Switch`, `disabled={!masterOn}` (gated by the master toggle exactly like decay/birthday, `:690`); `trackColor={{ false: border, true: accent }}`, `thumbColor: surfaceElevated` (`:693-694`) |
| Default | **ON** once notifications are granted (locked, dossier Cluster D "defaults on") |
| Value source | Reads/writes a digest-enabled app setting via the existing `persist(...)` + `reconcileSchedule` path (`:350-360`); the persistence mechanism (existing settings write vs a migration) is a planning/data-layer decision, NOT a UI concern |
| Helper | 13/400/18 `textSecondary`: **"A Sunday-morning look back at your week — who you reached, and who's slipping quietly."** |
| a11y | `accessibilityRole="switch"`, `accessibilityLabel="Weekly digest"`, `accessibilityState={{ disabled: !masterOn, checked: <digest on> }}`, `testID="settings-notifications-digest"` |

Flipping the toggle cancels/re-registers the single WEEKLY trigger (CONTEXT § Claude's Discretion) —
a mechanism concern for planning; the row's presentation is locked here.
