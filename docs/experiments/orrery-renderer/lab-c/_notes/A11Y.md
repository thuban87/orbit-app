# Orrery Lab C — accessibility check (Checkpoint F.3, RELEASE build, 2026-10-01)

Pixel 6 Pro, release APK (`flags=[ HAS_CODE ALLOW_CLEAR_USER_DATA ]`), Lab C Inner System, Galaxy/Dark.
Dumps: `evidence/08-final/a11y-uiautomator-{overview-inner,focus-sami,contacts-sheet}.xml`.
`uiautomator dump` worked first try in release at overview and focus (it failed while the Orrery animated
in debug).

## 1. Per-body a11y overlay nodes — **do not exist**

The brief asked to verify "invisible a11y overlay nodes" for contacts whose bounds follow the 3D-projected
bodies. **There are none**, in Lab C or in the production Skia Orrery: the overview dump has no node inside the
canvas area except the lab badge (`ORRERY LAB C — TRUE 3D`, [42,2786][580,2837]). The `orrery-canvas` View
carries no label and no children; bodies are GPU draws. This matches the product design recorded in
`research/CURRENT-ORRERY.md` §4: *"The canvas is not the accessible path"* — the companion controls are.
So the bounds-vs-screenshot comparison is **not applicable**; nothing was built and nothing was changed.
If per-body nodes are wanted (e.g. explore-by-touch on the bodies), that is new scope: the projection packet
already has each body's screen x/y/radius per frame, so overlays are feasible, but they would need throttled
React updates (not per-frame setState).

## 3. TalkBack swipe navigation — **could not be exercised via adb**

Settings read first: `enabled_accessibility_services = com.tech.gm.pegasusdriver/com.tech.gm.pegasusdriver.services.Accessibility`,
`accessibility_enabled = 1`. TalkBack was enabled by appending its component (keeping the existing service), then
six `input swipe` right-swipes were sent. TalkBack did not treat them as navigation gestures: `input` injects
events past touch exploration, so each swipe **orbited the 3D camera** instead
(`a11y-talkback-on-injected-swipe-orbits-camera.png`); no accessibility-focus outline appeared and logcat shows no
utterances. Both settings were then restored to exactly the values read (`dumpsys accessibility` confirms only
the pegasusdriver service is enabled again). A real TalkBack pass needs a human with the phone (owner checklist
item), or a UiAutomator instrumentation test.
